# Viewgrain QA 이슈

## VG-001: 특수 파일 조회가 열기 단계에서 대기함

- 우선순위: P2
- 최초 보고: 2026-11-17 사용자 리뷰. 임시 사본에서 두 번 재현됐으며 기존 테스트 네 개는 통과했다.
- 원인: 파일을 연 뒤에만 일반 파일 여부를 검사해 FIFO의 열기 대기를 막지 못했다.
- 수정 전 재현: 실제 MCP 서버의 이미지 경로에 FIFO를 두자 2초 요청 제한을 초과했다. 추가한 회귀 테스트가 실패했다.
- 수정: 열기 전 파일 종류 검사, 비차단 및 심볼릭 링크 추적 금지 옵션으로 열기, 열린 파일의 종류 재검사.
- 재검증: macOS에서 이미지, manifest, 설명과 프롬프트 파일을 각각 FIFO로 바꾸고 두 번씩 조회했다. 모두 `INVALID_FILE`을 반환했고 일반 파일로 복원한 뒤 같은 서버에서 이미지 조회가 성공했다.
- 상태: macOS 재현 조건에서 해결. Windows와 파일 교체 경쟁 상황의 실제 재현은 미검증.

## VG-002: 목록의 긴 이미지 ID를 상세 조회에서 거부함

- 우선순위: P2
- 최초 보고: 2026-11-17 사용자 리뷰. 목록이 반환한 151자 이미지 ID가 상세 조회의 150자 제한으로 거부됐다.
- 원인: 목록과 상세 조회가 같은 ID의 제약을 별도로 정의했다.
- 수정 전 재현: 150자 ID의 조회는 성공했으나 151자 ID를 목록에서 거부해야 한다는 회귀 테스트가 실패했다.
- 수정: 허용 문자와 최대 길이를 `src/identifiers.mjs`에서 공유한다. 최대 길이를 넘는 manifest는 목록 조회부터 거부한다.
- 재검증: 실제 MCP 목록 응답에서 얻은 150자 ID로 이미지 조회 성공. 151자 ID를 가진 manifest는 `INVALID_MANIFEST`로 거부.
- 상태: macOS의 실제 MCP 연결에서 해결.

검사 명령과 남은 범위는 [검증 기록](verification.md)에 있다. 최초 보고와 실패 기록은 해결 후에도 보존한다.
