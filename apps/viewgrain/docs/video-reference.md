# 비디오 앱 레퍼런스 탐색 방향

기존 앱의 구현 범위와 독립적으로, 만들고 싶은 최고의 비디오 앱 모습을 탐색한다. 첫 목표는 사용자가 갖고 싶은 화면을 찾는 것이다.

## 탐색 기준

- `for-me/apps/video`의 코드, 현재 기능, 기술과 구현 난이도를 생성 조건으로 사용하지 않는다.
- 영상 탐색과 시청 경험을 중심으로 화면 구성과 필요한 기능을 새롭게 제안한다.
- 영상 제목, 콘텐츠 수, 색상, 글꼴, 화면 방향과 버튼 배치를 미리 고정하지 않는다. 한 시안 안에서는 선택한 디자인 규칙을 일관되게 적용한다.
- 영상 이미지, 글자와 여백, 조작 요소가 함께 완성도 있는 앱 화면을 이루게 한다. 특정 서비스의 로고나 화면을 그대로 복제하는 것은 목표가 아니다.
- 기능은 사용 목적에 맞게 선택한다. 기존 앱에 없다는 이유로 제외하거나 화면을 채우기 위해 추가하지 않는다.
- 전체를 단정하게 만드는 규칙과 기억에 남는 디자인 선택을 함께 설명한다. 추상적인 칭찬이나 강도 점수만으로 요청하지 않는다.

## 프롬프트 작성

전체 의도, 역할별 색상과 글자, 구역 사이의 관계, 화면 상태와 가독성 기준으로 요청을 구성한다. 공개 프롬프트에서 추출한 작성 방식을 사용하되 특정 색상이나 배치를 정답으로 복제하지 않는다.

먼저 가장 설득력 있는 비디오 앱의 주 화면을 만든다. 마음에 드는 방향이 나오면 그 이미지의 디자인 규칙을 이어받아 재생 화면과 다른 상태를 확장한다. 목록과 재생 화면을 모두 탐색하되 처음부터 같은 비중의 시안 여섯 장으로 제한하지 않는다.

구체적인 작성 순서와 수정 방식은 [프롬프트 활용](prompt-guide.md)에 있다. 첫 실행에서 대화로 제공한 프롬프트 전문은 [SCENE 프롬프트 기록](../references/scene-001/v1/prompts.md)에 보존한다.

## 선택 이후

좋아한 화면과 부분, 이유를 기록한다. 여러 방향의 차이를 더 정확히 비교할 필요가 생기면 그때 콘텐츠와 화면 조건을 맞춘다. 기존 제품에 반영할 기능과 구현 가능성은 방향 선택 이후 별도로 검토한다.

생성 이미지의 완성도는 실제 재생 동작, 접근성이나 기기 호환성의 검증 결과가 아니다.

첫 선택 결과는 [SCENE 버전 1](../references/scene-001/v1/README.md)의 홈, 세로 재생과 가로 재생이다. 사용자의 만족 평가와 화면 관찰에서 추출한 특징을 구분해 기록했다.

## 2026-11-17 방향 정정

이전 초안은 현재 동영상 앱을 기준으로 영상 3개, 고정 제목과 시간, 세로 목록과 가로 재생, 필수 조작과 제외 기능을 정했다. 사용자가 기존 앱을 전혀 고려하지 않고 최고의 비디오 앱 레퍼런스를 탐색하도록 정정했다. 이전 고정 조건과 그 조건으로 만든 A, B, C 프롬프트는 현재 탐색 기준으로 사용하지 않는다.
