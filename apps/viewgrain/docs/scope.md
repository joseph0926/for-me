# Viewgrain 범위와 결정

화면을 직접 보며 원하는 디자인을 고르고, 선택한 모습을 AI가 구현할 때 참고하게 합니다.

## 시작한 문제

[동영상 앱](../../video/README.md)을 만들면서 영상 목록과 재생 조작 화면 모두에서 기대한 느낌을 얻지 못했습니다. 원하는 방향은 넷플릭스와 여러 OTT 서비스에서 느낀 모던하고 깔끔한 화면입니다. OTT는 인터넷으로 영상을 제공하는 서비스를 뜻합니다.

기존 tastepin은 컴포넌트와 화면의 배치, 동작에 관한 취향을 기록합니다. 이번에는 그런 선택에 더해 완성된 화면을 보면서 디자인 방향을 정하는 과정이 필요합니다. 두 도구를 자동으로 연결하거나 tastepin을 대체할지는 아직 정하지 않았습니다.

유료 레퍼런스 서비스 구독을 원하지 않아, GPT-Image-2.6으로 우리 시안을 만들고 갤러리에 쌓는 방향을 선택했습니다. 생성한 시안이 실제 제품에서 검증된 사용성을 갖춘 사례라는 뜻은 아닙니다.

## 확정한 방향

- 프로젝트 이름은 Viewgrain, 식별자는 `viewgrain`입니다.
- 사람이 화면을 보고 비교하고 고르는 레퍼런스 사이트를 만듭니다.
- 생성한 화면과 선택 이유를 축적하고, AI가 참고하도록 MCP를 기본 연결 방식으로 제공합니다.
- 첫 탐색 주제는 비디오 앱입니다. 기존 앱의 기능과 구현 제약을 제외하고 원하는 영상 탐색과 재생 화면을 찾습니다.
- 유료 레퍼런스 서비스 구독을 필수 조건으로 삼지 않습니다.
- 문서화부터 진행합니다. 공개 프롬프트 후보의 전체 수입이나 이미지 생성 자동화 도입은 아직 확정하지 않았습니다.

## 첫 버전 범위 제안

### 현재 구현 범위

2026-11-17에는 보관한 묶음 정보와 이미지 한 장을 읽는 로컬 MCP 서버를 구현했습니다. 원본과 선택 기록을 보존하며, 잘못된 입력과 버전, 누락 또는 손상된 파일을 거부합니다. 완료 기준은 실제 MCP 연결의 원본 바이트 일치와 Codex의 이미지 인식 확인입니다. 사이트 화면, 검색과 원격 운영은 이번 구현에 포함하지 않습니다.

### 이후 제품 범위

다음 범위는 구현을 시작할 때 구체화할 초안입니다.

1. 생성한 화면 이미지와 프롬프트를 등록합니다. 갤러리 밖에서 만든 이미지도 등록할 수 있게 합니다.
2. 목록과 재생 화면처럼 같은 앱의 화면을 한 묶음으로 비교합니다.
3. 마음에 드는 시안과 부분을 고르고, 유지할 특징과 바꿀 점을 기록합니다.
4. AI가 MCP로 후보를 검색하고 선택한 이미지와 기록을 읽습니다.
5. 실제 구현 화면을 연결해 시안의 어떤 부분이 반영됐는지 확인합니다.

초기에는 콘텐츠와 기능을 고정하지 않고 매력적인 화면 구성을 탐색합니다. 방향을 선택한 뒤 더 정확한 비교가 필요할 때 영상 제목과 기능을 맞춥니다. 영상 이미지의 매력과 화면 구성에서 좋아한 점을 각각 기록합니다.

## 완료 판단

- 사용자가 문장만으로 설명하기 어려웠던 화면의 모습을 이미지로 선택할 수 있습니다.
- AI가 선택한 시안의 이미지와 선택 이유를 함께 받습니다.
- 같은 묶음에 속한 목록과 재생 화면을 함께 가져올 수 있습니다.
- 생성한 시안과 실제 구현 화면을 구분하고, 비교 결과를 저장할 수 있습니다.
- 저장한 이미지, 프롬프트와 선택 기록이 앱을 다시 열어도 유지됩니다.

첫 실험의 비교 조건과 기록 항목은 [검증 계획](verification.md)에 둡니다.

## 첫 버전에서 미룰 기능 제안

- 외부 레퍼런스 사이트의 대량 수집과 자동 복제
- 결제, 여러 사용자의 계정과 공개 커뮤니티
- 프롬프트의 무제한 자동 생성과 예약 생성
- 레퍼런스에서 앱 코드를 자동으로 만들고 배포하는 기능
- tastepin과의 자동 동기화

파일 내보내기는 보조 기능 후보입니다. MCP를 기본으로 쓴다는 결정은 유지합니다.

## 구현 전에 정할 항목

- 후속 지원 OS와 원격 접근: 첫 구현은 macOS 로컬 파일과 stdio를 사용하며 다른 OS와 원격 운영은 미검증입니다.
- 웹 화면 기술, 이미지 저장 방식과 검색 방식
- 다른 AI 앱에서의 이미지 전달 호환성
- 이미지 생성 환경, GPT-Image-2.6의 구체적인 모델과 설정, 생성량과 비용 한도
- 후보 프롬프트에서 실제로 가져올 항목과 각 항목의 출처 기록
- 비교 화면에서 선택 이유를 남기는 방법과 부분 선택의 범위

프로젝트 이름의 상표와 도메인 확보 여부는 확인하지 않았습니다.
