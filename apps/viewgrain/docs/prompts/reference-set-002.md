# 두 번째 레퍼런스 묶음 프롬프트

두 번째 묶음은 FRAME 홈을 생성하고 수정한 뒤 컬렉션 상세 화면을 탐색했다. 사용자는 첫 홈의 글꼴과 높은 밀도를 지적했고 수정된 홈에는 나아졌다고 평가했다. 이후 추가 수정한 목록형 컬렉션 상세의 두 번째 이미지를 선택해 [FRAME 버전 1](../../references/frame-002/v1/README.md)로 등록했다. 홈과 재생 화면의 최종 선택은 아직 포함하지 않았다. 제품 기능과 시각적 결정은 기존 앱의 구현과 독립적이다.

P01은 최초 탐색, P04는 홈의 글꼴과 밀도 수정, P05는 컬렉션 상세 화면, P06은 목록형 대안 요청이다. P07은 사용자가 실제 추가 프롬프트로 제공한 문장이다. P02와 P03은 후속 재생 화면의 준비안으로 남긴다. P07을 제외한 문장은 에이전트가 대화에서 제공했거나 준비한 요청이며 실제 입력 전문은 미확인이다. P07도 도구 실행 로그가 아닌 사용자 보고로 확인했다.

## 현재 관찰

첫 FRAME 홈은 포스터와 작품 정보를 좌우로 나누고 작품 격자를 사용했지만, 사용자는 장식적인 글꼴과 높은 밀도를 지적했다. 수정 홈은 글꼴과 여백이 정리된 대신 큰 대표 장면 중심으로 바뀌어 첫 SCENE 묶음과 구성이 가까워졌다. 이 유사성은 에이전트의 관찰이다.

사용자는 수정 홈을 평가한 뒤 컬렉션 상세 화면으로 확장하자는 제안에 동의했다. `도시의 밤`의 두 열 결과에는 디자인은 좋지만 한 작품이 한 줄을 차지하는 방식이나 보기 선택을 검토하자고 했다. 목록형 첫 결과 뒤에는 썸네일 너비와 행 간격을 지적한 추가 프롬프트를 직접 제공했고, 이후 `2번으로`라고 수정 결과를 선택했다. 보기 전환 기능 도입은 아직 정하지 않았다.

추가 수정 결과에서는 썸네일이 좁아지고 제목의 시작점이 왼쪽으로 이동해 제목과 이미지 사이의 비중이 달라졌다. 두 결과 모두 화면에 작품 여덟 개가 보여 항목 수를 줄인 것은 아니다. 간격이 여유롭게 느껴지는 변화와 행 간격 자체의 증가량은 구분하며, 실제 기기의 가독성이나 간격 수치는 측정하지 않았다. 이는 에이전트의 화면 관찰이다.

## P01

첫 생성은 홈과 컬렉션 탐색 경험을 보여주는 한 화면이다. 컬렉션은 서로 관련된 영상을 모아 보여주는 묶음을 뜻한다.

```text
새로운 비디오 앱의 디자인 레퍼런스를 만들어 주세요.

이번 제품은 취향에 맞는 영화를 발견하고, 마음에 든 작품을 모으고, 한 편을 골라 감상하는 개인 상영관입니다. 앱을 열었을 때 작품을 천천히 살펴보고 싶으면서도 보고 싶은 영화를 쉽게 찾을 수 있어야 합니다.

기존 프로젝트의 코드, 기능 목록, 기술 스택과 구현 난이도는 고려하지 마세요. 처음부터 가장 매력적인 제품 경험을 설계할 수 있습니다.

디자인 방향:
잘 편집된 영화 매거진과 개인 영화 컬렉션에서 느껴지는 안목을 실제로 사용할 수 있는 앱 화면으로 표현하세요.
큰 대표 영상 하나 아래에 비슷한 가로 목록을 반복하는 구성에서 벗어나세요. 포스터의 크기와 배치, 제목의 위계, 여백과 작품 사이의 관계로 이 앱만의 구성을 만드세요.
서로 다른 가능성을 검토한 뒤 가장 설득력 있는 방향 하나를 선택해 일관되게 적용하세요.

제품 경험:
사용자가 작품에 관심을 갖고, 더 알아보고, 감상을 시작하는 흐름이 화면에서 읽혀야 합니다.
작품을 모으거나 다시 찾는 방법, 컬렉션을 탐색하는 방식과 필요한 기능은 직접 선택하세요. 기능을 많이 보여주기보다 무엇을 먼저 해야 하는지 분명하게 만드세요.
작품의 큰 제목과 짧은 정보, 이미지가 함께 의미를 전달하도록 구성하세요. 모든 작품에 설명 문장과 배지를 붙이지 마세요.

시각적 선택:
배경의 밝기, 색상, 글꼴, 이미지 비율과 화면 방향은 콘셉트에 맞게 결정하세요.
작품 이미지는 각자 다른 색과 분위기를 가질 수 있습니다. UI는 그 차이를 정돈하면서 자신만의 인상을 만들어야 합니다.
색을 사용한다면 선택 상태나 주요 행동 등 역할을 정하세요. 금속성 금색, 발광과 광택을 겹쳐 고급스러움을 연출하지 마세요.
글자는 실제로 읽기 편해야 합니다. 제목, 작품 정보와 탐색 메뉴의 중요도를 크기, 굵기와 간격으로 구분하세요.

조작 요소:
내비게이션과 버튼은 콘텐츠보다 과하게 눈에 띄지 않게 하세요.
같은 기능을 상단과 하단에 중복해서 나열하지 마세요.
큰 둥근 패널 안에 버튼을 다시 여러 겹 넣거나 모든 아이콘 아래에 설명을 반복하지 마세요.
주요 행동은 분명하게 강조하고 보조 기능은 차분하게 정리하세요. 버튼을 알아보기 어렵게 만들거나 무조건 작고 얇게 만들지는 마세요.

콘텐츠:
새로운 앱 이름과 가상의 작품, 포스터를 직접 구성하세요. 다양한 장면과 분위기의 작품을 선택해 단순히 같은 이미지가 반복되는 느낌을 피하세요.
한국어 문구는 짧고 자연스럽게 쓰세요. 작품 이미지의 아름다움과 화면 구성의 완성도를 함께 보여주세요.

출력:
제품의 성격을 가장 잘 보여주는 홈 또는 컬렉션 탐색 화면 한 장을 이미지로 생성하세요.
사용자가 실제로 탐색하고 재생할 수 있는 앱 화면으로 표현하세요. 잡지 지면이나 홍보 포스터처럼 만들지 마세요.
앱 화면을 정면에서 보여주고 이미지 전체를 채우세요. 기기 목업, 화면 밖 장식, 설명 주석과 여러 화면을 축소한 보드는 제외하세요.
```

## P02

새 홈이 선택된 뒤 해당 이미지를 첨부한다. 앱에 담긴 작품 하나를 세로 화면에서 감상하는 경험으로 확장한다.

```text
첨부한 이미지는 새 비디오 앱의 디자인 방향입니다. 같은 제품의 세로 재생 화면 한 장을 디자인해 주세요.

첨부 이미지에서 색상 관계, 글자 위계, 아이콘과 형태 표현을 읽어 이어받으세요. 홈의 목록 배치를 반복하지 말고 영상을 감상하는 경험에 맞춰 재구성하세요.

홈에 담긴 작품 하나를 골라 그 작품의 한 장면을 보여주세요. 선택한 작품의 제목과 분위기를 일관되게 유지하세요. 영상의 비율은 작품에 맞게 선택하고 화면을 채우기 위해 인물이나 장면을 부자연스럽게 늘리지 마세요.

영상에 몰입하면서 재생과 위치 이동을 편하게 할 수 있어야 합니다. 어떤 조작을 먼저 보여주고 어떤 기능을 보조 영역에 둘지는 직접 결정하세요.
주요 조작과 보조 설정을 같은 크기와 밝기로 나열하지 마세요. 큰 바탕 패널과 반복 라벨에 의존하지 않고 간격과 정렬, 명암으로 묶으세요.
제목과 영상 장면을 살리고, 화면을 채우기 위해 줄거리나 장르 배지를 추가하지 마세요.

조작 요소가 보이는 재생 중 상태로 표현하세요. 주 버튼에는 일시정지 아이콘을 쓰고, 현재 시간과 전체 길이, 진행 막대의 위치를 서로 맞추세요. 숫자는 직접 선택하되 화면 안에서 일관돼야 합니다.

영상과 글자, 버튼의 관계가 편안하고 정돈돼 있어야 합니다. 홈에서 사용한 강조색을 모든 조작에 반복하지 말고 필요한 역할에만 사용하세요.

세로 앱 화면 한 장만 정면으로 출력하세요. 기기 목업, 화면 밖 배경과 설명 주석은 제외하세요.
```

## P03

선택한 세로 재생 이미지를 첨부한다. 영상 장면과 상태를 유지한 가로 화면으로 확장한다.

```text
첨부한 세로 재생 화면을 같은 앱의 가로 재생 화면으로 확장해 주세요.

같은 작품과 영상 장면, 제목, 현재 시간과 전체 길이, 재생 상태를 유지하세요. 진행 막대도 같은 위치를 나타내야 합니다.
영상은 원래 비율을 유지하고 전체 장면이 보이게 배치하세요. 남는 공간을 허용하며, 장면을 다시 만들거나 인물을 늘려 가로 폭을 채우지 마세요.

세로 화면의 버튼을 가로로 늘어놓는 방식으로 끝내지 마세요. 넓어진 공간에서 영상이 중심에 남고 필요한 조작을 쉽게 찾을 수 있도록 다시 구성하세요.
주요 재생 조작과 보조 기능을 묶는 방식, 제목과 시간의 위치를 가로 화면에 맞게 선택하세요. 모든 조작을 균등한 간격으로 화면 전체에 흩뿌리지 마세요.

첨부 이미지의 글자, 색상과 아이콘 규칙을 유지하세요. 큰 버튼 바탕, 두꺼운 패널과 반복 설명을 추가하지 마세요. 장면 위에서 읽기 어려운 부분에만 명암 보완을 사용하세요.

조작 요소가 보이는 가로 앱 화면 한 장을 생성하세요. 기기 목업과 설명 주석은 제외하세요.
```

## P04

첫 FRAME 홈의 글꼴과 밀도를 수정하도록 대화에서 제공한 요청이다. 이후 사용자가 수정 결과를 첨부하고 나아졌다고 평가했다.

```text
첨부한 비디오 앱 화면을 수정해 주세요.

현재 장식적인 글꼴의 반복이 인위적으로 느껴지고, 첫 화면에 담긴 정보가 많아 답답합니다. 작품을 천천히 고르고 수집하는 개인 상영관이라는 방향을 유지하면서 글자와 화면 밀도를 정리하세요.

글꼴:
앱 이름, 메뉴, 구역 제목과 작품 정보에는 글자 끝에 장식이 없는 단정한 산세리프 계열을 사용하세요.
여러 서체를 섞는 대신 크기와 굵기, 간격으로 위계를 만드세요.
작품 제목마다 붓글씨나 명조체를 반복하지 마세요.
가장 중요한 작품 제목 하나에만 충분한 존재감을 주고, 나머지 제목은 읽기 편한 크기와 보통 또는 중간 굵기로 표현하세요.
모든 제목을 크고 굵게 만들거나 자간을 넓혀 분위기를 만들지 마세요.

첫 화면의 우선순위:
대표 작품을 살펴보고 감상을 시작하는 행동이 먼저 보여야 합니다.
그다음 내 컬렉션과 다른 작품을 탐색할 수 있게 하세요.
모든 콘텐츠를 한 화면 안에 끝까지 보여줄 필요는 없습니다. 자연스럽게 아래로 스크롤하는 화면으로 설계하세요.

밀도 조정:
상단 대표 작품 옆에 붙어 있는 작은 추천 작품 두 개는 제거하고, 작품 제목과 주요 행동 주변에 여유를 주세요.
컬렉션은 이름과 대표 이미지가 명확하게 읽히도록 단순화하세요. 여러 장의 사진을 기울여 겹친 장식은 제거하세요.
작품 탐색은 세 열의 빽빽한 격자 대신 여유 있는 두 열로 구성하세요. 화면 아래로 이어지는 작품은 다음 스크롤 영역에 남겨두세요.
장르 필터는 긴 항목 목록으로 구역 제목과 경쟁하지 않도록 간결하게 정리하세요.

정보 표현:
작품마다 필요한 정보만 남기세요. 제목, 장르, 연도와 상영 시간을 모든 위치에 반복하지 마세요.
구역 사이 간격은 개별 작품 사이 간격보다 넓게 두어 읽는 흐름을 만드세요.
공간을 확보하기 위해 글자를 작게 줄이지 마세요. 동시에 보여주는 항목 수를 줄이세요.
비워진 공간을 배지, 설명 문장이나 장식으로 다시 채우지 마세요.

유지할 것:
FRAME이라는 앱 이름, 개인 영화 컬렉션이라는 제품 성격, 기존 작품 이름과 이미지의 정체성은 유지하세요.
어두운 배경과 절제된 조작 표현을 유지하고 새로운 광택이나 발광 효과를 추가하지 마세요.

수정된 앱 화면 한 장을 정면으로 출력하세요.
```

## P05

글꼴과 밀도를 수정한 FRAME 홈을 첨부하고 사용한다. 첫 FRAME 홈이나 SCENE 화면을 참조 이미지로 혼합하지 않는다.

```text
첨부한 이미지는 FRAME이라는 개인 영화 컬렉션 앱의 홈 화면입니다.
홈에서 ‘도시의 밤’ 컬렉션을 눌러 들어간 상세 화면을 디자인해 주세요.

목표:
내가 모아둔 영화들을 편안하게 살펴보고 지금 감상할 한 편을 고르는 화면입니다.
홈과 같은 앱이라는 느낌을 유지하면서, 작품들을 한 묶음으로 탐색하는 경험을 보여주세요.
기존 프로젝트의 구현 기능이나 기술 제약은 고려하지 마세요.

화면 구성:
```
