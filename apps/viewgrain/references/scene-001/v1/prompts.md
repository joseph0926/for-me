# SCENE 생성 및 수정 프롬프트 기록

이 대화에서 사용자에게 제공한 프롬프트 전문을 보존한다. 실제 생성 도구의 입력 기록을 받은 것은 아니므로 그대로 입력됐다고 단정하지 않는다. 사용자 결과와 반응은 [묶음 설명](README.md)에 있다. 원문 복사와 구분하기 위해 설명은 코드 블록 밖에 둔다.

이전 앱의 기능을 고정했던 A, B, C 프롬프트는 방향 정정으로 폐기되어 포함하지 않는다. 아래 P01부터가 구현 제약을 벗어난 탐색이다. P01과 P02를 같은 답변에서 제공했고, 이후 결과를 보며 P03, P04와 P05를 제공했다. P04와 P05는 각각 홈과 재생 화면에 사용하는 별도 수정 요청이다.

## P01

새 비디오 앱의 주 화면 탐색. 특정 이미지 첨부를 요구하지 않은 최초 생성 요청이다.

```text
새로운 비디오 앱의 디자인 레퍼런스를 만들어 주세요.

목표는 이 화면을 보는 순간 실제로 사용하고 싶어지는, 완성도 높은 비디오 앱을 발견하는 것입니다. 기존 프로젝트의 코드, 기능 목록, 기술 스택, 개발 비용이나 구현 난이도는 고려하지 마세요. 제품을 처음부터 새롭게 디자인할 수 있습니다.

넷플릭스나 뛰어난 OTT 서비스에서 느껴지는 영상의 매력, 탐색의 즐거움과 정돈된 사용 경험을 지향합니다. 특정 서비스의 화면을 복제하기보다 독자적인 제품으로 설득력 있는 방향을 제안해 주세요.

먼저 내부적으로 서로 다른 디자인 가능성을 검토하고, 가장 강한 방향 하나를 선택하세요. 그 방향을 끝까지 일관되게 적용한 주 화면 한 장을 이미지로 생성하세요.

제품과 화면 구성:
사용자가 영상을 발견하고, 보고 싶은 것을 고르고, 시청을 시작하고 싶어지는 순간을 디자인하세요.
홈, 라이브러리, 탐색을 어떤 방식으로 구성할지 직접 결정하세요.
필요한 기능, 콘텐츠의 종류와 개수, 탐색 방식, 정보의 우선순위도 선택할 수 있습니다.
각 요소에는 사용자에게 필요한 역할이 있어야 합니다. 많은 기능을 보여주는 것 자체를 목표로 삼지는 마세요.

시각적 방향:
화면을 기억하게 만드는 뚜렷한 디자인 선택이 있어야 합니다.
그 선택은 이미지의 사용 방식, 공간 구성, 타이포그래피, 색의 관계나 탐색 구조에서 드러날 수 있습니다.
색상, 밝고 어두운 정도, 글꼴, 밀도, 이미지 비율과 화면 방향을 미리 정해진 템플릿에 맞추지 말고 선택한 콘셉트에 맞게 결정하세요.

영상 이미지와 UI를 함께 디자인하세요.
콘텐츠의 분위기와 화면 구성이 서로를 돋보이게 해야 합니다.
이미지의 크기와 배치, 제목의 존재감, 보조 정보와 조작 요소의 무게를 조절해 시선이 자연스럽게 흐르게 하세요.
모든 구역과 버튼이 똑같이 강조되지 않도록 하세요.

콘텐츠:
선택한 제품에 어울리는 가상의 영상 제목과 장면, 포스터를 직접 구성하세요.
실제 서비스처럼 구체적이고 자연스러운 내용을 사용하세요.
한국어 문구는 짧고 정확하게 쓰고, 제목과 조작 요소가 실제 화면 크기에서도 읽혀야 합니다.

완성도:
주요 행동과 탐색 경로가 화면만 보고 이해돼야 합니다.
글자, 색상, 아이콘, 여백과 모서리 표현은 하나의 제품 규칙을 따라야 합니다.
이 화면만의 매력과 편안한 사용 경험이 함께 드러나야 합니다.

출력:
선택한 콘셉트를 가장 잘 보여주는 실제 앱 화면 한 장을 생성하세요.
화면을 정면에서 보여주고 앱 자체가 이미지를 채우게 하세요.
기기 목업, 광고용 배경, 디자인 설명과 여러 화면을 축소한 보드는 제외하세요.
```

## P02

홈 이미지를 첨부해 같은 앱의 재생 화면으로 확장하는 요청. 실제로 어떤 버전의 홈을 첨부했는지는 미확인이다.

```text
첨부한 이미지는 새 비디오 앱의 디자인 방향입니다.
이 앱에서 영상을 재생하는 화면을 디자인해 주세요.

첨부 이미지의 색상 관계, 글자 위계, 여백, 아이콘과 형태 표현을 읽고 같은 제품의 재생 화면으로 발전시키세요. 홈 화면의 배치를 그대로 반복할 필요는 없습니다.

목표는 영상에 몰입하면서도 필요한 조작을 편하게 찾을 수 있는 아름다운 재생 경험입니다.

재생 화면의 방향과 구성, 필요한 기능, 조작 요소의 위치와 묶음은 직접 결정하세요. 기존 플레이어의 기능 목록이나 중앙 버튼 배치에 얽매이지 마세요.

어떤 조작은 먼저 보여야 하고 어떤 기능은 보조 영역으로 물러나야 하는지 판단하세요. 재생 상태, 시간, 진행 표시와 버튼 아이콘은 서로 일치해야 합니다.

선택한 영상 장면과 조작부를 함께 구성하세요. 장면의 중요한 부분을 살리면서 글자와 버튼이 편안하게 읽히도록 배치와 명암을 조절하세요.

홈 화면과 같은 앱이라는 인상을 유지하면서, 재생 경험에 맞는 독자적인 구성을 만들어 주세요.

조작 요소가 보이는 상태의 재생 화면 한 장을 생성하세요.
앱 화면만 정면으로 출력하고 기기 목업, 설명 주석과 화면 밖 장식은 제외하세요.
```

## P03

사용자가 첫 홈의 금색 강조색을 지적한 뒤 제공한 수정 요청. 대상은 금색 홈 이미지다.

```text
첨부한 비디오 앱 화면을 수정해 주세요.

현재 금색 강조와 광택, 빛 번짐이 겹쳐 인위적으로 고급스러움을 연출하는 느낌이 납니다. 장식을 덜어내고 영상과 화면 구성의 매력이 드러나게 해 주세요.

이번 수정에서는 콘텐츠, 배치, 이미지 크기와 글자 위계를 유지하세요. 색상과 표면 처리의 변화만 비교하려는 목적입니다.

- 로고 위의 금색 빛 곡선을 제거하고 문자 로고만 남깁니다.
- 선택된 메뉴는 밝은 글자와 얇은 선으로 표시하고 발광을 없앱니다.
- 주 재생 버튼은 부드러운 흰색 단색 바탕과 어두운 아이콘으로 표현합니다.
- 배지는 채도가 낮은 중립색으로 정리합니다.
- 진행 막대는 밝은 중립색으로 표시합니다.
- 버튼의 금속성 광택, 금색 그라데이션과 장식적인 빛 번짐을 제거합니다.
- 새로운 강조색으로 금색을 일괄 치환하지 마세요. 강조가 필요한 요소만 명암으로 구분하세요.

영화 장면 안의 가로등, 노을 등 원래 빛과 색은 유지하세요.
수정된 앱 화면 한 장만 생성해 주세요.
```

## P04

사용자가 하단 메뉴바와 버튼들이 모던하지 않다고 지적한 뒤 제공한 홈 수정 요청. 대상은 그때 첨부한 금색 처리를 줄인 홈 이미지다.

```text
첨부한 비디오 앱 홈 화면에서 하단 내비게이션을 다시 디자인하세요.
나머지 콘텐츠와 화면 구성은 유지하세요.

목표는 콘텐츠의 존재감을 해치지 않는 가볍고 정돈된 내비게이션입니다.

현재 하단 메뉴의 큰 아이콘, 강한 흰색 윤곽과 넓게 퍼진 배경 처리를 줄이세요.
하단 영역은 앱 배경과 자연스럽게 이어지는 평평한 어두운 면으로 표현하세요. 떠 있는 캡슐, 유리 효과, 그림자와 발광은 사용하지 마세요.

홈, 탐색, 라이브, 보관함, MY의 다섯 목적지는 유지하세요.
아이콘은 하나의 조형 규칙으로 다시 그리세요. 선 굵기와 시각적인 크기를 맞추고 세부 묘사를 줄이세요.
아이콘 아래의 짧은 라벨은 유지하되 아이콘보다 조용하게 표현하세요.

선택된 홈만 밝은 채움 아이콘과 밝은 라벨로 구분하세요.
나머지는 읽을 수 있는 중간 명도의 회색으로 표현하세요.
선택 표시를 위한 별도 바탕, 테두리, 빛 번짐은 추가하지 마세요.

아이콘과 라벨 사이, 메뉴 항목 사이의 간격을 정밀하게 맞추세요.
전체 높이는 지금보다 간결하게 조정하되 화면 가장자리와의 여유, 누르기 편한 공간은 유지하세요.
단순히 모든 요소를 작게 만드는 방식으로 해결하지 마세요.

수정된 앱 화면 한 장만 출력하세요.
```

## P05

같은 지적에 대해 제공한 재생 조작부 수정 요청. 대상은 당시 사용자 첨부의 세로 재생 화면이다. 이 요청의 보존 지시가 최종 이미지에서 모두 유지되지는 않았다.

```text
첨부한 비디오 앱의 하단 재생 조작부를 다시 디자인하세요.
영상 장면, 상단 제목과 탐색 영역은 유지하세요.

목표는 영상 위에 필요한 조작만 가볍게 드러나는 현대적인 플레이어입니다.
주요 재생 조작과 보조 설정의 시각적 중요도를 분명히 나누세요.

주 재생 조작:
중앙 일시정지와 양옆의 10초 이동을 하나의 중심 그룹으로 구성하세요.
현재 일시정지 버튼의 크고 두꺼운 회색 원형 바탕을 제거하세요.
명확한 흰색 일시정지 기호를 중심으로 하고, 배경과 구분이 필요한 경우에만 작은 반투명 바탕을 사용하세요.
10초 이동은 단정한 회전 화살표 안에 숫자 10을 넣으세요. 그 아래의 ‘10초 뒤로’, ‘10초 앞으로’ 설명은 제거하세요.
이전 장면과 다음 회는 중심 그룹 바깥에 더 낮은 강조도로 배치하세요.
모든 조작을 같은 크기와 밝기로 표현하지 마세요.

진행 표시:
진행 막대는 얇고 선명하게 표현하고 손잡이는 지금보다 절제된 크기로 조정하세요.
현재 시간과 전체 시간은 막대 양 끝에 정렬하고 보조 정보의 크기와 밝기로 표현하세요.
18:42 / 45:00과 이에 맞는 진행 위치를 유지하세요.

보조 설정:
화면비, 속도, 에피소드, 음성/자막을 감싼 큰 둥근 패널을 제거하세요.
각 기능을 배경 없는 짧은 텍스트 또는 간결한 아이콘으로 한 줄에 정렬하세요.
‘1.0x’ 아래에 다시 ‘속도’를 적는 식의 중복 설명을 없애세요.
구획을 나누는 세로선 대신 충분한 간격으로 묶음을 구분하세요.
보조 설정은 주 재생 조작보다 작고 차분하게 표현하되 읽기 어려울 정도로 흐리게 하지 마세요.

배경 처리는 조작부 전체를 받쳐주는 부드러운 어두운 그라데이션 하나로 정리하세요.
버튼별 그림자, 입체적인 테두리, 광택과 유리 패널을 추가하지 마세요.
아이콘의 선 굵기와 시각적 크기를 통일하고, 얇게 만드는 것만으로 세련됨을 표현하지 마세요.

수정된 앱 화면 한 장만 출력하세요.
```

## 확인되지 않은 생성 입력

최종 가로 재생 화면을 만들 때 사용한 별도 프롬프트는 제공받지 않았다. 입력 기록을 추후 받으면 그 출처를 표시해 추가한다. P05가 그대로 가로 화면을 만들었다고 연결하지 않는다.

실제 입력 전문, 모델과 설정이 없으므로 이 기록만으로 같은 이미지를 재현할 수 있다고 보장하지 않는다. 이 기록은 다음 탐색에서 작성 방식과 수정 과정을 참고하기 위한 자료다.
