# FRAME 컬렉션 상세 화면 프롬프트 기록

선택 시점의 컬렉션 상세 생성과 수정 요청을 보존한다. P05와 P06은 에이전트가 제공한 문장이고 P07은 사용자가 실제 추가 입력으로 보고한 문장이다. 전체 입력 전문과 생성 도구의 실행 로그는 확인하지 않았다.

홈의 탐색 및 수정 과정과 후속 준비안은 [두 번째 묶음 작업 문서](../../../docs/prompts/reference-set-002.md)에 있다. 아래 번호는 해당 문서와의 대응을 유지한다. 홈과 재생 화면을 이 버전의 선택 결과로 포함하지 않는다.

## P05

글꼴과 밀도를 수정한 FRAME 홈을 첨부하고 사용한다. 첫 FRAME 홈이나 SCENE 화면을 참조 이미지로 혼합하지 않는다.

```text
첨부한 이미지는 FRAME이라는 개인 영화 컬렉션 앱의 홈 화면입니다.
홈에서 ‘도시의 밤’ 컬렉션을 눌러 들어간 상세 화면을 디자인해 주세요.

목표:
내가 모아둔 영화들을 편안하게 살펴보고 지금 감상할 한 편을 고르는 화면입니다.
홈과 같은 앱이라는 느낌을 유지하면서, 작품들을 한 묶음으로 탐색하는 경험을 보여주세요.
기존 프로젝트의 구현 기능이나 기술 제약은 고려하지 마세요.

화면 구성:
상단에는 돌아가기, 컬렉션 제목 ‘도시의 밤’, 작품 수 ‘12편’을 간결하게 배치하세요.
컬렉션의 분위기를 보여주는 이미지가 필요하면 작게 활용하세요. 큰 대표 장면으로 화면 대부분을 차지하지 말고 작품 목록이 일찍 보이게 하세요.
그 아래에는 여유 있는 두 열의 작품 목록을 구성하세요. 12편을 한 화면에 전부 넣지 말고 아래로 자연스럽게 이어지게 하세요.
작품을 고르거나 재생하는 행동이 분명해야 합니다. 정렬이나 컬렉션 관리 같은 보조 기능은 필요한 만큼만 조용하게 배치하세요.
홈의 다른 추천 구역과 탐색 메뉴 전체를 이 화면에 반복하지 마세요.

콘텐츠:
도시의 밤을 배경으로 하는 가상의 영화들을 구성하세요. 빗속의 거리뿐 아니라 심야 열차, 불이 켜진 아파트, 늦은 퇴근길 등 서로 다른 장면으로 묶음의 분위기를 표현하세요.
‘잔광의 거리’를 포함하고 홈에서 보인 작품의 이미지 정체성을 이어받으세요. 이 작품의 상영 시간은 127분입니다.
각 작품은 이미지와 제목을 중심으로 표현하고, 보조 정보는 짧게 정리하세요. 작품마다 줄거리, 배지와 여러 버튼을 반복하지 마세요.

글자와 밀도:
첨부 홈의 장식 없는 글꼴을 이어받고 제목, 작품 이름과 보조 정보를 크기와 굵기로 구분하세요.
명조체, 붓글씨와 과도한 자간을 추가하지 마세요.
콘텐츠를 많이 담으려고 글자를 줄이지 말고 한 번에 보여주는 작품 수를 조절하세요.
목록 안의 간격과 제목 주변 여백을 충분히 확보하되, 의미 없는 빈 공간 때문에 작품 탐색이 뒤로 밀리지 않게 하세요.

시각적 일관성:
홈의 어두운 배경, 절제된 색상, 아이콘과 모서리 표현을 이어받으세요.
작품 이미지의 색과 분위기는 살리고 버튼은 주요 행동에만 강조를 주세요.
두꺼운 패널, 겹친 사진 장식, 금속성 광택과 발광을 추가하지 마세요.

출력:
첨부 홈과 같은 세로 비율의 실제 앱 화면 한 장을 생성하세요.
화면을 정면에서 보여주고 이미지 전체를 채우세요. 기기 목업, 설명 주석과 화면 밖 배경은 제외하세요.
```

## P06

두 열 컬렉션 결과를 첨부해 한 작품이 한 줄을 차지하는 목록형 대안을 요청하도록 제공한 문장이다.

```text
첨부한 FRAME 컬렉션 상세 화면을 한 작품이 한 줄을 차지하는 목록형으로 다시 디자인해 주세요.

기존 두 열 화면과 비교할 대안입니다.
‘도시의 밤’이라는 컬렉션, 작품 수 12편, 기존 작품의 제목과 이미지, 장르와 상영 시간은 유지하세요.

작품 목록:
각 행의 왼쪽에는 충분한 크기의 가로형 썸네일을 두고, 오른쪽에는 작품 제목과 짧은 정보를 배치하세요.
제목과 정보는 이미지 밖에 두어 편안하게 읽히도록 하세요.
제목이 먼저 읽히고 장르와 상영 시간은 그 아래에서 조용하게 받쳐주게 하세요.
재생 동작은 쉽게 찾을 수 있어야 하지만 모든 행의 버튼이 작품보다 눈에 띄지 않게 하세요.

밀도:
행 사이에 충분한 간격을 두세요.
많은 작품을 한 화면에 넣기 위해 이미지나 글자를 줄이지 마세요.
아래로 스크롤하며 남은 작품을 살펴보는 화면으로 구성하세요.
각 행을 두꺼운 카드 바탕이나 테두리로 둘러싸지 말고 정렬과 간격으로 구분하세요.

상단:
돌아가기, 컬렉션 제목과 작품 수를 유지하세요.
도시 야경은 컬렉션의 분위기를 전달할 만큼만 사용하고 작품 목록을 지나치게 아래로 밀지 않게 하세요.

스타일:
기존 화면의 어두운 배경, 단정한 글꼴, 절제된 아이콘과 색상을 이어받으세요.
새로운 배지, 줄거리, 장식과 보기 전환 버튼은 추가하지 마세요. 이번에는 목록형 자체의 완성도를 비교합니다.

기존 이미지와 같은 세로 비율로 앱 화면 한 장을 생성하세요.
```

## P07

사용자가 목록형 첫 결과에 실제로 사용한 추가 프롬프트라고 보고한 문장이다. 사용자 첨부 두 장 중 첫 장이 수정 전, 두 번째 장이 수정 후다. 생성 모델과 설정은 미확인이다.

```text
썸네일 너비가 너무 넓고 각 회차간의 간격이 너무 좁습니다
```
