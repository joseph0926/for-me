# 레퍼런스 묶음

사용자가 선택한 화면과 원본 이미지, 프롬프트 기록을 함께 보관한다. 로컬 MCP의 `get_reference_set`과 `get_reference`로 묶음 정보와 PNG 원본을 조회할 수 있다. 웹 갤러리와 검색은 아직 구현하지 않았다.

| 묶음 | 버전 | 화면 | 선택 상태 |
|---|---|---|---|
| [SCENE 비디오 앱](scene-001/v1/README.md) | 1 | 홈, 세로 재생, 가로 재생 | 2026-11-17 사용자 선택 |
| [FRAME 도시의 밤 컬렉션](frame-002/v1/README.md) | 1 | 목록형 컬렉션 상세 | 2026-11-17 두 번째 목록형 선택. 다른 화면은 미포함 |

각 묶음의 README는 화면과 선택 맥락을, `prompts.md`는 제공한 프롬프트를, `manifest.json`은 식별자와 이미지 파일 정보를 기록한다. 서버는 `manifest.json`과 설명 파일을 읽어 응답을 구성한다. 입력과 응답 형식은 [MCP 조회 계약](../docs/mcp.md), 실제 전달과 구현 활용 범위는 [검증 기록](../docs/verification.md)에 있다.

등록한 버전의 이미지를 교체하지 않는다. 이후 시안은 새 버전으로 보존한다. 원본 파일명은 메타데이터에 남기고 저장소 파일명에는 영문을 사용한다.
