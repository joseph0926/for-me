# 레퍼런스 묶음

사용자가 선택한 화면과 원본 이미지, 프롬프트 기록을 함께 보관한다. 현재는 로컬 자료이며 갤러리와 MCP 조회 기능은 아직 구현하지 않았다.

| 묶음 | 버전 | 화면 | 선택 상태 |
|---|---|---|---|
| [SCENE 비디오 앱](scene-001/v1/README.md) | 1 | 홈, 세로 재생, 가로 재생 | 2026-11-17 사용자 선택 |
| [FRAME 도시의 밤 컬렉션](frame-002/v1/README.md) | 1 | 목록형 컬렉션 상세 | 2026-11-17 두 번째 목록형 선택. 다른 화면은 미포함 |

각 묶음의 README는 화면과 선택 맥락을, `prompts.md`는 제공한 프롬프트를, `manifest.json`은 식별자와 이미지 파일 정보를 기록한다. `manifest.json`은 현재 파일 보관용 형식이며 확정된 MCP 응답 규격이 아니다.

등록한 버전의 이미지를 교체하지 않는다. 이후 시안은 새 버전으로 보존한다. 원본 파일명은 메타데이터에 남기고 저장소 파일명에는 영문을 사용한다.
