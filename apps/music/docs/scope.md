# 음악 앱

## 목표

평소 사용하는 음악 앱을 대체해 직접 쓰고 유지보수합니다. 휴대폰에 저장한 음악 파일을 재생합니다.

## 구현 범위

- Android를 먼저 개발합니다.
- 기술 선택의 근거와 조사 결과는 [기술 조사](research.md)에 있습니다. 재생 엔진은 2026-11-28에 Media3로 조건부 채택했고, [확정 조건](research.md#검증-결과와-남은-조건)을 검증한 뒤 확정합니다.
- 사용자의 음악 파일과 태그는 읽기만 하고 수정하거나 삭제하지 않습니다.

## 할 일

- [ ] **안드로이드 음악 플레이어 앱 만들기.** 2026-11-28 사용자 요청: "이 레포 할일에 안드로이드 음악 플레이어앱 만들기 등록". 기술 조사는 끝났습니다. 재생 엔진을 확정하고, 첫 버전의 기능과 완료 기준을 이 문서에 적은 뒤 구현합니다. 완료 기준 제안(AI 해석, 사용자 미확정): 실제 휴대폰에서 화면을 끄거나 다른 앱으로 가도 재생이 이어지고, 알림과 잠금 화면에서 조작되며, 앱을 업데이트한 뒤에도 재생 목록과 재생 위치가 남습니다.
  - 2026-11-28 진행: 사용자가 권장안(Media3)으로 하되 최선인지 검증이 필요하다고 했습니다. Android 14 가상 기기 실험에서 화면 밖 재생 유지와 FLAC, MP3, AAC의 곡 사이 끊김 없음을 확인했고, Opus 틈과 ALAC 미재생을 찾았습니다([검증 기록](verification.md#2026-11-28-media3-가상-기기-최소-실험)). 남은 것: Android 17 가상 기기 검사(SDK 37 플랫폼과 이미지 설치 필요), 사용자 음악 파일 형식 확인, 그 뒤 엔진 확정.
