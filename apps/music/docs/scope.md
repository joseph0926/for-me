# 음악 앱

## 목표

평소 사용하는 음악 앱을 대체해 직접 쓰고 유지보수합니다. 휴대폰에 저장한 음악 파일을 재생합니다.

## 구현 범위

- Android를 먼저 개발합니다.
- 기술 선택의 근거와 조사 결과는 [기술 조사](research.md)에 있습니다. 재생 엔진은 2026-11-28에 Media3로 조건부 채택했고, [확정 조건](research.md#검증-결과와-남은-조건)을 가상 기기와 파일 형식 기준으로 충족한 뒤 같은 날 사용자가 확정했습니다.
- 사용자의 음악 파일과 태그는 읽기만 하고 수정하거나 삭제하지 않습니다.

## 첫 버전의 목표

2026-11-28 AI 초안을 사용자가 확정했습니다(사용자 결정: "이대로 확정"). 사용자 음악의 [형식 확인](verification.md#2026-11-28-사용자-음악-파일의-형식-확인) 결과와 화면 레퍼런스 [속지](../../today-ref/works/2026-11-28-music/README.md)를 바탕으로 했습니다.

### 음악 목록

- 처음 열 때 음악 접근 권한을 요청하고, 휴대폰의 곡을 한 목록으로 보여 줍니다. 이름 검색과 이름순, 추가한 날짜순 정렬을 둡니다.
- 목록에 나오지 않는 곡은 시스템 파일 선택기로 직접 추가합니다. [기술 조사](research.md#음악-파일-접근)에 따르면 다른 앱이 받은 `Download` 안의 파일은 이 경로가 필요할 수 있습니다.
- 사용자 음악의 아티스트 태그가 모두 영상을 올린 채널 이름이라, 아티스트와 앨범으로 묶는 보관함은 첫 버전에서 뺍니다.
- 곡 이름은 확장자를 뺀 파일 이름으로 보여 주고, 태그 제목은 재생 화면에 보조로 둡니다. 2026-11-28 사용자 결정: "파일 이름으로". 태그 제목은 "가수 - 곡명 | 공연 날짜" 같은 영상 제목이라 목록에서 깁니다. 12곡 중 1곡은 파일 이름에 곡명이 없어(`Lyrics Video   -  .mp3`) 이 방식으로는 곡을 알아볼 수 없습니다.

### 재생

- 곡을 누르면 그 목록 순서대로 이어서 재생합니다. 일시정지, 이전 곡, 다음 곡, 진행 막대로 위치 이동, 셔플, 한 곡 반복과 전체 반복을 둡니다.
- 화면 아래에 미니 플레이어를 두고, 끌어 올리면 커버, 제목, 진행 막대가 있는 재생 화면이 열립니다. 재생 화면에서 다음 곡 대기열을 보고 순서를 바꾸거나 뺍니다.
- 화면을 끄거나 다른 앱으로 가도 재생이 이어지고, 알림과 잠금 화면에서 조작합니다. 이어폰이 빠지거나 블루투스가 끊기면 멈추고, 전화나 다른 앱의 소리가 끼어들면 잠시 멈춥니다.

### 재생 목록

- 재생 목록을 만들고, 이름을 바꾸고, 곡을 넣고 빼고, 순서를 바꾸고, 지웁니다. 재생 목록은 앱 데이터에만 저장하고 음악 파일에는 쓰지 않습니다.

### 이어듣기

- 대기열, 현재 곡, 재생 위치를 저장해 앱을 닫았다 열면 그 상태로 돌아옵니다. 다시 열 때 저절로 재생하지는 않습니다.

### 첫 버전에서 빼는 것

- 가사: 사용자 음악 12곡에 가사 태그가 없습니다.
- 홈의 추천 곡: 서버 데이터가 필요합니다.
- 재부팅 뒤 시스템 이어듣기 알림, Android Auto: `MediaLibraryService` 구현이 필요합니다([기술 조사](research.md#media3-백그라운드-재생-구조)).
- 태그 편집, 음악 파일 삭제, Windows와 macOS 버전

### 완료 기준

실제 휴대폰에서 확인하고, 기기 모델, Android 버전, 앱 빌드를 함께 남깁니다. 가상 기기 결과만으로는 통과 처리하지 않습니다.

1. 사용자 음악 12곡이 목록에 나오고 모두 소리가 납니다.
2. 화면을 끄거나 다른 앱으로 간 동안 재생이 이어지고 다음 곡으로 넘어갑니다. 알림과 잠금 화면에서 일시정지, 재개, 다음 곡이 됩니다.
3. 이어폰을 빼거나 블루투스가 끊기면 재생이 멈춥니다.
4. 곡 중간에 앱을 닫고 다시 열면 같은 대기열의 같은 곡이 저장한 위치에서 이어집니다.
5. 재생 목록과 재생 위치가 있는 상태에서 새 빌드를 덮어 설치해도 둘 다 남습니다.
6. 음악 권한을 거절하거나 파일 선택을 취소하면 이유를 알리고 다시 허용하는 길을 보여 줍니다. 재생 목록의 곡 파일이 옮겨지거나 지워지면 그 곡을 재생할 수 없다고 표시하고 나머지 곡은 재생됩니다.
7. 헤더 길이보다 실제 소리가 짧은 곡에서 실제 끝에 다음 곡으로 넘어가고, 저장 위치가 실제 길이를 넘어도 재생이 멈춰 버리지 않습니다.
8. 사용 전후에 음악 파일의 크기와 수정 시각이 같습니다.
9. 자동 검사: Android 17 가상 기기의 강제 오류 모드에서 화면 밖 재생, 일시정지 뒤 재개 동안 위반 기록이 없습니다([검사 방법](research.md#android-17의-백그라운드-오디오-제한)).

### 확인할 것

- 휴대폰에서 음악이 있는 폴더와 이 12곡 밖의 음악 유무. 첫 기능 구현 뒤 가상 기기에서 그 폴더의 곡이 음악 목록에 나오는지 먼저 봅니다.
- 테스트 기기가 [장면](../../video/docs/scope.md#테스트-기기)과 같은지, 그 기기의 Android 버전
