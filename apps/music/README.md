# 음악 앱

휴대폰에 저장한 음악 파일을 재생하는 Android 앱입니다. 앱 이름과 앱 식별자는 아직 정하지 않았습니다.

공통 개발 절차는 [개발 절차](../../docs/development.md), 조작과 증거 수집 방법은 [QA 절차](../../docs/qa.md)를 따릅니다.

## 현재 상태

2026-11-28 기준으로 착수 전입니다. 기술 조사를 마쳤고 재생 엔진은 정하지 않았습니다. 코드와 빌드 설정은 없습니다.
