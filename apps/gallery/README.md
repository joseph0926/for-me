# 갤러리 앱

휴대폰에 저장한 사진과 영상을 보는 Android 앱입니다. 앱 이름과 앱 식별자는 아직 정하지 않았습니다.

공통 개발 절차는 [개발 절차](../../docs/development.md), 조작과 증거 수집 방법은 [QA 절차](../../docs/qa.md)를 따릅니다.

## 현재 상태

2026-11-28 기준으로 착수 전입니다. 기술 조사를 마쳤고 사진 목록을 읽는 방식과 화면 기술은 정하지 않았습니다. 코드와 빌드 설정은 없습니다.

## 문서

- [범위](docs/scope.md): 목표와 할 일
- [기술 조사](docs/research.md): 사진과 영상 읽기 권한(부분 허용 포함), Google Play 사진 권한 정책, MediaStore 휴지통 요청, 썸네일 성능, 참고할 오픈소스 갤러리
