# 갤러리 앱

## 목표

평소 사용하는 갤러리 앱을 대체해 직접 쓰고 유지보수합니다. 휴대폰에 저장한 사진과 영상을 봅니다.

## 구현 범위

- Android를 먼저 개발합니다.
- 기술 선택의 근거와 조사 결과는 [기술 조사](research.md)에 있습니다. 사진 목록을 읽는 방식, 화면 기술과 이미지 로더는 아직 정하지 않았습니다.
- 사용자의 사진과 영상 원본을 수정하지 않습니다. 삭제는 사용자가 시스템 확인 창에서 승인한 경우에만 하고, 기본은 휴지통으로 옮기는 것입니다.
