# 갤러리 앱

## 목표

평소 사용하는 갤러리 앱을 대체해 직접 쓰고 유지보수합니다. 휴대폰에 저장한 사진과 영상을 봅니다.

## 구현 범위

- Android 14 이상을 대상으로 먼저 개발합니다.
- 기술 선택의 근거와 조사 결과는 [기술 조사](research.md)에 있습니다. 2026-11-28에 [개발 스택](research.md#개발-스택)을 정했습니다. 미디어 관리 권한은 [최소 실험](research.md#착수-전-최소-실험)을 Android 14와 17 가상 기기에서 통과했고, 실제 휴대폰 확인이 남았습니다([검증 기록](verification.md)).
- 사용자의 사진과 영상 원본을 수정하지 않습니다. 삭제는 사용자가 시스템 확인 창이나 미디어 관리 권한으로 승인한 경우에만 하고, 기본은 휴지통으로 옮기는 것입니다.
- 화면은 [오늘의레퍼런스](../../today-ref/README.md)의 `2026-11-28-gallery-app` 완성작을 참고합니다.

## 첫 버전

넣는 기능(AI 제안, 사용자 미확정. 시안에서 뺄 기능만 사용자가 정했습니다):

- 보관함: 날짜로 쌓인 사진과 영상 격자, 연, 월, 일, 전체 단위 전환
- 사진 보기: 좌우 넘기기, 두 번 눌러 확대와 끌어 옮기기, 아래로 끌어 닫기, 영상 재생
- 사진 정보: 촬영 시각, 파일 이름, 형식, 해상도, 용량, 카메라와 노출. 위치 줄은 숨깁니다
- 선택: 길게 눌러 여러 장 고르기, 즐겨찾기, 앨범에 추가, 휴지통
- 앨범: 기기 폴더와 앱에서 만든 앨범, 새 앨범
- 최근 삭제됨: 되돌리기와 영구 삭제
- 검색: 날짜, 앨범, 파일 이름
- 권한: 전체 허용, 부분 허용, 거절마다 다른 안내와 사진을 더 허용하는 경로

뺀 기능(2026-11-28 사용자 결정: "장소 이름, 주제 검색, 추억"):

- 장소 이름: GPS 좌표를 이름으로 바꾸려면 네트워크와 Google 서비스가 필요합니다.
- 주제 검색: "바다", "산" 같은 검색은 기기 안의 사진 분류 모델이 필요합니다.
- 추억: 사진을 묶는 규칙을 새로 정해야 합니다.
