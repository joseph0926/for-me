# 대시보드 웹

- 주제 id: `2026-11-18-dashboard`
- 플랫폼: 웹
- 가상 제품: 웹 분석 도구 안의 "소담책방" 작업 공간. 사이트는 소담책방 스토어(`sodambook.kr`), 작가 파트너센터, 소담 매거진 세 개이고 데이터는 모두 지어낸 값이다. 시각은 2026년 11월 18일 14:37 KST로 고정했다.

## 레퍼런스별로 가져온 것과 가져오지 않은 것

### r4 Vercel 웹 분석 개요

- 가져온 것: 지표 4개(방문자, 페이지뷰, 이탈률, 평균 체류 시간)를 탭처럼 나란히 두고 고른 칸 아래 밑줄로 바로 아래 영역 그래프와 연결한 구조. 숫자 옆 초록과 빨강 배경의 증감 알약. 아직 끝나지 않은 마지막 구간(30일은 오늘, 7일은 현재 3시간 묶음, 24시간은 현재 시간대)을 점선으로 이어 그리는 표현. 목록 끝 행을 흐리게 하고 그 위에 "모두 보기"를 겹치는 처리.
- 가져오지 않은 것: 흰 바탕과 파란 그래프 색, 제품 이름과 로고, 환경 선택(Production)과 더보기 버튼, 서체.

### r1 Plausible 공개 대시보드

- 가져온 것: 두 열 목록 카드 그리드, 카드 머리의 탭(채널, 출처, 캠페인 / 상위 페이지, 진입 페이지, 이탈 페이지 등)과 밑줄로 표시한 선택 탭, 값에 비례한 막대를 행 뒤에 깔고 숫자는 오른쪽 끝에 맞춘 행. 목록 행을 눌러 대시보드 전체에 필터를 거는 흐름.
- 가져오지 않은 것: 보라색 강조색, 지도 카드, 대문자 탭 이름, 제품 이름과 로고.

### r3 Linear 대시보드

- 가져온 것: 거의 검은 바탕에 회색 글자를 기본으로 두고 색은 그래프, 증감 알약, 접속 중 점에만 쓰는 조용한 색 사용. 왼쪽 사이드바(그룹 이름 아래 항목), 이동 경로가 있는 맨 위 줄, 큰 제목과 필터 줄로 이어지는 페이지 머리. 점선 가로 격자.
- 가져오지 않은 것: 보라와 파랑 계열 브랜드 색, 작업 공간과 팀 이름, 아이콘 세트, 서체, 설명 입력 자리와 "인사이트 추가" 버튼.

강조색은 세 제품 어디에도 없는 낮은 채도의 호박색(`#d9a24e`) 하나만 쓰고, 서체는 Pretendard를 쓴다.

## 동작

- 지표 탭을 누르면 아래 그래프가 그 지표로 바뀐다. 같은 기간 안에서는 선이 이어서 변한다.
- 오른쪽 위 기간 선택(최근 24시간, 7일, 30일)이 그래프, 합계, 증감, 목록을 모두 바꾼다. 증감은 바로 앞 같은 길이의 기간과 비교하고 이탈률은 %p로 보여 준다. 그래프 점은 24시간은 1시간, 7일은 3시간, 30일은 하루 단위이고 축 눈금은 7일과 30일에서 날짜만 단다.
- 그래프 위에 포인터를 올리면 세로선과 함께 날짜와 시간대(24시간은 시각, 7일은 09:00–12:00 같은 3시간 범위)와 값이 뜬다. 마지막 점에는 "집계 중"이 붙는다.
- 목록 카드의 탭으로 차원을 바꾸고, "모두 보기"로 카드를 펼치거나 접는다.
- 목록 행을 누르면 그 값이 필터 칩으로 더해지고 대시보드 전체가 그 조건으로 다시 계산된다. 칩의 ×로 지운다. "필터" 버튼에서 차원을 고르고 값을 검색해 더할 수도 있다. 출처와 캠페인은 채널에, 지역은 국가에 속해서 서로 어긋나는 필터는 자동으로 빠진다.
- 사이드바의 세 사이트는 각자 다른 데이터로 같은 대시보드를 보여 주고, 사이트를 바꾸면 필터를 비운다. 알림, 전환 목표, 정기 리포트는 빈 상태 화면이다.
- 1024px 아래에서는 사이드바가 접히고 맨 위 줄의 메뉴 버튼으로 서랍을 연다.

## 상태로 가는 방법

새로고침 직후 기준입니다. 활용할 때 이 줄로 바로 그 상태를 띄웁니다.

- r4 지표 전환: 지표 탭 줄에서 "페이지뷰" 누르기, 밑줄이 옮겨 가고 그래프 선이 이어서 바뀜
- r4 기간 변경: 필터 줄 오른쪽 "최근 7일"에서 "최근 30일", 합계, 증감, 그래프, 목록이 함께 바뀜
- r4 집계 중 툴팁: 그래프 맨 오른쪽 점(점선 끝) 위에 포인터 올리기, 세로선과 "집계 중"
- r1 목록 탭과 모두 보기: 첫 목록 카드의 "출처" 탭, 둘째 목록 카드 아래 "모두 보기"와 "접기"
- r1 행 눌러 필터: 첫 목록 카드의 첫 행 누르기, 필터 칩이 생기고 전체가 다시 계산됨. 칩의 ×(`채널 필터 제거`)로 지움
- r3 필터 메뉴: 필터 줄 "필터", "출처", "출처 검색" 칸에 `naver`, 결과를 눌러 칩 더하기
- r3 사이트 전환과 접속 중 숫자: 사이드바 "작가 파트너센터", 데이터가 바뀌고 필터가 비워짐. 제목 아래 접속 중 숫자는 4초마다 바뀜
- r3 서랍 메뉴: 1023px 이하에서 맨 위 "메뉴 열기", 사이드바가 왼쪽에서 나옴
