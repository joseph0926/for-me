# 대시보드 웹

- 주제 id: `2026-11-18-dashboard`
- 플랫폼: 웹
- 가상 제품: 웹 분석 도구 안의 "소담책방" 작업 공간. 사이트는 소담책방 스토어(`sodambook.kr`), 작가 파트너센터, 소담 매거진 세 개이고 데이터는 모두 지어낸 값이다. 시각은 2026년 11월 18일 14:37 KST로 고정했다.

## 레퍼런스별로 가져온 것과 가져오지 않은 것

### r4 Vercel 웹 분석 개요

- 가져온 것: 지표 4개(방문자, 페이지뷰, 이탈률, 평균 체류 시간)를 탭처럼 나란히 두고 고른 칸이 바로 아래 영역 그래프를 정하는 구조. 숫자 옆 초록과 빨강 증감 표시. 아직 끝나지 않은 마지막 구간(30일은 오늘, 7일은 현재 3시간 묶음, 24시간은 현재 시간대)을 점선으로 이어 그리는 표현. 2026-11-26 tastepin 다듬기에서 고른 칸의 밑줄은 옅은 면으로, 증감 알약은 화살표와 색 글자로 바꾸고, 목록 끝 행을 흐리게 하고 "모두 보기"를 겹치던 처리는 카드 아래 글자 버튼 줄로 바꿨다.
- 가져오지 않은 것: 흰 바탕과 파란 그래프 색, 제품 이름과 로고, 환경 선택(Production)과 더보기 버튼, 서체.

### r1 Plausible 공개 대시보드

- 가져온 것: 두 열 목록 카드 그리드, 카드 머리의 탭(채널, 출처, 캠페인 / 상위 페이지, 진입 페이지, 이탈 페이지 등)과 밑줄로 표시한 선택 탭, 값에 비례한 막대와 오른쪽 끝에 맞춘 숫자. 목록 행을 눌러 대시보드 전체에 필터를 거는 흐름. 막대는 행 뒤에 깔던 것을 2026-11-26 tastepin 다듬기에서 이름 아래 가는 막대로 바꿨다.
- 가져오지 않은 것: 보라색 강조색, 지도 카드, 대문자 탭 이름, 제품 이름과 로고.

### r3 Linear 대시보드

- 가져온 것: 거의 검은 바탕에 회색 글자를 기본으로 두고 색은 그래프, 증감 알약, 접속 중 점에만 쓰는 조용한 색 사용. 왼쪽 사이드바(그룹 이름 아래 항목), 이동 경로가 있는 맨 위 줄, 큰 제목과 필터 줄로 이어지는 페이지 머리. 점선 가로 격자.
- 가져오지 않은 것: 보라와 파랑 계열 브랜드 색, 작업 공간과 팀 이름, 아이콘 세트, 서체, 설명 입력 자리와 "인사이트 추가" 버튼.

강조색은 세 제품 어디에도 없는 낮은 채도의 호박색(`#d9a24e`) 하나만 쓰고, 서체는 Pretendard를 쓴다.

## 동작

- 지표 탭을 누르면 고른 칸의 옅은 면이 옮겨 가고 아래 그래프가 그 지표로 바뀐다. 같은 기간 안에서는 선이 이어서 변한다.
- 오른쪽 위 기간 세 칸(24시간, 7일, 30일)이 그래프, 합계, 증감, 목록을 모두 바꾼다. 지표 숫자는 늘면 아래에서, 줄면 위에서 넘어온다. 증감은 바로 앞 같은 길이의 기간과 비교해 ▲와 ▼로 보여 주고, 색은 좋아지면 초록, 나빠지면 빨강이다. 이탈률은 %p로 보여 준다. 그래프 점은 24시간은 1시간, 7일은 3시간, 30일은 하루 단위이고 축 눈금은 7일과 30일에서 날짜만 단다.
- 그래프 위에 포인터를 올리면 세로선과 함께 날짜와 시간대(24시간은 시각, 7일은 09:00–12:00 같은 3시간 범위)와 값이 뜬다. 마지막 점에는 "집계 중"이 붙는다.
- 목록 카드는 처음 6행을 보여 주고(7행이면 다 보여 준다), 탭으로 차원을 바꾸면 같은 자리의 막대가 새 길이로 이어서 바뀐다. 카드 아래 "n개 모두 보기"로 펼치고 "접기"로 접는다.
- 목록 행을 누르면 그 값이 필터 칩으로 더해지고 대시보드 전체가 그 조건으로 다시 계산된다. 칩의 ×로 지운다. "필터" 버튼에서 차원을 고르고 값을 검색해 더할 수도 있다. 출처와 캠페인은 채널에, 지역은 국가에 속해서 서로 어긋나는 필터는 자동으로 빠진다.
- 사이드바의 세 사이트는 각자 다른 데이터로 같은 대시보드를 보여 주고, 사이트를 바꾸면 필터를 비운다. 알림, 전환 목표, 정기 리포트는 빈 상태 화면이다.
- 1024px 아래에서는 사이드바가 접히고 맨 위 줄의 메뉴 버튼으로 왼쪽 서랍을 연다.
- 맨 위 줄은 늘 고정이고, 스크롤하면 아래에 그림자가 생긴다.

## tastepin 다듬기에서 고친 것 (2026-11-26 소급)

이 완성작은 진행 절차에 tastepin 다듬기 단계가 생기기 전(2026-11-22)에 만들어, 2026-11-26에 소급해 다듬었습니다. 완성작 폴더에서 받은 취향의 분석 대시보드 시편 값(지표 탭과 그래프, 막대 배경 목록 카드)과 규칙을 따랐고, 이 폴더의 색과 서체 토큰과 제목 표현은 바꾸지 않았습니다.

- 지표 탭: 고른 칸 아래 밑줄을 지우고 강조색을 8% 섞은 면을 깔았으며, 고른 지표의 숫자는 강조색으로 둡니다. 면은 스프링(0.25초, 탄성 0.15)으로 옮겨 갑니다. 탭 줄과 그래프 사이의 선도 지웠습니다(지표 탭 값: 바탕 면, 강조색).
- 증감: 초록과 빨강 면의 알약을 지우고 "▲ 27%"처럼 화살표와 12px 색 글자만 둡니다. 화면 읽기에는 증가와 감소, 좋아짐과 나빠짐을 말로 읽힙니다(지표 탭 값: 색 글자와 화살표). r4에서 가져온 알약 모양보다 이 자리에서 고른 취향 값을 앞세웠습니다.
- 목록 카드: 행 뒤에 깔던 막대를 40px 행의 이름 아래 3px 강조색 막대로 바꾸고, 8행과 흐린 끝 행 위에 겹친 "모두 보기" 버튼(최대화 화살표 아이콘)을 처음 6행과 카드 아래 1px 선 뒤의 "n개 모두 보기" 글자 버튼 줄로 바꿨습니다. 기준을 바꾸면 같은 자리의 막대가 300ms에 이어서 바뀝니다(막대 배경 목록 카드 값). 한 행만 남을 때는 펼치기 대신 7행을 다 보여 줍니다.
- 기간 선택: 세 값뿐인 단일 선택이 드롭다운 뒤에 숨어 있어, 필터 줄 오른쪽에 늘 보이는 세 칸(24시간, 7일, 30일)으로 바꿨습니다(규칙: 하나뿐인 선택을 드롭다운 팝업 뒤에 숨기지 않는다). "최근"이 세 번 반복되던 이름도 줄였습니다.
- 숫자: 기간이나 필터를 바꿀 때와 접속 중 숫자가 바뀔 때 숫자가 세로로 넘어갑니다(숫자 바뀜 값, 200ms).
- 맨 위 줄: 늘 있던 아래 선과 반투명 흐림을 지우고, 맨 위에서는 경계 없이 두다가 스크롤하면 그림자를 120ms에 깝니다(헤더 경계 값). 어두운 바탕이라 그림자는 시편보다 짙게 뒀습니다.
- 서랍: 스프링으로 들어오던 서랍을 곡선 220ms로 열고 같은 길로 닫으며, 폭을 76%(최대 300px)로 넓혔습니다(드로어 예외, 메뉴 여는 방식 값). 시편은 오른쪽 패널이지만 넓은 화면의 사이드바 자리를 이어 받으므로 왼쪽에서 엽니다.
- 사이드바: 마우스를 올린 항목에 현재 위치와 거의 같은 면이 깔려 선택처럼 보이던 것을 글자색만 바뀌게 했습니다.
- 모서리와 간격: 카드, 툴팁, 메뉴의 모서리를 12px와 8px에서 6px로 줄이고, 본문 폭을 1280px, 지표 묶음과 목록 묶음 사이를 28px, 목록 카드 사이를 20px로 넓혔습니다. 목록 행, 사이드바, 지표 이름은 13px에서 14px로 올렸습니다(화면 전체 값, 규칙: 한글 본문 14px 미만 금지).
- 모션: 필터 칩과 필터 메뉴가 흐림이 걷히며 220ms에 나타나고 같은 길로 사라지며, 작은 버튼은 누르는 동안 0.95배로 줄어듭니다(모션 기본값).
- 빈 상태: 점선 상자와 테두리 친 아이콘을 지우고 제목 아래에 굵은 한 줄과 15px 설명만 둡니다(규칙: 그룹은 여백과 글자 굵기로 나눈다).
- 결함: 그래프 툴팁의 7일 시간대와 "집계 중"이 "집계/중"처럼 두 줄로 갈라지던 것을 툴팁 폭을 넓혀 한 줄로 맞췄고, 필터 메뉴의 검색 입력에 강조색 상자가 늘 그려지던 것(초점 규칙이 outline-none을 덮음)을 고쳤습니다. 한글이 낱말 가운데서 줄을 바꾸지 않게 했습니다.

남긴 것: 카드의 1px 테두리와 카드 머리 아래 선은 남겼습니다. r1에서 가져온 목록 카드 구조이고, 이 자리의 시편도 테두리 있는 카드입니다. 사이트를 바꿀 때 내용이 옆으로 밀려 바뀌는 화면 전환은 새 동작이라 더하지 않았습니다.

## 상태로 가는 방법

새로고침 직후 기준입니다. 활용할 때 이 줄로 바로 그 상태를 띄웁니다.

- r4 지표 전환: 지표 탭 줄에서 "페이지뷰" 누르기, 옅은 면이 옮겨 가고 숫자가 강조색이 되며 그래프 선이 이어서 바뀜
- r4 기간 변경: 필터 줄 오른쪽 기간 세 칸에서 "30일", 지표 숫자가 세로로 넘어가고 증감, 그래프, 목록이 함께 바뀜
- r4 집계 중 툴팁: 그래프 맨 오른쪽 점(점선 끝) 위에 포인터 올리기, 세로선과 "집계 중"
- r1 목록 탭과 모두 보기: 첫 목록 카드의 "출처" 탭(막대가 새 길이로 이어서 바뀜), 둘째 목록 카드 아래 "20개 모두 보기"와 "접기"
- r1 행 눌러 필터: 첫 목록 카드의 첫 행 누르기, 필터 칩이 생기고 전체가 다시 계산됨. 칩의 ×(`채널 필터 제거`)로 지움
- r3 필터 메뉴: 필터 줄 "필터", "출처", "출처 검색" 칸에 `naver`, 결과를 눌러 칩 더하기
- r3 사이트 전환과 접속 중 숫자: 사이드바 "작가 파트너센터", 데이터가 바뀌고 필터가 비워짐. 제목 아래 접속 중 숫자는 4초마다 바뀜
- r3 서랍 메뉴: 1023px 이하에서 맨 위 "메뉴 열기", 사이드바가 왼쪽에서 곡선으로 나옴
- 맨 위 줄 그림자: 대시보드를 조금 스크롤하면 맨 위 줄 아래에 그림자가 생기고, 맨 위로 돌아오면 사라짐
