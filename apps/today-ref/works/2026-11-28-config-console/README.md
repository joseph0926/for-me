## 고른 이유

사용자가 운영용 프런트엔드 앱에서 뽑은 후보([collection-candidates.md](../../docs/collection-candidates.md))를 2026-11-28에 아홉 수집 주제로 모은 뒤 "이거 기반으로 /today-ref-use 제작"을 요청했습니다. 후보에 환경 선택, JSON 입력, 버전 비교, 게시 환경 선택이 함께 있어 소재를 환경별 설정 값을 고치고 비교해 게시하는 운영 콘솔로 잡았습니다. 아홉 수집에서 레퍼런스 12개를 옮겼고 새로 캡처하지 않았습니다.

조합은 네 개까지라 화면 틀과 목록, 편집, 게시, 실패를 한 레퍼런스씩 맡겼습니다. 이 업종에만 있는 본체 구조는 r3(환경 사이 비교와 복사 미리보기)이고, 오류 상태는 r4(게시 실패와 다시 시도)가 맡습니다. 넷 모두 실제 제품 화면(`still`)입니다.

## 레퍼런스별로 가져온 부분

- **r1 Sentry, 화면 틀과 설정 목록:** 왼쪽의 아이콘과 짧은 이름 띠 메뉴, 페이지 머리의 제목과 오른쪽 주 버튼, 붙은 버튼 묶음으로 된 범위 거르기(프로젝트, 환경, 기간)와 오른쪽 정렬 메뉴(지금 기준 이름과 체크), 조건 토큰("상태: 사용 중")이 남는 검색 줄. 굵은 이름 아래 회색 메타 줄과 오른쪽 숫자 열의 행. 행을 고르면 머리 줄 자리가 묶음 작업 줄(켜기, 끄기, 보관)로 바뀌고 앞의 체크가 일부 선택 표시로 바뀝니다.
- **r2 LaunchDarkly, 설정 값 편집:** 이름과 키(만든 뒤 바꿀 수 없다는 안내), 설명, 값 종류 선택에 따라 바뀌는 변형 칩(JSON이면 칩 안에 한 줄 JSON), 꺼짐일 때와 켜짐일 때 값의 요약, 닫을 수 있는 스키마 검증 칸의 줄 번호 편집기.
- **r3 LaunchDarkly, 환경 사이 게시:** 원본 환경 → 대상 환경 선택과 환경 바꾸기, 설정마다 칸별 다름(노란 경고 칸)과 같음(체크) 표. 한 설정을 열면 항목마다 체크하고 "대상의 현재 값"과 "복사 뒤 값"을 나란히 보며 바뀌는 칸을 초록 바탕으로 둡니다.
- **r4 Netlify, 게시 실패와 다시 시도:** 결과 카드 위쪽의 붉은 안내 상자에 실패 한 줄과 다시 시도 버튼, 그 아래 원인을 짧게 적은 기록.

## 가져오지 않은 부분

- 제품 이름, 로고, 브랜드 색(Sentry의 보라, LaunchDarkly의 연두 경고 칸과 파랑, Netlify의 청록)과 서체. 가상의 이름 "노브"와 이 완성작의 정체성(바탕 `#f6f6f4`, 승인 도장의 코발트 `#2446a8`, 모서리 5px, Noto Sans KR과 JetBrains Mono)을 씁니다.
- r1의 행마다 있는 추세 그래프, 우선순위와 담당자 칸, 저장된 보기와 AI 버튼, 정렬 메뉴 항목마다 붙은 한 줄 설명. r2의 사용자 지정 변형 묶음 메뉴. r3의 태그와 제외 거르기, 정렬, 행 왼쪽의 파란 강조 막대(tastepin 금지 증상). r4의 AI 진단 문단과 피드백 버튼.
- 서버와 실제 배포. 설정 열두 개와 호출 수는 지어낸 가짜 데이터이고, 새로고침하면 처음 상태로 돌아갑니다. 게시 실패는 게시 화면을 연 뒤 운영으로 가는 첫 게시에서 일부러 일어납니다.

## 상태로 가는 방법

- 설정 목록: `/#/settings`
- 묶음 작업 줄: 목록에서 "연휴 배송 안내 띠"와 "결제 수단별 수수료"의 체크 상자를 누르기
- 정렬 메뉴: 목록 오른쪽 위 "최근 변경" 버튼
- 빈 결과: 검색 줄에 "없는 설정" 입력. 검색 줄 오른쪽 ×나 빈 결과 자리의 "검색어 지우기"로 되돌림
- JSON 편집 패널: 목록에서 "연휴 배송 안내 띠" 이름을 누르고 두 번째 칩을 누르기
- 스키마 오류: JSON 편집 패널의 두 번째 값에서 `"show"`를 `"yes"`로 바꾸고 저장
- 필수 칸 오류: "새 설정"을 누르고 빈 채로 "만들기"
- 환경 비교: `/#/publish`
- 항목별 복사 미리보기: `/#/publish/checkout.retry-limit`
- 게시 실패: 복사 미리보기에서 "운영에 3개 항목 게시"를 누르고 1초 기다리기
- 게시 성공과 바뀐 칸 표시: 실패 카드의 "다시 시도"를 누른 뒤 위쪽 "비교로 돌아가기". 게시한 칸이 초록 바탕에서 한 번 옅어집니다
