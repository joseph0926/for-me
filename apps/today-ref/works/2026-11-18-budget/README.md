# 살림장 (가계부 앱 레퍼런스 구현)

- 주제 id: `2026-11-18-budget`
- 플랫폼: 앱 (데스크톱에서는 갤럭시 S26 기본형을 본뜬 프레임, 휴대폰 너비에서는 화면 전체)
- 선택: r3, r6, r5, r7 조합. 사용자가 아니라 AI가 골랐습니다.

## 고른 이유

주제의 핵심 화면인 월 요약, 달력과 날짜별 내역, 빠른 입력, 예산, 통계를 실제 제품 화면 네 개로 겹치지 않게 나눌 수 있었습니다. 실제 제품을 중심에 두고, 서버 없이 실제로 움직이게 만들 수 있는 부분만 골랐습니다.

- 뺀 후보: Copilot(r4)의 확인할 거래 묶음과 뱅크샐러드(r1)의 자산분석은 은행 연동과 자동 분류에 기대고, 편한가계부(r2)의 다섯 탭 구조는 r3의 달력과 겹치며, Dribbble 시안(r9~r11)은 실제 제품이 같은 부분을 이미 보여 줍니다.

## 레퍼런스별로 가져온 부분

- **r3 위플 가계부, 홈:** 맨 위 수입, 지출, 수입-지출 요약. 달력 칸마다 그날 지출(빨강)과 수입(파랑) 숫자, 고른 날 칠하기, 달력 아래 그날 내역 목록.
- **r6 뱅크샐러드(What Was IT), 내역 추가:** 지출과 수입 전환, 화면 아래 절반의 숫자 키패드(00 키와 지우기), 분류 선택과 메모.
- **r5 Monarch, 예산 탭:** 맨 위 남은 예산 띠, 분류별 진행 막대와 이번 달이 지난 만큼의 세로 눈금, 사용과 예산 두 숫자.
- **r7 네이버페이(What Was IT), 분석 탭:** "지난달 같은 기간보다 얼마 덜/더 썼어요" 문장, 이번 달과 지난달 누적 지출 두 선 그래프, 분류별 비율 목록.

## 가져오지 않은 부분

- 제품 이름, 로고, 브랜드 색(위플의 청록과 분홍, 뱅크샐러드의 초록, Monarch의 주황, 네이버페이의 초록)과 서체. 가상의 이름 "살림장"과 남색 강조색 하나, 지출 빨강과 수입 파랑을 씁니다.
- r3의 주간, 일간 탭과 영수증 모양 상세, 사진 첨부와 반복 지출 버튼.
- r6의 거래처명 입력 단계와 이체 종류, 분류가 필요한 내역 안내.
- r5의 목표 예산, 수입 예산, 생키 차트와 구독 목록.
- r7의 카드, 계좌, 포인트 필터와 누적, 주간, 월간 전환.

## 동작

- 달력 날짜를 누르면 그 숫자가 검은 사각으로 칠해지고 그날 내역이 아래에 바로 바뀝니다. 오늘은 숫자 아래 남색 점으로 표시합니다. 오늘 뒤의 날짜는 누를 수 없습니다.
- 월 이동: 이전 달로 가면 1일을 고르고, 이번 달로 돌아오면 오늘을 고릅니다. 날짜 칸과 달 이름은 넘기는 방향으로 밀리며 바뀌고, 월 합계 숫자는 세로로 넘어갑니다. 이번 달보다 뒤로는 가지 않습니다. 가짜 내역은 10월 1일부터 11월 18일까지만 있습니다.
- 내역 목록 머리줄의 "n일에 추가"로 고른 날짜에 내역을 넣습니다. 시트는 아래에서 0.3초에 올라오고, 덮개나 X를 누르면 같은 길로 내려갑니다. 키패드로 금액을 넣고 지출과 수입, 분류를 고른 뒤 저장하면 목록 맨 위에 펼쳐지며 1.6초 칠해지고, 달력 칸, 월 합계, 예산, 분석이 같은 내역에서 다시 계산됩니다.
- 아래 탭을 바꾸면 탭 순서 방향으로 화면이 밀리며 이전 화면과 겹쳐 바뀝니다.
- 예산: 이번 달 경과보다 많이 쓴 분류는 막대가 노랑과 "속도 빠름", 예산을 넘으면 빨강과 "초과"로 바뀝니다. 고정비(주거 통신)는 월초에 한 번 나가므로 속도를 따지지 않습니다.
- 오늘은 2026-11-18로 고정되어 있고, 서버 없이 메모리에만 저장하므로 새로고침하면 처음 상태로 돌아갑니다. 라이트와 다크 모드는 기기 설정을 따릅니다.

## AI 피드백 한 번에서 고친 것

- 떠 있던 + 버튼이 금액을 가리고 어느 날짜에 추가되는지 보이지 않아, 내역 머리줄의 "n일에 추가" 버튼으로 옮겼습니다.
- 저장한 내역이 목록 맨 아래로 가서 보이지 않아, 나중에 넣은 내역이 위로 오게 했습니다.
- 고정비에 붙던 "속도 빠름"을 없앴고, 예산 목록의 금액 단위를 원으로 맞췄습니다.
- 분석 그래프에서 두 달의 선이 겹쳐 구분되지 않아, 지난달은 점선, 이번 달은 굵은 선과 아래 채움으로 바꾸고 눈금을 50만 원 단위로 맞췄습니다.
- 내역 없는 날 머리줄의 "-0"과, 메모 없이 저장한 내역에서 분류 이름이 두 번 나오던 것을 없앴습니다.

## tastepin 다듬기에서 고친 것 (2026-11-26 소급)

이 완성작은 진행 절차에 tastepin 다듬기 단계가 생기기 전(2026-11-22)에 만들어, 2026-11-26에 소급해 다듬었습니다. 완성작 폴더에서 받은 취향의 화면 전체 값, 모션 기본값, 날짜 선택 값과 규칙을 따랐고, 이 폴더의 색과 서체 토큰과 분류 색은 바꾸지 않았습니다.

- 분류 표시: 분류 이름 첫 글자를 넣은 큰 색 원을 글자 없는 작은 색 점으로 바꿨습니다. 바로 옆에 분류 이름이 늘 있어 같은 말을 두 번 했습니다(규칙: 설명이 필요하면 문구 대신 구조를 고친다).
- 묶음 구분: 홈과 분석의 굵은 회색 띠, 월 요약 안의 선, 분석 비교 금액의 회색 상자 두 개를 지우고 28px 여백과 굵은 묶음 제목으로만 나눴습니다(화면 전체 값: 묶음 나누기는 여백과 제목).
- 달력: 고른 날은 본문색으로 채운 모서리 6px 사각, 오늘은 숫자 아래 4px 강조색 점으로 나눴고, 토요일 머리글의 파랑을 지워 파랑은 수입만 뜻하게 했습니다. 달을 넘기면 날짜 칸과 달 이름이 24px 밀리며 200ms에 겹쳐 바뀝니다(날짜 선택 값). 칸 아래 금액 두 줄 때문에 사각은 시편의 36px 대신 30px입니다.
- 그날 내역: 날짜를 누를 때마다 줄이 높이 0에서 다시 펼쳐지던 것을, 방금 저장한 한 줄만 펼치며 들어오고 나머지는 바로 바뀌게 했습니다(규칙: 반복해서 누르는 목록 갱신은 목록을 움직이지 않는다). 저장한 줄의 칠하기가 회색으로 보이던 것은 motion이 CSS 변수 색을 보간하지 못해서라 CSS 애니메이션으로 옮겼습니다.
- 금액: 달력 칸만 빼고 모든 금액에 원을 붙였고, 월 합계와 수입-지출은 바뀔 때 세로로 넘깁니다(숫자 바뀜 값). 분석의 '덜 썼어요' 금액은 단추 색인 남색 대신 본문색으로 둡니다.
- 모서리: "n일에 추가" 알약, 시트 24px, 예산 띠 16px, 전환과 저장 단추 12px를 6px로 맞췄습니다(모서리 작게).
- 내역 추가 시트: 스프링 대신 300ms 곡선으로 열고 같은 길로 닫습니다(드로어 예외). 분류는 가로 스크롤에 숨던 생활, 문화, 주거 통신이 보이도록 줄을 넘기는 6px 단추로 바꿨고, 지출과 수입 전환은 고른 쪽 면이 작은 스프링으로 미끄러집니다. '메모' 칸의 '사용처' 안내 글과, 덮개에 붙은 두 번째 '닫기' 단추를 지웠습니다.
- 화면 전환: 탭은 순서 방향으로 24px 밀리며 2px 흐림을 거쳐 240ms에 겹쳐 바뀝니다(모션 기본값의 이동 거리, 전환 흐림, 겹침).
- 단추: 누르는 동안 0.95배(120ms)를 모든 단추에 같이 걸었고, 키보드 초점은 1px 강조선과 옅은 번짐으로 보이며 마우스로 누를 때는 보이지 않습니다.

남긴 것: '문화' 분류의 보라색은 취향 규칙(보라는 AI 표시에만)과 맞지 않지만 완성작이 정한 분류 색이라 두었습니다. 예산 행의 사용, 남음, 예산 세 숫자는 r5의 구조라 그대로 둡니다.

## 상태로 가는 방법

새로고침 직후 기준입니다. 활용할 때 이 줄로 바로 그 상태를 띄웁니다.

- r3 날짜 고르기: 달력의 10일 칸(`11월 10일`) 누르기, 숫자가 검은 사각으로 칠해지고 아래 내역이 그날로 바로 바뀜. 18일에는 오늘 점이 남음. 19일 뒤 칸은 눌리지 않음
- r3 달 이동: 맨 위 "이전 달"이면 날짜 칸이 오른쪽으로 밀리며 10월 1일, "다음 달"이면 왼쪽으로 밀리며 11월 18일이 골라지고 월 합계 숫자가 세로로 넘어감
- r6 금액 입력 시트: 내역 머리줄 "18일에 추가", 시트가 아래에서 올라옴. "수입"을 누르면 고른 면이 옆 칸으로 미끄러지고 분류 단추가 월급, 부수입으로 바뀌며, 키패드와 "지우기"로 금액을 바꿈
- r6 저장 뒤 목록 반영: 시트에 금액을 넣고 "메모" 칸을 채운 뒤 "저장", 목록 맨 위에 새 내역이 펼쳐지며 1.6초 칠해지고 달력 칸과 월 합계가 바뀜
- r5 예산 막대: 아래 탭 "예산", 분류별 막대가 0.6초 동안 차오르고 "속도 빠름"과 "초과" 표시가 보임. 초과를 더 만들려면 위 시트로 그 분류에 지출을 넣음
- r7 분석 그래프: 아래 탭 "분석", 이번 달 누적 선이 0.8초 동안 왼쪽부터 그려지고 "어디에 썼나요" 비율 막대가 차오름
