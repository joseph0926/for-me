# 소곤 (크리에이터 팬 플랫폼 앱 레퍼런스 구현)

- 주제 id: `2026-11-21-creator`
- 플랫폼: 앱 (데스크톱에서는 갤럭시 S26 기본형을 본뜬 프레임, 휴대폰 너비에서는 화면 전체)
- 선택: r2, r4, r3 조합 (AI가 고름)

## 고른 이유

주제의 핵심은 크리에이터와 팬의 비대칭입니다. 크리에이터 글과 팬 글을 나누고, 크리에이터가 남긴 반응을 따로 보여 주는 화면은 실제 제품 중 r2가 가장 직접 보여 줍니다. 구독한 크리에이터를 모아 보는 홈과 글마다 붙는 공개 범위는 r4에, 유료 등급 비교와 가입은 r3에만 있어 셋으로 나눴습니다. 시안(r6~r9)은 실제 제품이 덮지 못한 부분이 없어 쓰지 않았습니다.

## 레퍼런스별로 가져온 부분

### r2 Berriz

- 크리에이터 홈: 화면 위쪽을 채운 대표 그림과 왼쪽 아래 큰 이름, 그 아래 공지, 일정(새 일정 빨간 점), From ○○, 팬 글(오늘 올라온 수 배지) 칩 줄, 기념일 띠(D-2 데뷔 3주년).
- 팬 글 상세에서 '크리에이터 댓글' 구역을 일반 댓글 위에 따로 두고, 크리에이터 댓글은 크리에이터 색 바탕으로 칠합니다.
- 라이브: 세로 화면 전체 영상 자리 위에 시청자 수와 하트 수, 고정된 크리에이터 메시지, 반투명 채팅 줄, 입력창, 떠오르는 하트.

### r4 팬딩

- 홈의 '내 크리에이터 N' 원형 아바타 줄과 '모두보기', '전체'와 '열람 가능' 필터.
- 글마다 공개 범위(전체 공개, 멤버 전용, 가까운 멤버 전용)와 조회 수를 작게 붙입니다.

### r3 Patreon

- 멤버십 등급 카드: 등급 이름, 월 금액, '인기' 표시, 혜택 목록, 가입 버튼. 가입하면 잠겨 있던 글이 바로 열립니다.
- 댓글 이름 옆 '크리에이터' 배지.

## 가져오지 않은 부분

- 제품 이름, 로고, 아티스트 사진과 이름: 가상의 이름 "소곤", 가상의 크리에이터 넷(하윤슬, 늦은여름, 도요, 마루)과 팬, CSS로 그린 그림과 이름 글자 아바타를 씁니다.
- 브랜드 색: r2의 검정 바탕과 분홍, r3의 주황, r4의 파랑은 쓰지 않았습니다. 앱 바탕은 흑백이고, 크리에이터마다 하나의 색상을 정해 그 크리에이터 공간의 강조색으로만 씁니다.
- r2의 외부 SNS 아이콘 줄, 번역 버튼, 상점과 응모 이벤트, r3의 커뮤니티 채팅방, r4의 온라인 강의와 펀딩, 1:1 메시지.
- 앱스토어 이미지 위의 광고 문구.

## 동작

- 홈: 구독한 크리에이터의 글만 최신순으로 보여 줍니다. 아바타 테두리는 라이브 중이면 빨강, 마지막 방문 뒤 새 글이 있으면 크리에이터 색입니다. 라이브 중인 크리에이터는 아바타와 위쪽 카드에서 바로 라이브로 들어갑니다.
- 잠긴 글은 흐리게 가리고 '멤버십 보기'로 등급 시트를 엽니다. 등급을 고르고 자동 결제 동의에 체크해야 가입 버튼이 켜집니다. 이미 멤버면 상위 등급은 '변경'으로 표시합니다. 실제 결제는 없습니다.
- 크리에이터 홈의 칩으로 공지, 일정, 크리에이터 글, 팬 글을 전환합니다. 일정마다 알림을 켜고 끌 수 있습니다.
- 팬 글을 올리면 상세로 이동하고, 6초 뒤 크리에이터 답글이 '크리에이터 댓글' 구역에 붙습니다. 동시에 알림 탭에 알림이 쌓이고, 다른 화면에 있어도 토스트로 알립니다.
- 댓글 쓰기와 좋아요, 글 좋아요. 댓글 수는 실제 댓글 목록에서 셉니다. 좋아요, 조회, 팔로워 수는 목록을 열 수 없는 숫자라 값으로만 둡니다.
- 라이브 채팅은 정해 둔 팬 메시지를 1.7초마다 흘리고, 다섯 번째마다 크리에이터가 채팅에 끼어듭니다. 내가 보낸 채팅과 하트도 바로 보입니다.
- 탐색에서 크리에이터를 검색하고 구독합니다. '나' 탭에서 멤버십을 해지하고, 구독 목록과 내가 쓴 팬 글(크리에이터 댓글 도착 표시)을 봅니다.
- 탭마다 쌓인 화면을 따로 유지하고, 보고 있는 탭을 다시 누르면 첫 화면으로 돌아갑니다.
- 서버 없이 메모리에만 저장하므로 새로고침하면 처음 상태로 돌아갑니다. 라이트와 다크 모드는 기기 설정을 따릅니다.
