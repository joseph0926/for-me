# 소곤 웹 (크리에이터 팬 플랫폼 웹 레퍼런스 구현)

- 주제 id: `2026-11-21-creator-web`
- 플랫폼: 웹 (768px 이상은 왼쪽 메뉴, 1280px 이상은 오른쪽 보조 열, 그보다 좁으면 위아래 막대)
- 선택: r1, r2, r4, r5 조합 (AI가 고름)
- 같은 날 만든 앱 완성작 [소곤](../2026-11-21-creator/README.md)의 웹 버전입니다. 가상의 크리에이터, 글, 댓글, 일정과 상태 규칙(`data.ts`, `store.ts`)은 앱에서 복사해 같게 두고, 화면 배치와 이동 방식만 웹에 맞게 새로 만들었습니다. 두 완성작은 서로 독립된 패키지라 한쪽을 고쳐도 다른 쪽은 바뀌지 않습니다.

## 고른 이유

넓은 화면의 크리에이터 페이지와 등급 비교는 r1 Patreon 웹이 가장 분명하게 보여 줍니다. 왼쪽 고정 메뉴와 잠긴 글의 본문 가림은 r2 팬딩 웹에, 가운데 한 열 글 카드와 탭 밑줄은 r4 YouTube 게시물 탭에 있습니다. 실제 제품 캡처에 없는 오른쪽 보조 열만 시안 r5에서 가져왔습니다.

## 레퍼런스별로 가져온 부분

### r1 Patreon

- 크리에이터 페이지 머리: 폭 전체 표지, 표지에 걸친 원형 프로필, 그 아래 큰 이름과 소개, 오른쪽 구독과 멤버십 버튼.
- 크리에이터 홈의 대표 글(큰 그림과 제목, 요약을 좌우로)과 그 아래 3열 글 카드 격자. 잠긴 카드는 그림을 흐리게 하고 잠김 배지를 답니다.
- 멤버십 탭: 등급 카드 셋을 나란히 두고 추천 등급만 위 띠와 굵은 테두리로 강조합니다.

### r2 팬딩

- 왼쪽 고정 메뉴: 로고, 내 계정, 홈, 탐색, 알림, 나, 그 아래 구독 중인 크리에이터 목록.
- 잠긴 글 상세: 본문을 회색 줄로 가리고 자물쇠, 글자 수와 그림 수, 멤버십 보기 버튼을 보여 줍니다.

### r4 YouTube

- 크리에이터 페이지의 글자 탭(홈, 포스트, 팬 글, 일정, 멤버십)과 선택한 탭의 밑줄.
- 홈 피드의 가운데 한 열 글 카드: 작은 프로필과 이름, 시간, 다섯 줄까지의 본문, 큰 그림.

### r5 CONNECTIFY 시안

- 1280px 이상에서만 보이는 오른쪽 보조 열: 지금 라이브, 다가오는 일정과 알림 버튼, 구독하지 않은 크리에이터 추천. 왼쪽 메뉴의 구독 목록에는 마지막 방문 뒤 올라온 새 글 수를 숫자 배지로 붙입니다.

## 가져오지 않은 부분

- 제품 이름, 로고, 크리에이터 사진과 이름, 브랜드 색(Patreon의 파랑, 팬딩의 보라, YouTube의 빨강). 앱 완성작과 같이 흑백 바탕에 크리에이터별 색상만 강조색으로 씁니다.
- r1의 컬렉션, 스토어, 연간 결제 전환, r2의 커뮤니티와 후기, 이벤트 탭, r4의 동영상과 Shorts 탭, r5의 연락처와 그룹 목록.
- r3 Berriz 웹, r6~r8 시안은 고르지 않았습니다.

## 동작

- 화면 위치를 주소 `#` 뒤에 둡니다(`#/c/yoonseul/membership`, `#/p/p1`, `#/live/lateSummer` 등). 새로고침, 링크 공유, 브라우저 뒤로 가기가 같은 화면을 엽니다. 없는 글과 주소는 안내 화면을 보여 줍니다. 상태는 메모리에만 있어 새로고침하면 처음 데이터로 돌아갑니다.
- 화면 안의 '뒤로'는 앱 안에서 이동한 기록이 있을 때만 브라우저 뒤로 가기를 쓰고, 링크로 바로 들어온 경우에는 홈으로 갑니다.
- 잠긴 글을 누르면 그 크리에이터의 멤버십 탭으로 갑니다. 등급을 고르면 확인 창이 열리고 자동 결제 동의에 체크해야 버튼이 켜집니다. 가입하면 잠긴 글이 바로 열립니다. 실제 결제는 없습니다.
- 팬 글을 올리면 상세로 이동하고, 6초 뒤 크리에이터 답글이 '크리에이터 댓글' 구역에 붙습니다. 알림이 쌓이고 다른 화면에 있어도 알림 문구가 뜹니다.
- 라이브는 넓은 화면에서 영상 자리와 채팅을 좌우로, 좁은 화면에서 위아래로 둡니다. 채팅은 정해 둔 팬 메시지를 1.7초마다 흘리고 다섯 번째마다 크리에이터가 끼어듭니다.
- 확인 창은 Esc와 바깥 클릭으로 닫히고, 닫히기 시작한 순간부터 아래 화면을 바로 누를 수 있습니다.
- 라이트와 다크 모드는 기기 설정을 따릅니다.
