# 곁 (AI 채팅 앱 레퍼런스 구현)

- 주제 id: `2026-11-20-ai-chat`
- 플랫폼: 앱 (데스크톱에서는 갤럭시 S26 기본형을 본뜬 프레임, 휴대폰 너비에서는 화면 전체)
- 선택: r1, r3, r4, r6 조합. 사용자가 아니라 AI가 골랐습니다.

## 고른 이유

주제는 사용자가 정한 "AI 채팅앱"입니다. AI 채팅 앱의 핵심은 답이 쓰이는 동안과 쓰인 뒤의 상태 변화라서, 그 상태를 실제 화면으로 보여 주는 레퍼런스를 골랐습니다. 대화 화면의 기본 구조는 ChatGPT(r1), 모델과 도구 선택은 Gemini(r3), 작업 단계와 출처는 Perplexity(r4), 생성 중 중지와 생성 뒤 다시 생성과 추천 질문은 What Was IT에 실린 뤼튼의 실제 캡처(r6)가 맡습니다.

- 뺀 후보: Claude(r2)의 지도 카드와 플래시카드 시트는 외부 지도와 결과물 실행에 기대고, 스토어 이미지라 일부만 보입니다. 뤼튼 스토어 이미지(r5)의 모델 고르기 대기와 도구 목록은 r6과 겹칩니다. Dribbble 시안 셋(r7~r9)은 실제 제품이 같은 부분을 이미 보여 줍니다.

## 레퍼런스별로 가져온 부분

- **r1 ChatGPT, 대화의 기본 구조:** 질문만 오른쪽 말풍선이고 답은 말풍선 없이 화면 폭 본문으로 쓰기. 답 안의 굵은 문장, 구분선, 제목, 목록. 맨 위 왼쪽 메뉴와 오른쪽 새 대화 버튼.
- **r3 Gemini, 제목줄과 입력창:** 메뉴 옆 "모델 이름 ▾"로 모델 바꾸기. 위는 글줄, 아래는 +와 보내기인 두 줄 입력 상자. 도구를 고르면 입력창 위에 "도구 ×" 칩이 붙고 안내 문구가 바뀌기.
- **r4 Perplexity, 작업 단계와 출처:** 답 전에 회색 작은 단계 행을 하나씩 쌓기, 출처가 있는 구절을 강조색으로 칠하기, 묶음마다 개수를 붙인 출처 목록(매체 이름과 제목 두 줄).
- **r6 뤼튼(What Was IT), 생성 중과 생성 뒤:** "분석하고 있어요" 회색 문장, 보내기 자리가 검은 중지 버튼으로 바뀌기, 답 뒤 "다시 생성"과 복사 줄, 오른쪽에 +가 붙은 추천 질문 세 줄, 빈 대화의 가운데 이름과 한 줄 설명.

## 가져오지 않은 부분

- 제품 이름, 로고, 브랜드 색(ChatGPT와 Gemini의 파랑, Perplexity의 청록, 뤼튼의 빨강)과 서체. 가상의 이름 "곁", 흰 바탕과 검은 글자, 출처와 선택 표시에만 쓰는 이끼 초록 하나를 씁니다.
- r1의 음성 대화, 이미지 질문, 연한 파랑 질문 말풍선(회색 말풍선으로 대신함).
- r3의 마이크, 이미지와 동영상 만들기 도구, 그림 위 탐색 버튼.
- r4의 결과물 칸, 커넥터와 파일 출처, 위쪽 세 칸 전환(답 아래 "출처 n" 버튼과 시트로 대신함).
- r6의 하단 탭(검색, 7초, 캐릭터 챗 등), 저장하기, 검색 모드의 동영상과 이미지 뼈대.
- 레퍼런스에 없던 부분: 지난 대화 서랍(오늘, 어제, 지난 7일 묶음), 모델 선택 시트, 다른 대화에서 답을 쓰는 중이라는 안내는 이 앱에서 정했습니다. 서랍의 대화 검색은 2026-11-26에 뺐습니다.

## 동작

- 답은 서버 없이 미리 써 둔 글을 한 글자씩 내보냅니다. 추천 질문, 그 답들이 제안하는 첫 이어서 물을 질문, 지난 대화에는 맞는 답이 있고, 그 밖의 질문에는 질문을 넣은 일반 틀로 답합니다.
- + 를 누르면 웹 검색과 깊게 생각하기 두 도구가 나옵니다. 웹 검색은 작업 단계 4개 뒤에 답하고 본문의 출처 번호와 "출처 n" 버튼으로 출처 시트를 엽니다. 깊게 생각하기는 단계 3개 뒤에 답하고 출처가 없습니다.
- 모델은 "곁 2 빠름"(초당 150자)과 "곁 2 깊이"(초당 75자, 단계 하나 더)이고, 바꾼 모델은 다음 질문과 다시 생성부터 씁니다.
- 답을 쓰는 동안 보내기 자리가 중지 버튼이 됩니다. 멈춘 답은 쓴 데까지 남고 "중간에 멈췄어요"가 붙습니다. 다시 생성은 같은 질문을 다른 표현의 답으로 처음부터 다시 씁니다.
- 끝난 답에는 다시 생성, 출처, 복사 버튼과(마지막 답에만) 이어서 물어보기 세 줄이 붙고, 작업 단계는 "작업 n단계"로 접힙니다. 빈 대화의 추천 질문과 이어서 물어보기는 같은 모양(오른쪽 +, 선 없는 행)입니다.
- 지난 대화 서랍은 맨 위 "새 대화" 행과 날짜 묶음 목록만 둡니다. 지금 대화는 이끼 초록 면으로 표시합니다.
- 맨 아래를 보고 있으면 새 글을 따라 내려가고, 위로 올려 읽는 중이면 그대로 두고 ↓ 버튼을 띄웁니다.
- 한 번에 하나의 답만 씁니다. 답을 쓰는 중에 다른 대화로 옮겨도 그 답은 계속 쓰이고, 지난 대화 목록에서 그 대화 옆에 진행 표시가 돕니다.
- 엔터로 보내고 Shift+엔터로 줄을 바꿉니다. 라이트와 다크 모드는 기기 설정을 따릅니다. 새로고침하면 처음 상태로 돌아갑니다.
- 출처는 화면 시연을 위해 지어낸 자료이고, 출처 시트 맨 아래에 그렇게 적어 두었습니다.

## AI 피드백 한 번에서 고친 것

- 앱이 제안한 "이어서 물어보기"와 지난 대화 "아침 루틴 30분 짜기"를 누르면 질문과 상관없는 일반 틀 답("~를 세 부분으로 나눠 볼게요")이 나왔습니다. 각 추천 답의 첫 이어서 물을 질문과 지난 대화의 질문에 맞는 답을 써 두었습니다.
- 한 대화에서 답을 쓰는 중에 새 대화로 옮기면 그 화면에 중지 버튼이 보였고, 추천 질문을 눌러도 아무 반응이 없었습니다. 중지 버튼은 답이 보이는 대화에만 두고, 다른 화면에서는 "다른 대화의 답을 마저 쓰고 있어요" 안내와 함께 보내기와 추천 질문을 막았다가 끝나면 다시 엽니다.

## tastepin 다듬기에서 고친 것 (2026-11-26 소급)

이 완성작은 진행 절차에 tastepin 다듬기 단계가 생기기 전(2026-11-22)에 만들어, 2026-11-26에 소급해 다듬었습니다. 완성작 폴더에서 받은 취향의 버튼, 입력, 배지 값과 모션 기본값, 규칙을 따랐고, 이 폴더의 색과 서체 토큰과 제목 표현은 바꾸지 않았습니다.

- 추천 질문: 빈 대화에서는 테두리 카드에 >, 답 뒤에서는 선으로 나눈 행에 초록 +로 같은 것을 다르게 그리던 것을 한 컴포넌트(선 없는 행, 오른쪽 회색 +)로 맞췄습니다. +의 초록은 출처와 선택 표시에만 쓴다는 이 앱의 색 결정과 어긋나 뺐습니다(규칙: 그룹은 여백과 글자 굵기로 나눈다).
- 답 아래 줄: 다시 생성은 바탕 없는 글자, 출처는 테두리 알약에 초록 아이콘, 복사는 아이콘만이던 세 모양을 높이 36px, 모서리 6px, 마우스를 올리면 옅은 면, 누르면 0.95배인 한 벌로 맞췄고, 답 사이의 선은 28px 여백으로 바꿨습니다(아이콘 버튼 값, 묶음 나누기 값).
- 출처 시트: 시트 제목 "출처 4"와 묶음 제목 "웹 4", 버튼 "출처 4"가 같은 숫자를 되풀이해 시트 제목을 "출처"로 줄였습니다. 출처 번호는 회색 원 대신 보조색 고정폭 숫자로 두었습니다(배지 값의 식별 번호).
- 시트: 끌어서 닫지 못하는데 보이던 손잡이 막대를 지웠습니다. 모델 시트의 "바꾼 모델은 다음 질문과 다시 생성부터 씁니다." 안내를 지웠습니다(규칙: 설명이 필요하면 문구 대신 구조를 고친다).
- 지난 대화 서랍: 대화 네 개에 붙은 검색 칸을 지웠습니다. 검색 칸이 서랍 폭을 넘어 서랍 안의 새 대화 버튼이 서랍 밖 제목줄 아이콘과 겹치던 결함도 함께 없어졌고, 새 대화는 목록 맨 위 행으로 옮겼습니다. 지금 대화 표시는 회색 면에서 이끼 초록 면으로 바꿔 마우스를 올린 행(회색 면)과 헷갈리지 않게 했습니다(규칙: 필요 없는 컨트롤을 붙이지 않는다).
- 모션: 서랍과 바텀 시트는 스프링 대신 300ms, 도구 메뉴, 작업 단계 펼침, 맨 아래로 버튼과 복사 알림은 220ms ease-out-cubic으로 열고 같은 길로 닫습니다. 맨 아래로 버튼과 복사 알림은 사라질 때도 들어온 방향으로 움직입니다(드로어 예외, 펼침 영역 예외, 퇴장 값).
- 모서리: 입력 상자 22px, 도구 메뉴, 시트, 대화 행, 복사 알림의 큰 모서리와 알약 모양을 6px로 줄였습니다. 도구 칩, 보내기와 중지 원, 본문의 출처 번호, 질문 말풍선은 레퍼런스에서 가져온 모양이라 그대로 둡니다(규칙: 모서리는 작게 둔다).
- 버튼: 제목줄과 시트 닫기는 36px 아이콘 버튼으로, 입력창 +는 테두리 원 대신 같은 아이콘 버튼으로 맞췄고, 쓸 수 없을 때는 0.4로 흐립니다. 키보드 초점은 1px 강조선과 옅은 번짐이고 마우스로 누를 때는 보이지 않습니다(버튼 값).
- 입력 상자: 글줄에 초점이 있으면 테두리가 2px로 짙어집니다. 취향 값의 강조색 대신 보조 글자색을 썼습니다. 보낸 뒤에도 초점이 남아 늘 보이는 테두리라, 이끼 초록을 출처와 선택 표시에만 쓰는 이 앱의 색 결정이 앞섭니다.
- 도구 메뉴: 설명 "최신 자료를 찾아 출처와 함께 답합니다"의 마지막 "다"가 혼자 다음 줄로 넘어가 메뉴 폭을 264px로 넓혔습니다.

남긴 것: 빈 대화 가운데의 검은 사각 "곁" 표시와 "무엇을 도와드릴까요?" 인사, 사용법 한 줄은 흔한 AI 채팅 첫 화면 구성이지만 r6에서 가져온 "가운데 이름과 한 줄 설명"이고 제목 표현이라 두었습니다. 출처 시트 맨 아래의 "지어낸 자료" 안내는 가상의 매체 이름을 실제 기사로 오해하지 않게 두었습니다.

## 상태로 가는 방법

새로고침 직후 기준입니다. 활용할 때 이 줄로 바로 그 상태를 띄웁니다.

- r1 지난 대화 서랍: 맨 위 왼쪽 "지난 대화", 서랍이 왼쪽에서 들어옴. 지금 대화가 이끼 초록 면, "아침 루틴 30분 짜기"를 누르면 서랍이 닫히고 그 대화의 다 쓴 답이 열림
- r1 한 글자씩 쓰이는 답: 추천 질문 "전세와 월세, 지금 뭐가 나을지 따져 줘", 약 4초 동안 본문이 쓰이며 끝의 깜빡이는 점과 제목, 목록이 차례로 생김. 더 길게 보려면 먼저 모델을 "곁 2 깊이"로
- r3 모델 시트: 맨 위 "곁 2 빠름", 아래에서 "모델" 시트가 올라오고 "곁 2 깊이"를 고르면 제목줄이 바뀜
- r3 도구 칩: 입력창 왼쪽 +(`도구`), "웹 검색"을 고르면 입력창 위 칩과 안내 문구가 바뀜. 칩의 ×로 끔
- r4 작업 단계와 접힘: "웹 검색"을 켠 뒤 위 추천 질문, 단계 4개가 0.75초마다 붙고 답이 끝나면 "작업 4단계"로 접힘
- r4 출처 시트: 웹 검색 답이 끝난 뒤 본문의 출처 번호 "1"이나 답 아래 "출처 4", 아래에서 출처 시트가 올라옴
- r6 멈춤: 추천 질문을 보낸 직후 보내기 자리의 "답변 멈추기", 쓴 데까지 남고 "답변을 중간에 멈췄어요."가 붙음
- r6 끝난 답의 줄: 추천 질문 뒤 약 5초 기다리면 "다시 생성", "답변 복사", 이어서 물어보기 세 줄(빈 대화의 추천 질문과 같은 모양). 위로 스크롤하면 "맨 아래로"
