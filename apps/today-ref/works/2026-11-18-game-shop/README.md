# KICKLINE 27 상점 (인게임 샵 웹 레퍼런스 구현)

- 주제 id: `2026-11-18-game-shop`
- 플랫폼: 웹 (콘솔과 PC 게임의 메인 메뉴 안 상점처럼 화면 전체를 씀)
- 주제: 사용자가 정했습니다. 레퍼런스 선택은 사용자가 아니라 AI가 했습니다(r1, r2, r4, r7 조합).
- 게임과 선수는 모두 가상의 이름입니다.

## 고른 이유

주제의 핵심인 보유 재화 표시, 팩 진열, 시즌 패스, 구매 흐름은 실제 제품 화면 셋(FC 27 Companion, NBA 2K Mobile, Battlefield 6)이 겹치지 않게 보여 줬습니다. 실제 제품 캡처에 없던 재화 충전 목록만 Dribbble 시안에서 가져왔습니다.

- 뺀 후보: eFootball(r3)의 보유 선수 격자는 상점보다 보관함에 가깝고, eFootball 콘셉트(r5)의 세 타일 첫 화면은 r2의 세로 메뉴와 역할이 겹치며, FIFA22 패스 보상 줄(r6)은 조합 4개 안에서 r4의 등급 비교를 우선했고, FC24 웹앱 시안(r8)은 r1, r2가 같은 머리줄과 메뉴를 실제 제품으로 보여 주며, Dota 2 구매 완료(r9)는 확인 화면 하나라 직접 만들었습니다.

## 레퍼런스별로 가져온 부분

- **r1 EA SPORTS FC 27 Companion:** 모든 화면 머리줄 오른쪽에 늘 보이는 두 재화(경기로 버는 코인, 충전하는 포인트). 팩 카드의 이름, 설명, 내용물, 반복 가능과 계정당 한도 같은 조건 줄, 코인과 포인트 중 골라 내는 가격.
- **r2 NBA 2K Mobile:** 상점 구역 전환 메뉴를 참고했고, 현재 화면에서는 머리줄 아래의 가로 메뉴로 이동합니다. 무료 보상의 수령, 대기, 잠김 세 상태를 가져왔습니다. 피드백을 반영해 열 수 있는 팩은 수령 버튼으로, 대기 시간과 잠금 조건은 그 아래 목록으로 표시합니다.
- **r4 Battlefield 6 공식 뉴스:** 무료, 시즌 패스, 패스 플러스 세 열과 혜택 행의 비교표. 포함은 체크, 등급마다 다른 혜택은 값(+10%, 20단계)으로 적기.
- **r7 Dribbble 코인 상점 시안:** 포인트 충전 묶음을 한 줄씩 쌓고, 양이 늘수록 커지는 보석 그림, 수량과 가격 버튼, 일부 묶음에만 기울어진 배지.

## 가져오지 않은 부분

- 게임 이름, 로고, 선수 사진, 브랜드 색(FC의 초록, Battlefield의 빨강과 군용 서체, NBA 2K의 빨강)과 서체. 가상의 "KICKLINE 27"과 검정과 흰색을 기본으로 쓰고, 선택한 메뉴와 무료 팩 열기 버튼에만 밝은 청록색을 강조합니다. 코인은 은색 원, 포인트는 청록색 보석으로 구분합니다.
- r1의 이적 시장 입찰과 SBC 제출 조건, r2의 이벤트 챕터 진행과 팬 수, r4의 표지 그림과 포털 서버 같은 게임 전용 혜택, r7의 나무판 모양 장식과 Close 버튼.
- 추천 배너, 상품 포장, 선수 카드 초상과 충전 보석은 이 상점을 위해 생성한 이미지입니다. 상품명, 가격, 선수 등급과 장수는 앱 데이터에서 표시합니다.
- 실제 결제. 포인트 충전의 결제 버튼은 흉내만 내고 바로 포인트를 더합니다.

## 사용자 결정

- 금색과 누런색은 사용자 피드백으로 뺀 색입니다. 상품 포장에 쓰인 색을 배경, 무료 보상과 주 동작으로 넓히지 않습니다.

## 동작

- 머리줄의 코인과 포인트는 구매와 충전마다 바로 바뀌고, 포인트 옆 + 버튼은 충전 화면으로 갑니다.
- 팩 구매: 가격 버튼을 누르면 확인 창이 뜹니다. 두 재화로 살 수 있는 팩은 창 안에서 낼 재화를 바꿀 수 있고, 장당 확률과 구매 전후 잔액이 보입니다. 구매하면 카드가 높은 등급부터 한 장씩 뒤집힙니다. 한 팩 안에서는 같은 등급의 선수가 다 나오기 전까지 같은 선수가 다시 나오지 않습니다.
- 잔액이 모자라면 구매 버튼이 막히고 부족한 양을 보여 줍니다. 포인트가 모자라면 충전 화면으로 갈 수 있고, 충전을 마치면 "○○ 구매 계속"으로 원래 사려던 것에 돌아갑니다. 코인은 충전할 수 없습니다.
- 계정당 한도가 있는 팩은 남은 횟수를 보여 주고, 다 사면 "구매 완료"로 바뀝니다.
- 무료 보상: 처음에 한 칸은 바로 열 수 있고, 한 칸은 15초 뒤 열립니다. 연 칸은 4시간 타이머로 돌아갑니다. 잠긴 칸은 단계 10에 열린다고만 표시합니다.
- 시즌 패스: 사면 비교표의 현재 등급이 바뀌고 즉시 보상 팩이 열립니다. 시즌 패스에서 패스 플러스로 올릴 때는 차액만 냅니다.
- 팩 화면의 전체, 한정, 코인으로 사기, 즐겨찾기 필터. 별을 누르면 즐겨찾기에 모입니다.
- 구매 내역에 이번 접속의 구매, 충전, 무료 보상이 최근 것부터 쌓입니다.
- 서버 없이 메모리에만 저장하므로 새로고침하면 처음 상태로 돌아갑니다. 게임 메뉴처럼 어두운 화면 하나만 씁니다. 창은 Esc로 닫습니다.

## AI 피드백 한 번에서 고친 것

- 카드가 3장일 때 공개 화면에서 왼쪽으로 쏠리던 것을 가운데 정렬로 바꿨습니다.
- "코인로 내기", "코인가 부족" 같은 조사 오류를 재화마다 조사를 따로 두어 고쳤습니다.
- 한 팩에 같은 선수가 세 번 나오던 것을, 한 팩 안에서는 같은 선수를 다시 뽑지 않게 하고 일반 선수를 늘려 고쳤습니다.
- 포인트가 모자라 충전하러 간 뒤 원래 구매로 돌아갈 길이 없어, 충전 완료 창에 "구매 계속" 버튼을 넣었습니다.
- 375px에서 "패스 플러/스"처럼 단어 중간에서 줄이 바뀌던 것을 단어 단위 줄바꿈으로 바꿨습니다.
- 가격 버튼과 무료 보상 열기 버튼에 화면 읽기용 이름을 붙였습니다.
- 수정 중 구매 내역의 "오후 02:24:17"이 두 줄로 갈라져 24시간 표기로 바꿨습니다.

## 상태로 가는 방법

새로고침 직후 기준입니다. 활용할 때 이 줄로 바로 그 상태를 띄웁니다.

- r2 무료 팩 열기: 추천 화면 "무료 보상"의 "팩 열기"(`무료 보상 팩 열기`), 카드 공개 뒤 "확인", 그 칸이 4시간 대기로 바뀜
- r2 대기 중과 15초 뒤 열림: 새로고침 직후 둘째 칸은 "대기 중"과 카운트다운, 15초 뒤 "팩 열기"로 바뀜
- r1 팩 구매와 카드 뒤집기: "기본 선수 팩"의 코인 가격 버튼, 확인 창 "구매", 카드가 높은 등급부터 뒤집히고 머리줄 코인이 바뀜
- r1 낼 재화 바꾸기: "골드 선수 팩"의 가격 버튼, 확인 창의 "낼 재화" 두 칸을 번갈아 누르기, 잔액 줄과 구매 금액이 바뀜
- r1 한도 다 사기: 메뉴 "팩", "주말 리그 팩"을 두 번 구매, 버튼이 "구매 완료"
- r1 포인트 부족에서 구매 계속: 맨 위 영웅 선택 팩 구매, 부족 안내의 "포인트 충전하러 가기", 충전 상품 결제, "충전 완료" 창의 "영웅 선택 팩 구매 계속"
- r7 포인트 충전: 머리줄 포인트 옆 +(`포인트 충전`), 충전 상품 결제, "충전 완료"와 머리줄 포인트 변화
- r4 시즌 패스: 메뉴 "시즌 패스", 표의 시즌 패스 열 "구매", 보상 뒤 "확인", "현재 등급"이 옮겨 가고 패스 플러스 열이 "올리기"로 바뀜
