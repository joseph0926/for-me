# 필름함 (동영상 앱 레퍼런스 구현)

- 주제 id: `2026-11-20-video`
- 플랫폼: 앱 (데스크톱에서는 갤럭시 S26 기본형을 본뜬 프레임, 휴대폰 너비에서는 화면 전체)
- 선택: r1, r2, r6, r7 조합. 사용자가 아니라 AI가 골랐습니다.

## 고른 이유

주제는 사용자가 정한 "동영상 앱(비디오 플레이어) / OTT"입니다. 휴대폰에 저장한 파일을 재생하는 앱이 OTT처럼 보이려면 홈의 이어보기와 상세 화면이, 파일 재생기로 쓰려면 폴더 목록과 재생 조작이 필요합니다. 내 영상 라이브러리를 OTT처럼 보여 주는 Infuse(r1)와 폴더 기반 재생기 nPlayer(r2)를 중심에 두고, 두 실제 제품의 스토어 이미지로는 보이지 않는 재생 조작의 상태 변화(조작 겹침, 끝난 뒤, 재생바 끌기, 두 번 눌러 이동)만 Dribbble 시안 두 개(r6, r7)에서 가져왔습니다.

- 뺀 후보: Netflix(r4)와 왓챠(r5)의 대표작 카드, 찜, 순위, 추천은 작품 정보와 추천 데이터에 기대고 로컬 파일 앱에는 맞지 않습니다. VLC(r3)의 두 열 목록과 썸네일 진행 막대는 r1, r2와 겹칩니다. r8 시안은 r1의 상세와 겹치고, r9는 데스크톱 창, r10 치지직은 생방송 채널 화면입니다.

## 레퍼런스별로 가져온 부분

- **r1 Infuse, 홈과 상세:** 큰 "홈" 제목 아래 넓은 썸네일의 이어보기 줄(가운데 재생 원, 제목, 남은 시간, 아래 진행 막대), 폴더 바로가기 타일 줄과 "모두 보기". 상세의 장면 배경, 제목과 "길이 · 날짜 · 해상도" 한 줄, 본 만큼 바탕이 채워지는 이어보기 버튼.
- **r2 nPlayer, 보관함과 재생 가장자리:** 상위 폴더(..), 하위 폴더, 영상 순서의 폴더 목록. 영상 행의 "형식 · 용량 · 날짜"와 "지난 시간 / 길이" 두 줄, 보던 영상의 강조색 제목과 부분 채움 원, 안 본 영상의 "새 영상" 표시. 상세 아래 영상, 음성 형식 표. 재생 화면 오른쪽 가장자리의 속도 +, 1.0x, -와 화면 잠금.
- **r6 Dribbble 재생기 시안, 조작 겹침:** 영상 전체를 어둡게 덮고 위에 폴더 이름(작게)과 제목(굵게), 오른쪽 위 아이콘, 가운데 이전, 일시정지(크게), 다음 원 버튼, 아래 "지난 시간 / 길이"와 전체 폭 재생바. 끝난 뒤 가운데 다시 보기와 다음 영상 강조 버튼.
- **r7 Dribbble 재생기 시안, 탐색 제스처:** 재생바를 끄는 동안 다른 조작을 숨기고 손잡이 위에 시간 말풍선만 띄우기. 화면 왼쪽이나 오른쪽을 두 번 누르면 그쪽 가장자리에 반원 모양 밝은 영역과 "10초"가 나타나는 표시.

- r2의 네트워크 서버, 재생 목록, 다운로드 탭, 음악 미니 플레이어, 별점, 화면 전송과 구간 반복, 막대 바탕이 진행을 겸하는 상단 막대(r6의 재생바로 대신함).
- r6의 화면 전송과 목록 아이콘, 강의 묶음 이름의 "Finish Class" 문구.
- 레퍼런스에 없던 부분: 자막 시트(영상에 포함된 자막, 외부 SRT, 끄기)와 가로 보기 전환은 주제의 핵심 동작이라 이 앱에서 정했습니다.

## 동작

- 영상 파일 대신 캔버스에 장면을 그립니다. 해와 물결, 건물 창의 불빛이 재생 시각에 따라 움직이고, 같은 시각이면 썸네일과 재생 화면이 같은 그림입니다.
- 홈의 이어보기 카드는 재생 원을 누르면 저장한 위치에서 바로 재생하고, 나머지를 누르면 상세가 열립니다. 폴더 타일과 "모두 보기"는 보관함의 그 폴더로 갑니다.
- 저장한 위치에서 재생을 시작하면 영상 아래쪽에 "21:58부터 이어서 재생해요"와 "처음부터" 버튼이 4초 보입니다.
- 상세는 맨 위에서 뒤로 버튼만 장면 위에 띄우고, 130px 넘게 내리면 머리 막대가 채워지며 가운데에 제목이 나옵니다. 지금 데이터로는 휴대폰 높이에서 상세가 거의 스크롤되지 않아, 창 높이가 낮을 때만 보입니다.
- 재생 화면: 가운데를 누르면 조작을 보이거나 숨기고, 재생 중이면 마지막으로 만진 뒤 2초가 지나면 저절로 숨습니다. 양옆을 두 번 누르면 10초 이동이고, 표시가 떠 있는 동안 같은 쪽을 한 번 더 누르면 20초, 30초로 쌓입니다. 재생바는 누르거나 끌어서 옮깁니다.
- 속도는 0.5배에서 2배까지 바뀌고, 가운데 숫자를 누르면 1.0배로 돌아갑니다. 1배가 아니면 숫자 바탕이 강조색입니다. 속도와 가로 보기는 다음 영상에도 이어집니다.
- 자막은 영상마다 고른 것을 기억합니다. "외부 SRT 열기"는 실제 파일 선택기 대신 장면 종류에 맞춰 정해 둔 대사 SRT를 불러온 것으로 처리하고 알림을 띄웁니다.
- 화면 잠금 중에는 조작과 두 번 누르기가 막히고, 화면을 누르면 "잠금 해제" 버튼만 2.5초 보입니다.
- 끝까지 보면 다시 보기와 같은 폴더의 다음 영상 버튼이 나옵니다. 이전과 다음 버튼도 같은 폴더 안에서 움직입니다.
- 재생 화면을 닫거나 다른 영상으로 넘어가면 그 위치를 저장합니다. 끝에서 20초 안이면 다 본 것으로 쳐서 이어보기에서 빠지고 보관함에 체크가 붙습니다. 10초 전에 닫으면 기존 기록을 그대로 둡니다.
- 데스크톱에서 확인할 때는 스페이스(재생, 일시정지), 좌우 화살표(10초 이동), Esc(닫기)를 씁니다.
- 오늘은 2026-11-20으로 고정되어 있고, 서버 없이 메모리에만 저장하므로 새로고침하면 처음 상태로 돌아갑니다. 기기 설정과 상관없이 어두운 화면만 씁니다.

## AI 피드백 한 번에서 고친 것

만들면서 확인할 때 고친 것:

- 양옆을 두 번 누르면 제목과 시간 글자가 선택되어 파랗게 칠해졌습니다. 재생 화면 전체에서 글자 선택을 막았습니다.
- 10초 이동 표시가 세로 화면에서 영상 밖 검은 여백까지 걸쳐 그려졌습니다. 영상 자리 안에만 그리도록 옮겼습니다.
- 가로 보기에서 영상이 16:9를 벗어나 화면 끝까지 늘어났습니다. 캔버스가 영상 자리의 크기를 밀어내지 않게 고쳤습니다.
- 재생바를 누르자마자 끌면 끌기가 무시되었습니다. 끄는 중인지를 화면 상태가 아니라 누른 순간에 바로 기록하도록 고쳤습니다.
- 조작을 띄우면 어둡게 덮는 층 아래로 자막이 깔려 흐려졌습니다. 자막을 덮개 위에 그립니다.

- 보관함에서 "새 영상" 상자가 붙은 행의 날짜가 "2026.1…"로 잘렸습니다. 올해 날짜는 "11.02"처럼 연도를 뺍니다.

- 새 영상을 열었다가 몇 초 만에 닫아도 이어보기 맨 앞에 "49분 남음"으로 올라왔습니다. 10초 전에 닫으면 기록을 남기지 않습니다.
