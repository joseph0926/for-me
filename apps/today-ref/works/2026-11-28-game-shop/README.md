- 피처드 묶음: 배너를 누르면 상세가 열리고, 왼쪽 목록에서 항목을 고르면 가운데 그림과 단품 가격이 바뀝니다. 묶음 가격은 이미 가진 항목만큼 줄고, 절약액은 아직 없는 항목의 단품 합에서 묶음 가격을 뺀 값입니다. 모두 가지면 "보유"가 됩니다.

- 선수 팩: 기둥을 누르면 고른 팩이 떠오르고 오른쪽 패널이 바뀝니다. 팩 확률은 패널의 "팩 확률 보기"로 열고, 표의 값과 실제 뽑기(`src/shop.ts`의 `drawPack`)가 같은 확률을 씁니다. 골드 미리보기 팩은 "미리보기"로 든 선수를 보고, 사면 미리 본 그대로 받습니다. 한 팩 안에서 같은 선수는 다시 나오지 않습니다.
- 잔액이 모자라면 카드, 기둥, 버튼의 가격만 빨갛게 보이고 칸은 흐리게 하지 않습니다. 확인 창에서 비용이 빨갛게 바뀌고 "포인트 2,080 부족"처럼 모자란 양이 보이며 구매 버튼이 막힙니다. 포인트면 같은 창에서 충전한 뒤 구매로 돌아옵니다.
- 남은 시간은 접속한 시각부터 1초마다 줄어듭니다. 서버 없이 메모리에만 저장하므로 새로고침하면 처음 상태로 돌아갑니다. 창은 Esc로 닫고, 팩 개봉은 버튼으로만 나갑니다.
