# 말틀 (프롬프트 생성 웹 레퍼런스 구현)

- 주제 id: `2026-11-21-prompt`
- 플랫폼: 웹. 넓은 화면에서는 가운데 760px 열, 휴대폰 너비에서는 화면 전체를 씁니다.
- 주제: 사용자가 정했습니다("ai가 사용자의 채팅 or 이미지 + 채팅을 받아서 프롬프트를 출력하는 웹"). 직전 주제가 AI 채팅 앱이라 같은 종류를 피하는 규칙과 겹칠 수 있지만 사용자가 정한 주제라 그대로 따랐습니다.
- 선택: r6, r4, r1, r5 조합. 사용자가 아니라 AI가 골랐습니다.
- 제품 이름 "말틀"과 기록 속 지난 프롬프트는 모두 가상입니다.

## 고른 이유

이 주제의 핵심은 대화 자체보다 결과물인 프롬프트입니다. 그래서 입력, 이미지 첨부, 결과 정리를 나눠 보여 주는 실제 제품 셋을 중심에 두었습니다. 텍스트 입력은 Claude Console(r1), 이미지 첨부는 Ideogram(r4), 이미지 옆 결과 카드는 Lexica(r5)에서 가져왔습니다. 채팅으로 요청하고 결과를 다듬어 가는 흐름은 실제 제품 캡처에 없어서 Dribbble 시안 Prompt Enhancer(r6)에서만 가져왔습니다.

- 뺀 후보: Claude Console 작업대(r2)는 개발자용 편집기 구조라 r1과 역할이 겹칩니다. Ideogram 문서 캡처(r3)는 잘린 입력칸뿐이고, 이미지 설명 결과는 r5 카드와 r6 결과 상자로 충분합니다. 편집 화면 시안(r7)은 r6의 칩과 겹치고, 양식형 시안(r8)은 채팅 흐름과 맞지 않습니다. Numenta(r9)는 첫 소개 화면뿐이고, Pixcl.ai(r10)는 기능 목록 그림이라 배치를 알 수 없습니다.

## 레퍼런스별로 가져온 부분

- **r6 Prompt Enhancer 시안, 대화 흐름:** 오른쪽 요청 말풍선과 그 아래 용도, 대상 태그. 왼쪽 결과 상자의 구조화된 프롬프트(역할 문장, 소제목, 목록)와 상자 오른쪽 바깥의 세로 아이콘 버튼. 결과 아래 반짝이 아이콘이 붙은 다듬기 제안. 입력창 안의 용도 칩(×로 빼기)과 왼쪽 아래 대상 선택. 위쪽 메뉴의 기록 진입.
- **r4 Ideogram, 첨부를 담은 입력창:** 둥근 큰 입력창 위쪽의 + 첨부 칸과 올린 이미지 썸네일, 가운데 글줄, 오른쪽 아래 둥근 보내기 버튼.
- **r1 Claude Console, 빈 첫 화면과 변수:** 제목 아래 아이콘이 붙은 예시 칩 두 줄. 프롬프트 속 {{변수}}를 색으로 구분하고, 변수 값을 따로 채우는 패널.
- **r5 Lexica, 이미지 분석 카드:** 이미지 옆 설명 카드와 그 아래 복사 버튼 두 개, 작은 회색 이름과 값 두 줄로 쌓는 정보(주요 색, 스타일, 비율과 크기).

## 가져오지 않은 부분

- 제품 이름, 로고, 브랜드 색(Claude의 주황, Ideogram의 보라, Lexica의 남보라, r6의 주황과 보라 그라데이션 테두리)과 서체. 따뜻한 회백색 바탕, 먹색 글자, 깊은 바다색 강조 하나, 변수 표시용 호박색을 씁니다. 글꼴은 템플릿의 Pretendard Variable입니다.
- r1의 고정폭 글꼴 프롬프트 편집칸과 Run 버튼, r4의 영상 도구와 커뮤니티 격자, r5의 Open in editor와 Explore this style, 이미지 네 장 줄, r6의 Statistics 메뉴, 페르소나 추가, 사용자 사진.
- 실제 모델 호출, 실제 이미지 생성, 로그인과 저장.
- 레퍼런스에 없던 부분: 대상(대화형 AI, 이미지 생성, 코딩 에이전트)마다 다른 프롬프트 구조, 기록 화면의 대상 거르기, 결과 텍스트 파일 내려받기, 쓰는 중 멈추기는 이 앱에서 정했습니다.

## 동작

- 첫 화면: 예시 칩을 누르면 글, 대상, 용도가 채워지고 입력칸으로 초점이 옮겨집니다. "이 사진 분위기로 그리기"는 샘플 그림(`public/samples/sunset.svg`)을 함께 붙입니다.
- 첨부: + 칸, 파일 끌어다 놓기, 붙여넣기로 이미지를 3장까지 붙입니다. 이미지가 아닌 파일, 10MB를 넘는 파일, 3장을 넘는 파일은 빼고 이유를 입력창 아래에 보여 줍니다.
- 이미지 분석: 서버 없이 브라우저 캔버스에서 실제 픽셀을 읽어 주요 색 네 가지(이름이 같으면 합침), 밝기, 채도, 색 온도, 명암 대비, 가장 가까운 비율을 계산합니다. 사물이나 장면은 알아보지 않습니다.
- 만들기: 요청 문장에 든 낱말(요약, 분류, 광고, 메일, 블로그, 코드 등)로 일의 종류를 고르고, 대상과 용도에 맞춘 구조로 프롬프트를 조립합니다. 잠시 "읽는 중"을 보인 뒤 글자가 차례로 쓰이고, 그동안 보내기 버튼이 멈추기 버튼으로 바뀝니다. 멈추면 보인 부분까지만 남습니다.
- 다듬기: "더 구체적으로", "짧게 줄이기", "예시 넣기", "바꿀 부분을 변수로"는 직전 결과를 바꿉니다. 같은 제안을 다시 눌러도 같은 묶음이 두 번 쌓이지 않습니다. 이어서 쓴 글은 "추가 요청"으로 덧붙고, 대상이나 용도를 바꾸거나 새 이미지를 붙이면 처음 요청부터 다시 만든 뒤 지금까지의 추가 요청을 다시 붙입니다.
- 변수: 결과에 {{변수}}가 있으면 아래에 "변수 n개" 패널이 생기고, 값을 채우면 결과 상자에 바로 반영되며 "채운 프롬프트 복사"로 채운 글을 복사합니다.
- 복사와 내려받기: 클립보드 권한이 막히면 숨은 입력란을 골라 복사하는 방법으로 한 번 더 시도하고, 그래도 실패하면 직접 복사하라고 알립니다.
- 기록: 세션마다 제목, 대상, 용도, 날짜와 결과의 묶음 이름을 보여 주고 대상으로 거릅니다. 누르면 그 대화를 다시 엽니다. 쓰는 중에는 다른 기록을 열 수 없습니다.
- 서버 없이 메모리에만 저장하므로 새로고침하면 처음부터 들어 있던 가상 기록 세 개만 남습니다. 밝은 화면과 어두운 화면은 기기 설정을 따릅니다.

## AI 피드백 한 번에서 고친 것

- "바꿀 부분을 변수로" 뒤에도 한 줄 버전에 원래 장면과 색이 남아, 변수를 채워도 한 줄 버전은 옛 내용이었습니다. 한 줄 버전도 같은 변수로 바꿉니다.
- 300×600 이미지의 비율을 9:16으로 표시했습니다. 1:2, 2:1, 4:5 후보를 더했습니다.
- 값이 다른 두 색이 모두 "빨강"으로 나왔습니다. 어두운 색의 기준을 넓혀 "짙은 빨강"으로 나누고, 그래도 이름이 같으면 한 줄로 합칩니다.
- 입력칸에 초점이 가면 둥근 입력창 안에 사각 초점 선이 겹쳐 그려졌습니다. 입력창 테두리가 초점을 보여 주므로 글줄의 선은 뺐습니다.
- 기록 목록의 둘째 줄이 제목이나 "너는 이 분야의 숙련된 전문가다."를 되풀이했습니다. 결과가 어떤 묶음으로 짜였는지(장면, 색과 분위기, 구도 등)를 보여 줍니다.
- 휴대폰에서 이어서 쓰는 입력창이 빈 첨부 칸 줄 때문에 화면의 4분의 1을 가렸습니다. 이어서 쓸 때는 첨부가 있을 때만 첨부 줄을 펼치고, 붙이기 버튼은 아래 도구 줄로 옮겼습니다(211px에서 139px).
- 복사 알림이 아래 입력창과 겹쳐 가려졌습니다. 위쪽 머리줄 아래로 옮겼습니다.
- 이미지 생성 대상에서 두 번째 이미지가 프롬프트에 들어가지 않았습니다. "함께 섞을 이미지" 묶음으로 적습니다.
- 첫 화면에서 직접 올린 이미지를 보내면 화면이 새 대화로 바뀌는 순간 그 이미지의 임시 주소가 정리되어, 기록 썸네일이 깨졌습니다. 보낸 첨부는 정리 대상에서 뺍니다.

## 상태로 가는 방법

새로고침 직후 기준입니다. 활용할 때 이 줄로 바로 그 상태를 띄웁니다.

- r1 예시 칩 채우기: 첫 화면 "회의록 요약 지시문", 입력칸과 용도, 대상이 채워지고 초점이 입력칸으로
- r6 용도와 대상 메뉴: 입력창 아래 "+ 용도"(`용도 고르기`)와 "대화형 AI", 메뉴가 위로 떠오름
- r6 쓰는 중과 멈춤: 예시 칩 뒤 Enter(`프롬프트 만들기`), 약 0.5초 읽는 중 뒤 약 3초 동안 결과가 쓰임. 그동안 "쓰기 멈추기"
- r6 결과 뒤 복사와 다듬기: 결과를 끝까지 기다리면 상자 옆 "프롬프트 복사"와 내려받기, 아래 "짧게 줄이기" 같은 제안. 640px 이하에서는 두 버튼이 상자 아래로
- r1 변수 패널: 결과 아래 변수 줄을 펼쳐 값을 넣으면 결과 상자에 바로 반영, "채운 프롬프트 복사"
- r4 첨부 썸네일: 첫 화면 "이 사진 분위기로 그리기", 입력창 위에 썸네일과 "이미지 붙이기" 칸, 대상이 이미지 생성으로
- r5 이미지 분석 카드: 위 첨부 상태에서 Enter, 요청 말풍선 아래 분석 카드(주요 색, 스타일, 비율과 크기)와 "색 코드 복사"
- r6 기록 거르기: 머리줄 "기록" 탭에서 대상으로 거르고 행을 누르면 그 대화가 열림. 결과를 쓰는 중에는 다른 기록을 열 수 없다는 안내
