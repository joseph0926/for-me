# 손질 (이미지 에디터 앱(PC) 레퍼런스 구현)

- 주제 id: `2026-11-23-image-editor`
- 플랫폼: PC 데스크톱 앱. 주제 형식에 데스크톱 값이 없어 `web`으로 두고 휴대폰 틀 없이 창 전체를 씁니다. 휴대폰 너비에서는 도구 열이 아래 줄로, 조정 패널이 작업 화면 아래로 내려갑니다.
- 주제: 사용자가 정했습니다("이미지 에디터 앱 (pc용)"). 2026-11-23에 사용자가 요청한 네 주제 중 둘째이고, 같은 날 사용자가 이 주제까지만 만들기로 범위를 줄였습니다.
- 선택: r3, r1, r2, r5 조합. 사용자가 아니라 AI가 골랐습니다.
- 제품 이름 "손질"은 가상입니다. 같은 저장소의 [개인용 이미지 편집기](../../../screen-note/README.md)와는 별개의 레퍼런스입니다.

## 고른 이유

PC 편집기의 핵심은 자르고 바로잡기, 빛과 색 조정, 필터, 표시 넣기, 원본과 비교, 저장입니다. 자르기와 수평 다이얼은 Microsoft 사진(r3), 묶음별 조정 패널은 Pixelmator Pro(r1), 원본 비교 막대와 프리셋 강도는 Lightroom(r2)이 실제 제품 화면으로 가장 분명히 보여 줬습니다. 필터를 사진 아래 같은 사진의 썸네일 줄로 고르는 흐름은 실제 제품 캡처에서 데스크톱 화면을 찾지 못해 Dribbble 시안(r5)에서 가져왔습니다.

- 사용자 취향(tastepin)의 이미지 편집기 값이 "도구는 왼쪽 세로 아이콘 열, 고른 도구의 설정은 위 옵션 막대, 빈 작업 공간 전체를 눌러 열기"여서, r3의 위쪽 도구 탭은 고르지 않고 자르기 화면만 가져왔습니다.
- 뺀 후보: 그림판(r4)의 리본과 레이어는 이 주제의 사진 보정 흐름보다 그리기 쪽이고, 레이어는 서버 없이 만들기에 범위가 큽니다. Photty(r6, r8)의 프리셋 목록은 r2와 r5가 맡은 부분과 겹치고, Pixlr 시안(r7)의 왼쪽 슬라이더는 r1과 겹칩니다.

## 레퍼런스별로 가져온 부분

- **r3 Microsoft 사진, 자르기:** 모서리와 변 가운데 손잡이, 3x3 안내선, 틀 밖을 어둡게 덮기, 사진 아래 각도 값과 눈금 다이얼, 결과 크기 이름표(1334 x 1334), 비율 고르기, 90도 회전, 좌우와 상하 뒤집기. 위쪽 머리줄의 배율 묶음과 되돌리기, 다시 하기, 오른쪽 저장.
- **r1 Pixelmator Pro, 조정 패널:** 묶음(빛, 색, 효과)마다 제목, 되돌리기 아이콘, 켜고 끄는 토글. 이름과 값을 한 줄에 두고 그 아래 막대를 두는 슬라이더 행. 패널 맨 아래 초기화.
- **r2 Lightroom, 비교와 강도:** 사진을 세로 선으로 나눠 왼쪽 원본, 오른쪽 편집 이름표를 붙이고 가운데 원형 손잡이로 끄는 비교 막대. 프리셋의 강도 막대.
- **r5 Image Filter Concept, 필터 줄:** 필터 도구에서 사진 아래에 같은 사진으로 그린 필터 썸네일 줄과 고른 칸 표시.

## 가져오지 않은 부분

- 제품 이름, 로고, 브랜드 색(Microsoft의 하늘색 저장 단추, Pixelmator의 파랑 토글, r6과 r8의 보라)과 서체.
- r3의 지우기(Erase)와 배경 제거, r1의 ML Enhance, 색 바퀴와 선택 색상, 레이어, r2의 마스크, AI 잡티 제거, 검색과 별점.
- 실제 파일 저장소. 연 이미지와 편집은 브라우저 메모리에만 있고, 결과는 내려받기나 클립보드로 꺼냅니다.
- 레퍼런스에 없던 부분: 펜, 글, 사각형과 화살표 표시와 그 고르기와 옮기기, 붙여넣기와 끌어 놓기로 열기, 견본 사진은 이 앱에서 정했습니다.

## 동작

- 열기: 빈 작업 공간 전체를 누르거나, 파일을 창에 끌어 놓거나, Ctrl+V로 붙여 넣거나, 아래 견본 네 장 중 하나를 누릅니다. 이미지가 아니거나 50MB를 넘거나 열 수 없는 파일은 이유를 알립니다. 여러 파일을 놓으면 첫 파일만 엽니다. 편집한 것이 있으면 머리줄 "열기"를 3초 안에 한 번 더 눌러야("편집 버리고 열기") 다른 이미지를 엽니다.
- 원본을 바꾸지 않습니다. 편집 내용(회전, 뒤집기, 수평, 자르기, 조정, 필터, 표시)을 값으로 들고 있다가 화면과 저장에서 같은 함수로 다시 그립니다.
- 자르기와 회전(C): 비율(자유, 원본, 1:1, 4:3, 3:2, 16:9, 9:16)을 고르면 그 비율로 가장 크게 가운데에 맞춥니다. 수평 다이얼은 끌어서 -45~45도, 방향키로 0.1도(Shift는 1도), 두 번 누르면 0도입니다. 기울인 만큼 이미지를 키워 빈 모서리가 보이지 않게 합니다. 90도 회전은 자르기 범위를 새로 시작합니다.
- 조정(A): 노출, 대비, 밝은 영역, 채도, 색온도, 색조, 비네트, 바랜 느낌. 막대를 두 번 누르면 0으로 돌아가고, 묶음 토글을 끄면 값은 남긴 채 화면에서만 뺍니다.
- 필터(F): 원본, 맑음, 노을, 새벽, 필름, 선명, 흑백, 느와르, 바랜 사진. 강도 0~100%는 조정 값 위에 더해집니다.
- 펜(P), 글(T), 도형(U): 표시는 원본 이미지 좌표로 저장해 나중에 자르거나 돌려도 이미지와 함께 움직입니다. 그리는 순간 화면에서 반듯하게 보이도록 사각형은 화면 기준 네 꼭짓점을, 글은 그때의 회전을 상쇄한 값을 저장합니다. 굵기와 글자 크기는 연 이미지의 긴 변에 비례한 값에서 시작합니다.
- 고르기(V): 표시를 눌러 고르고 끌어 옮깁니다. 위 옵션 막대에서 고른 표시의 색, 굵기나 크기를 바꾸고 지우기, Delete로 지웁니다. 글은 두 번 눌러 고칩니다.
- 비교(\, 머리줄 단추): 왼쪽은 조정과 필터, 표시를 뺀 원본, 오른쪽은 편집입니다. 자르기 중에는 쓸 수 없습니다.
- 되돌리기: Ctrl+Z, 다시 하기 Ctrl+Shift+Z나 Ctrl+Y. 막대나 다이얼을 끄는 동안의 변경, 표시 옮기기는 한 번으로 합칩니다. 기록은 100단계까지입니다.
- 배율: + - 0(맞춤) 1(100%), 머리줄의 배율 단추. 맞춤은 원본보다 키우지 않습니다.
- 저장: PNG 내려받기(Ctrl+S), JPEG 내려받기(품질 0.92), 이미지 복사. 모두 원본 해상도에서 자른 크기로 다시 그립니다. 클립보드 권한이 없으면 내려받기를 쓰라고 알립니다.

## AI 피드백 한 번에서 고친 것

- 수평을 기울인 뒤 사각형을 그리면 화면에서 기울어진 사각형이 그려졌습니다. 원본 좌표의 두 점이 아니라 화면 기준 네 꼭짓점을 원본 좌표로 저장합니다. 같은 까닭으로 글도 그때의 회전을 상쇄해 저장합니다.
- 글 도구로 사진을 누르면 입력칸이 열리자마자 닫혀 글을 넣을 수 없었습니다. 누른 직후 브라우저가 초점을 본문으로 옮기며 입력칸이 닫힌 것이라, 그 누르기의 기본 동작을 막습니다.
- 창 자체에서 온 키 이벤트에서 단축키 처리가 오류를 냈습니다. 입력 대상이 요소일 때만 입력칸 여부를 봅니다.

## tastepin으로 정한 것

이 주제는 갤러리 주제에서 받은 공통 값과 이미지 편집기 전용 값을 처음부터 적용해 만들었습니다.

- 도구는 왼쪽 세로 아이콘 열(휴대폰에서는 아래 줄)에 두고 고른 도구의 바탕을 밝힙니다. 아이콘에 400ms 올리거나 키보드 초점이 오면 오른쪽에 이름과 단축키 말풍선을 띄우고, 한 번 뜬 뒤 옆 아이콘으로 옮기면 기다리지 않습니다. 터치에서는 띄우지 않습니다.
- 위 옵션 막대에는 고른 도구의 설정만 둡니다. 빈 작업 공간은 안쪽 전체를 눌러 열 수 있게 점선 경계와 아이콘으로 표시합니다.
- 바탕 #f3f5f8와 #101318, 강조는 본문색, 글자 14px 이상, 제목 굵기 650, 모서리 6px. 사진 색을 바르게 보도록 작업 화면만 어두운 회색입니다.
- 비율과 도형 모양은 밑줄이 미끄러지는 단일 선택, 저장 메뉴는 버튼 쪽에서 0.96배로 펼치고 가리킨 항목을 옅은 면이 따라갑니다. 알림은 오른쪽 아래에 쌓습니다. 다른 이미지 열기는 제자리 두 번 누르기입니다.
- 따르지 않은 값: 없음. 조정 패널의 묶음 토글은 r1의 구조입니다.

## 확인하지 못한 것

- 내려받은 파일을 열어 결과 픽셀을 비교하지 않았습니다. 내려받기 알림이 뜨는 것까지 봤습니다.
- 이미지 복사는 브라우저 클립보드 권한에 따라 달라 실행 결과를 확인하지 않았습니다.
- 필터 도구에서 저장 알림이 필터 썸네일 줄의 오른쪽 끝을 잠시 가립니다.

## 상태로 가는 방법

새로 고침 직후, 1024px 너비 기준입니다.

- 빈 작업 공간: 새로 고침 직후 화면, 가운데 점선 안 아무 곳이나 누르면 파일 고르기
- r3 자르기 틀과 다이얼: 견본 "바위 해안"을 열고 C, 위 "1:1", 아래 다이얼을 왼쪽으로 끌기, 틀 안쪽을 끌어 옮기기
- r1 조정 패널: A, "노출" 막대를 오른쪽으로 끌기, "빛" 제목 옆 토글 끄기
- r5 필터 줄: F, 아래 "필름" 썸네일, 위 "강도" 막대
- r2 비교 막대: 머리줄 비교 단추(나뉜 사각형 아이콘), 가운데 원형 손잡이를 끌기
- 표시: U로 사각형을 끌어 그리고 T로 사진을 눌러 글 입력 후 Enter, V로 사각형을 끌어 옮기기
- 도구 이름 말풍선: 왼쪽 도구 아이콘에 마우스를 올려 잠시 기다리기
- 다른 이미지 열기 확인: 편집한 뒤 머리줄 "열기", "편집 버리고 열기"로 바뀐 단추를 3초 안에 한 번 더
