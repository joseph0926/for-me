# 말결 (SNS 앱 레퍼런스 구현)

- 주제 id: `2026-11-18-sns`
- 플랫폼: 앱 (데스크톱에서는 갤럭시 S26 기본형을 본뜬 프레임, 휴대폰 너비에서는 화면 전체)
- 선택: r1 하나로 결정. "카드 없이 얇은 구분선으로 나눈 글 중심 피드와 피드 안 글쓰기"

## r1에서 가져온 부분

- 홈 피드 맨 위의 글쓰기 줄: 내 프로필 사진과 아이디 아래 "새로운 소식이 있나요?" 입력. 피드 안에서 바로 쓰고 게시하면 목록 맨 위에 펼쳐지며 붙습니다.
- 카드 없는 글 줄: 프로필 사진 열과 본문 열, 아이디와 시간, 본문, 좋아요와 답글과 리포스트와 공유 수를 한 줄에 작게 둔 밀도. 글 사이는 얇은 구분선만 둡니다.
- 게시물 상세: 본문 아래 투표 막대(투표 전에는 선택지, 투표 후에는 비율 막대), '인기' 정렬 답글 목록, 하단에 고정된 '답글 달기...' 입력창과 그 아래 탭 막대.
- 커뮤니티 화면: 제목 옆 검은 '가입' 버튼, 멤버 수와 활동 중 인원, 커뮤니티 안 글쓰기 줄, '인기 게시물' 정렬 아래 같은 형식의 글 목록.
- 라벨 없는 다섯 아이콘 하단 탭과 가운데 회색 바탕의 글쓰기 버튼.

## 가져오지 않은 부분

- 제품 이름, 로고, 아이디와 사진: 가상의 이름 "말결"과 글자 워드마크, 가상의 사용자와 글, 이름 글자 아바타를 씁니다.
- 브랜드 색: 인증 배지와 커뮤니티 이름의 파란색, 활동 중 표시의 초록 점은 쓰지 않았습니다. 흑백 바탕에 좋아요 빨강 하나만 강조색으로 씁니다.
- 아바타 옆 '+' 팔로우 배지, 글 사이를 잇는 스레드 세로선, 답글 입력창의 사진과 GIF 버튼, 상세 화면의 알림 버튼은 넣지 않았습니다.
- 앱스토어 이미지 위의 광고 문구.

## 동작

- 좋아요와 리포스트: 누르면 수가 바뀌고 좋아요 하트가 튀어 오릅니다.
- 글 줄을 누르면 상세가 오른쪽에서 밀려 들어오고, '뒤로'로 돌아갑니다. 탭마다 쌓인 화면과 스크롤 위치를 따로 유지하고, 보고 있는 탭을 다시 누르면 첫 화면으로 돌아갑니다.
- 투표: 한 번 고르면 비율 막대가 늘어나며 내 선택은 검은 막대로 표시합니다.
- 상세에서 답글을 보내면 목록에 붙고 그 자리로 스크롤합니다. 정렬은 인기와 최신을 고를 수 있습니다.
- 답글 수는 저장하지 않고 실제 답글 목록에서 셉니다. 피드에 보이는 수와 상세에서 열리는 답글 개수가 항상 같습니다. 좋아요, 리포스트, 공유 수와 팔로워, 멤버 수는 목록을 열 수 없는 숫자라 값으로만 둡니다.
- 글쓰기 탭은 아래에서 올라오는 시트로 열리고, 게시하면 홈 첫 화면으로 돌아갑니다.
- 검색은 계정 추천과 팔로우, 글과 계정 검색. 활동은 종류별 필터와 맞팔로우. 프로필은 내 글, 답글, 리포스트 탭이며 새로 쓴 글이 바로 보입니다.
- 공유는 링크를 클립보드에 복사하고 결과를 알림으로 보여 줍니다.
- 서버 없이 메모리에만 저장하므로 새로고침하면 처음 상태로 돌아갑니다. 라이트와 다크 모드는 기기 설정을 따릅니다.
