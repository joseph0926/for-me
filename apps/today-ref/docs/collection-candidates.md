# 프런트엔드 UI 수집 후보

현재 프런트엔드 앱의 진입 흐름, 메뉴 연결과 화면 코드에서 실제 사용을 확인한 요소를 정리했습니다. 아래 목록은 이후 수집을 위한 후보이며, 외부 제품 화면 조사나 캡처는 아직 하지 않았습니다.

- 기준일: 2026-11-27
- 범위: 실제 화면에 연결된 공통 화면 틀과 운영 화면의 재사용 요소
- 제외: 테스트에서만 쓰이거나 정의만 있고 화면에서 참조되지 않은 요소, 라이브러리 내부 구현

| 후보                  | 나중에 확인할 화면과 상태                                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 앱 진입과 보호 화면   | 타일형 시작 화면, 인증 전후 화면, 권한 거부, 오류와 찾을 수 없는 화면, 첫 로딩                                                             |
| 상단과 좌측 메뉴      | 계층 메뉴, 선택 상태, 접힘과 펼침, 메뉴 검색과 결과 없음, 환경 선택, 탭 전환                                                               |
| 표와 목록             | 검색과 조건 선택, 날짜 범위, 정렬, 페이지 이동, 열 표시 조정, 행 선택과 묶음 작업, 상태 표시                                               |
| 입력과 편집           | 글자, 숫자, JSON 입력, 검색형 선택, 날짜 선택, 체크 상자, 라디오 버튼, 전환, 범위 조절, 여러 줄 입력, 파일 올리기, 검증 오류와 조건부 입력 |
| 확인 창과 보조 메뉴   | 변경 확인, 경고, 추가, 편집, 삭제 창, 옆 패널, 펼침 메뉴, 도움말 말풍선, 명령 목록                                                         |
| 상태 안내             | 로딩 표시, 자리 표시 뼈대, 진행 표시, 비어 있음, 조회 오류, 안내문과 알림                                                                  |
| 요약과 분석           | 요약 카드, 지표, 차트와 추세 비교, 상태 배지                                                                                               |
| 이력과 비교           | 변경 이력, 파일 목록, 차이 보기, 버전 비교, 병합과 충돌 해결, 게시 환경 선택                                                               |
| 일괄 처리와 파일 흐름 | 여러 항목 수정, 가져오기와 내보내기, 업로드 결과와 실패 처리                                                                               |
