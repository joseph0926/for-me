환경: macOS(Darwin 27.2.0), Node 24.22.3, pnpm 12.21.0. 브라우저 확인은 Claude 데스크톱 앱의 내장 브라우저입니다.

| 검사 | 결과 |
|---|---|
| `pnpm test` | 통과 12개. 형식 규칙(레퍼런스 24개와 25개, 폴더와 id 불일치, 없는 날짜, 캡처 이름의 경로, 하나로 결정과 조합의 항목 규칙, 선택과 상태의 불일치), 잘못된 주제 뒤 목록 유지, 캡처 누락은 경고, 이미지가 아닌 파일과 5MB 초과는 오류, 확정한 주제의 완성작 폴더 누락 |

## 2026-11-18 AI 사용자 역할로 세 주제 시험 실행

사용자 요청으로 AI가 사용자 역할을 맡았습니다. 선택과 피드백은 사용자의 판단이 아닙니다. 수집과 제작은 하위 에이전트가 하고, 고르기와 피드백, 확인은 내장 브라우저에서 직접 조작했습니다.

| 주제 | 레퍼런스 | 선택 | 1차 피드백 | 수정 후 확인 |
|---|---|---|---|---|
| 대시보드 웹(웹) | 10개(제품 4, 사이트 6) | 조합 3개(Vercel, Plausible, Linear). Linear 부분은 비워 두고 AI 제안을 받음 | 필터 때 목록 글자가 늘어나 일그러짐, 7일 그래프가 점 7개라 빈약, 375px 미확인 | 필터 때 막대만 움직임, 7일은 3시간 단위 점 56개, 좁은 너비에서 한 열 정리 |
| SNS 앱(앱) | 10개(제품 4, 사이트 6) | 하나로 결정(Threads), 메모 입력 | 답글 수 3인데 상세에 답글 없음 | 답글 수를 실제 목록에서 계산, 첫 글 3과 3 일치 |
| 숙소 예약 웹(웹) | 11개(제품 5, 사이트 6) | 조합 4개(Airbnb, 직방, Agoda, Baymard), 부분 모두 직접 입력 | 지도 가격 마커 겹침, 카드 사진을 눌러도 상세로 가지 않음 | 겹치는 마커는 "n곳"으로 묶임, 사진 클릭으로 상세 열림 |

- 세 완성작 모두 `pnpm build` 통과, 내장 브라우저 콘솔 오류 없음.
- 수집에서 막힌 곳: 여기어때(Cloudflare)와 야놀자 웹(차단 화면)은 App Store 스크린샷으로 대신했고, Baymard 유료 사례와 Dribbble의 curl 요청(봇 검사 응답)은 쓰지 않았습니다. SNS 주제의 Dribbble 이미지는 일반 화면 없는 Chrome에서 열린 페이지에서 받았습니다.
- 화면 없는 Chrome은 창을 500px보다 좁게 그리지 못해, 휴대폰 너비는 내장 브라우저나 개발자 도구 연결, iframe으로 확인했습니다.
- 실제 휴대폰 기기에서는 확인하지 않았습니다.

### 확인하지 못한 것

- 밝은 화면 모드의 실제 표시. 색 값만 정의했습니다.
- Windows 사본에서의 설치와 실행.

## 2026-11-18 숙소 예약 완성작 사진 교체

사용자 요청으로 SVG 일러스트를 Unsplash 무료 사진 38장으로 바꿨습니다.

- 사용자 Chrome에서 Unsplash 검색 페이지를 무료 필터로 열어 조합마다 후보 7장을 읽고, 한 장에 모은 비교 화면에서 눈으로 골랐습니다. Unsplash 내부 검색 API를 직접 부르는 방식은 권한 검사에서 거부되어 쓰지 않았습니다.
- 1200px 너비 JPG로 내려받았고 모두 JPEG 형식임을 확인했습니다(합계 6.4MB). 출처는 완성작 README의 사진 출처 표에 있습니다.
- 욕실 사진이 대표 사진이 되던 순서를 한 칸 뒤로 미뤘습니다. 대표 사진이 겹치는 숙소는 일러스트 때와 같이 남아 있습니다(예: 모텔 3곳이 같은 침실 사진).
- 빌드 통과. 내장 브라우저에서 1440px 결과 화면과 상세, 375px 결과 화면을 확인했고 깨진 이미지와 가로 넘침, 콘솔 오류는 없었습니다.
