# 규칙이 생긴 사례

[진행 절차](agent.md)와 [다듬기 루프](refine.md)의 규칙 중 실제로 겪은 일에서 나온 것의 경위입니다. 절차 문서에는 규칙 문장과 이 문서의 번호만 둡니다. 번호는 C1부터 붙이고 재사용하지 않습니다. 새 경위는 아래에 이어 붙이고, 규칙을 없애도 경위는 지우지 않습니다.

## C1 저장한 캡처를 직접 열어 보기

2026-11-18 숙소 주제 수집에서 여기어때는 Cloudflare 차단 페이지가, Airbnb 첫 화면은 할인 팝업이 캡처됐습니다. 규칙: [캡처 저장](agent.md#캡처-저장)의 "저장한 캡처는 하나씩 직접 열어 봅니다".

## C2 curl만 막히고 Chrome에서 열리는 페이지

2026-11-18 Dribbble은 curl에 봇 검사 응답을 줬지만 화면 없는 모드의 Chrome 명령 그대로는 페이지가 열렸습니다. 사용자가 이 경우를 쓰되 보고에 적는 기준을 유지하기로 했습니다. 규칙: [캡처 저장](agent.md#캡처-저장)의 차단과 CAPTCHA 항목.

## C3 시안의 배지와 요금 카드 모양

2026-11-26 인게임 샵의 포인트 충전 화면이 Dribbble 시안의 "인기", "최고 효율" 배지를 가져와 요금 카드 템플릿으로 읽혔습니다. 규칙: [고르기](agent.md#3-고르기)의 "시안은 배치와 정보 구성만".

## C4 핵심 경험을 보여 주는 레퍼런스를 빼지 않기

2026-11-26 인게임 샵이 시즌 패스의 보상 줄 레퍼런스(r6)를 빼고 등급 비교표(r4)만 가져와 SaaS 요금제 비교표처럼 읽혔습니다. 규칙: [고르기](agent.md#3-고르기)의 핵심 경험 항목.

## C5 빈자리 값과 tastepin 화면 전체 값으로의 수렴

2026-11-26에 완성작 11개 중 10개가 Pretendard였고, 10개가 모서리 6px였습니다. 사진 갤러리와 이미지 편집기는 바탕과 강조색까지 tastepin 화면 전체 값과 같았습니다. 같은 날 소급 다듬기는 큰 모서리를 모두 6px로 바꿨고(인게임 샵, 숙소 예약 등), 그 뒤 완성작 11개 중 10개가 6px을 가장 많이 썼으며, 11개 모두 누름 0.95배와 같은 곡선을, 9개가 흐림 등장을 썼습니다. tastepin 화면 전체 값을 덮으면 수렴한다는 판단은 2026-11-24에 했습니다. 규칙: [고르기](agent.md#3-고르기)의 정체성 항목과 [tastepin으로 다듬기](agent.md#6-tastepin으로-다듬기)의 지키는 값.

## C6 다른 화면 안에서 열리는 주제의 들어오고 돌아가는 상태

2026-11-26 인게임 상점 비교본 두 안이 상점 화면만 있어 게임 로비에서 들어가고 돌아오는 경험을 비교할 수 없었습니다. 규칙: [만들기](agent.md#4-만들기)의 인게임 상점 항목.

## C7 고를 때 적지 않은 컨트롤

2026-11-26에 팩 6개짜리 화면의 필터 칩 4개와 즐겨찾기 별이 불필요하다는 판정을 받았습니다. 규칙: [만들기](agent.md#4-만들기)의 `part`에 없는 컨트롤 항목.

## C8 생성 그림

2026-11-26 인게임 샵의 사용자 판정 네 건이 모두 생성 그림을 가리켰습니다. 규칙: [만들기](agent.md#4-만들기)의 화면에 쓸 그림 항목.

## C9 재설계 전에 레퍼런스를 다시 보기

2026-11-25 블로그 완성작을 재설계하며 레퍼런스를 보지 않고 이름에서 장식을 지어내자 사용자가 전보다 나쁘다고 판정했습니다. 규칙: [사용자 피드백](agent.md#8-사용자-피드백)의 재설계 항목.

## C10 하위 에이전트의 지적에 없는 수정

2026-11-28 조인 지시서로 숙소 판정 당시 사본을 다시 돌렸을 때, 하위 에이전트가 밑줄을 빼는 지적을 고치면서 "후기 612개"의 띄어쓰기까지 지워 "후기612개"로 만들었습니다. 보고와 `findings.json`에는 나오지 않았고, 상위 세션이 diff를 읽다가 찾아 되돌렸습니다([검증 기록](verification.md#2026-11-28-조인-다듬기-지시서-다시-돌리기)). 규칙: [refine.md 5절](refine.md#5-findingsjson-형식)의 diff 확인 항목.

## C11 Claude in Chrome 스크린샷 시간 초과

2026-11-27 게임 상점 수집에서 사용자가 Claude in Chrome으로 빈 곳을 다시 찾아 달라고 했을 때, 스크린샷과 확대 캡처가 이미지만 있는 페이지와 일부 기사 페이지에서 시간 초과로 실패했습니다. 그 화면은 이미지 서버 주소를 curl로 받아 채웠습니다([검증 기록](verification.md#claude-in-chrome으로-빈-곳-다시-찾기)). 2026-11-28 사용자 요청으로 실행면별 도구를 공식 문서와 위키로 확인해 절차에 넣었습니다. 규칙: [사용자 Chrome으로 볼 때](agent.md#사용자-chrome으로-볼-때)의 시간 초과 항목.
