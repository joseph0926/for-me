# 동영상 앱

## 목표

for-me의 첫 구현 대상입니다. 평소 사용하는 동영상 앱을 대체해 직접 쓰고 유지보수합니다.

## 구현 범위

- 안드로이드를 먼저 개발하고, 이후 Windows와 macOS로 확장합니다.
- 첫 대상은 휴대폰에 저장한 동영상 파일입니다.
- 기술은 안드로이드에서의 사용과 유지보수를 기준으로 선택합니다.
- PC와의 코드 재사용은 현재 고려하지 않습니다.

## 파일 지원 목표

- 다양한 영상과 자막 형식의 재생을 목표로 합니다.
- 현재 실제 사용하는 파일의 형식은 미확인입니다.
- 지원 목표와 실제 기기에서 재생을 확인한 형식은 구분합니다.
- 파일 확장자와 내부 영상, 음성의 압축 방식, 자막 표시를 함께 확인합니다.

## 테스트 기기

- 갤럭시 S25
- 갤럭시 A16로 추정되는 기기: 정확한 모델명 확인 필요

두 기기 모두 소프트웨어 업데이트를 꾸준히 적용하고 있습니다. 설치된 안드로이드 버전은 미확인입니다.

## 현재 사용 흐름

앱 열기 → 시스템 파일 선택기로 영상 열기 → 재생 → 홈이나 보관함에서 이어보기

보관함에서 최근 영상 최대 20개를 제목으로 검색하거나 **폴더별 영상**을 엽니다. **폴더 추가**에서 허용한 폴더를 고르고, 하위 폴더를 한 단계씩 열어 영상을 재생합니다.

## 첫 버전의 목표

### 폴더와 영상 목록 목표

- 사용자가 접근을 허용한 폴더의 영상 목록을 보여줍니다.
- 목록에서 재생할 영상을 선택합니다.
- 시스템 파일 선택기로 영상 하나를 직접 엽니다.

Android 11 이상에서는 시스템 폴더 선택기로 `Download` 폴더 전체의 접근 권한을 받을 수 없습니다. 그 안의 영상은 개별 파일로 선택합니다.

### 재생 화면

- 선택한 영상의 화면과 소리를 재생합니다.
- 일시정지하고 다시 재생합니다.
- 마지막 재생 위치를 저장해 앱을 닫은 뒤에도 이어봅니다.

### 확인 기준

- 접근을 허용한 폴더에서 영상을 선택해 재생할 수 있습니다.
- 시스템 파일 선택기로 선택한 영상도 재생할 수 있습니다.
- 일시정지한 뒤 다시 재생할 수 있습니다.
- 영상 중간에 앱을 닫고 다시 열어 같은 영상을 선택하면, 마지막으로 보던 위치에서 이어볼 수 있습니다.
- 기기를 다시 시작한 뒤에도 접근 권한이 유지되는 파일은 이어볼 수 있습니다.
- 앱을 업데이트한 뒤에도 저장한 재생 위치와 유지 가능한 파일 접근 권한이 보존됩니다.
- 파일 접근을 허용하지 않았거나 영상 파일이 사라진 경우, 이유를 알리고 다시 선택할 수 있습니다.

## 다음에 확인할 항목

- 테스트 기기의 정확한 모델명과 안드로이드 버전
- 다양한 영상과 자막으로 구성한 재생 확인용 파일
- 선택한 재생 기술의 파일 지원 범위와 기기별 동작

현재 구현한 화면과 조작을 실제 기기에서 확인하고, 자막 기능을 확장하기 위한 형식별 샘플을 준비합니다. 세부 검사 항목과 결과는 [검증 기록](verification.md)에 남깁니다.

## 구현 상태

2026-11-20 기준입니다. 아래 기능을 구현했습니다. 가상 기기에서 확인한 동작과 실제 휴대폰의 지원 범위는 구분합니다.

- 시스템 파일 선택기로 영상 열기
- 보관함에서 폴더 추가, 하위 폴더 탐색, 영상 재생과 목록 복귀. 지속 읽기 권한을 받은 폴더는 앱을 다시 열어도 표시합니다.
- 영상 재생, 일시정지, 재생 위치와 10초 이동
- 영상별 재생 위치 저장, 썸네일을 포함한 홈과 보관함, 제목 검색
- 영상 터치로 재생 상태 전환, 화면 잠금과 해제
- 앱을 벗어날 때 일시정지와 위치 저장
- 파일 접근 실패 안내와 재선택
- 내장 자막 선택과 끄기, 외부 UTF-8 SRT 열기(최대 2 MiB)
- 0.1초 단위 자막 시각 조절과 초기화, 외부 SRT 글자 크기 조절
- 영상별 자막 선택과 설정 복원. 외부 파일을 다시 읽을 수 없으면 재선택 안내

외부 ASS와 SMI, 문자 인코딩 선택은 후속 범위입니다.

## 기술 선택

2026-11-13에 Kotlin, Jetpack Compose, libVLC, Room을 사용하는 구성으로 결정했습니다. 2026-11-14에 시제품 구현을 시작했습니다.

- Kotlin: 앱의 동작 구현
- Jetpack Compose: 폴더와 영상 목록, 재생 조작 화면 구현
- libVLC: 영상, 음성, 자막 재생. 첫 검증 버전은 `3.7.7`
- Room: 영상별 마지막 재생 위치 저장
- Android의 시스템 폴더 및 파일 선택 기능: 사용자가 허용한 파일에 접근

선택 근거와 배포 파일 검사 결과는 [기술 조사](research.md)에 있습니다. 라이브러리 버전은 프로젝트 설정 시 호환성을 확인하고 고정합니다.

## 화면과 조작을 정하는 방식

직접 쓰는 데 필요한 기능을 하나씩 정하고, 그에 맞춰 화면과 조작을 쌓아갑니다.

VLC의 화면과 조작, MX Player의 광고는 직접 만들게 된 배경입니다. 기존 앱은 기능과 구현 방법을 참고하는 데 사용합니다. 설계는 필요한 기능에서 시작합니다.

## 2026-11-17 화면 리디자인

Viewgrain MCP로 `scene-001` v1의 홈, 세로 재생, 가로 재생과 `frame-002` v1의 컬렉션 목록 원본을 읽고 화면을 새로 구성했습니다. Viewgrain은 2026-11-18에 [폐기](../../../docs/retired-viewgrain.md)했고 레퍼런스 원본은 저장소에 남아 있지 않습니다.

- 홈: 마지막 영상의 큰 썸네일과 이어서 재생, 가로로 넘기는 이어보기 목록, 최근 영상 목록.
- 보관함: 좁은 썸네일과 제목, 재생 시간을 한 행에 배치하고 제목으로 검색합니다. 현재 저장소가 제공하는 최근 20개 기록을 대상으로 합니다.
- 재생: 영상 위 제목과 뒤로 가기, 양 끝 시간 표시, 배경 없는 재생 조작. 세로와 가로 모두 아래 중앙에 조작을 모읍니다. 영상 영역을 누르면 재생과 일시정지가 전환됩니다. 원본 영상 비율은 유지합니다.
- 빈 목록과 검색 결과 없음, 파일 재선택 안내도 같은 색상과 글자 체계를 사용합니다.
- 영상 이미지는 사용자가 연 파일에서 읽습니다. Android 8.0은 기본 아이콘을 사용하며, 8.1 이상에서도 썸네일 추출이 실패하면 기본 아이콘으로 표시합니다. 캐시는 메모리에만 두고 원본과 저장 구조는 변경하지 않습니다.

레퍼런스의 스트리밍 추천, 라이브, 계정, 전송, 다음 회차 버튼은 로컬 파일 앱의 기능으로 추가하지 않았습니다. 외부 자막 선택과 폴더별 컬렉션은 기존과 같이 미구현입니다. 새 의존성은 추가하지 않았습니다.

## 화면 잠금

재생 화면 오른쪽 위의 자물쇠 버튼으로 잠급니다. 잠금 중에는 영상 터치, 위치 이동과 화면의 재생 조작을 차단하며, 잠그기 전 재생 또는 일시정지 상태를 유지합니다. 화면을 누르거나 시스템 뒤로 가기를 사용하면 잠금 해제 버튼만 나타납니다. 해제 버튼을 눌러야 조작이 돌아옵니다.

회전 중에도 잠금은 유지하고, 다른 영상을 열면 잠금 없이 시작합니다. 화면 읽기 기능의 터치 탐색이 켜져 있으면 해제 버튼을 숨기지 않습니다. 앱 안의 조작 잠금이며 운영체제의 홈, 알림과 전원 기능을 막지는 않습니다.
