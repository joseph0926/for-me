# 동영상 앱

## 목표

for-me의 첫 구현 대상입니다. 평소 사용하는 동영상 앱을 대체해 직접 쓰고 유지보수합니다.

## 구현 범위

- 안드로이드를 먼저 개발하고, 이후 Windows와 macOS로 확장합니다.
- 첫 대상은 휴대폰에 저장한 동영상 파일입니다.
- 기술은 안드로이드에서의 사용과 유지보수를 기준으로 선택합니다.
- PC와의 코드 재사용은 현재 고려하지 않습니다.

## 파일 지원 목표

- 다양한 영상과 자막 형식의 재생을 목표로 합니다.
- 현재 실제 사용하는 파일의 형식은 미확인입니다.
- 지원 목표와 실제 기기에서 재생을 확인한 형식은 구분합니다.
- 파일 확장자와 내부 영상, 음성의 압축 방식, 자막 표시를 함께 확인합니다.

## 테스트 기기

- 갤럭시 S25
- 갤럭시 A16로 추정되는 기기: 정확한 모델명 확인 필요

두 기기 모두 소프트웨어 업데이트를 꾸준히 적용하고 있습니다. 설치된 안드로이드 버전은 미확인입니다.

## 현재 사용 흐름

앱 열기 → 시스템 파일 선택기로 영상 열기 → 재생 → 홈이나 보관함에서 이어보기

보관함에서 추가한 폴더를 바로 열거나 최근 영상 최대 20개를 제목으로 검색합니다. **폴더 추가**에서 허용한 폴더를 고르고, 하위 폴더를 한 단계씩 열어 영상을 재생합니다.

## 첫 버전의 목표

### 폴더와 영상 목록 목표

- 사용자가 접근을 허용한 폴더의 영상 목록을 보여줍니다.
- 목록에서 재생할 영상을 선택합니다.
- 시스템 파일 선택기로 영상 하나를 직접 엽니다.

Android 11 이상에서는 시스템 폴더 선택기로 `Download` 폴더 전체의 접근 권한을 받을 수 없습니다. 그 안의 영상은 개별 파일로 선택합니다.

### 재생 화면

- 선택한 영상의 화면과 소리를 재생합니다.
- 일시정지하고 다시 재생합니다.
- 마지막 재생 위치를 저장해 앱을 닫은 뒤에도 이어봅니다.

### 확인 기준

- 접근을 허용한 폴더에서 영상을 선택해 재생할 수 있습니다.
- 시스템 파일 선택기로 선택한 영상도 재생할 수 있습니다.
- 일시정지한 뒤 다시 재생할 수 있습니다.
- 영상 중간에 앱을 닫고 다시 열어 같은 영상을 선택하면, 마지막으로 보던 위치에서 이어볼 수 있습니다.
- 기기를 다시 시작한 뒤에도 접근 권한이 유지되는 파일은 이어볼 수 있습니다.
- 앱을 업데이트한 뒤에도 저장한 재생 위치와 유지 가능한 파일 접근 권한이 보존됩니다.
- 파일 접근을 허용하지 않았거나 영상 파일이 사라진 경우, 이유를 알리고 다시 선택할 수 있습니다.

## 구현 상태

2026-11-20 기준입니다. 아래 기능을 구현했습니다. 가상 기기에서 확인한 동작과 실제 휴대폰의 지원 범위는 구분합니다.

- 시스템 파일 선택기로 영상 열기
- 보관함에서 폴더 추가, 하위 폴더 탐색, 영상 재생과 목록 복귀. 지속 읽기 권한을 받은 폴더는 앱을 다시 열어도 표시합니다.
- 영상 재생, 일시정지, 재생 위치와 10초 이동
- 영상별 재생 위치 저장, 썸네일을 포함한 홈과 보관함, 제목 검색
- 영상 터치로 재생 상태 전환, 화면 잠금과 해제
- 앱을 벗어날 때 일시정지와 위치 저장
- 파일 접근 실패 안내와 재선택
- 내장 자막 선택과 끄기, 외부 SRT, SMI, VTT, ASS/SSA 열기(최대 2 MiB, UTF-8, UTF-16, CP949)
- 폴더 목록에서 연 영상의 같은 이름 자막 자동 연결
- 0.1초 단위 자막 시각 조절과 초기화, 외부 자막 글자 크기 조절
- 영상별 자막 선택과 설정 복원. 외부 파일을 다시 읽을 수 없으면 재선택 안내

외부 SMI에 대사가 있는 언어가 여러 개면 한국어로 시작하고, 자막 메뉴에서 다른 언어를 고를 수 있습니다. 영상과 자막별로 선택을 복원합니다. 문자 인코딩 직접 선택은 후속 범위입니다.

## 기술 선택

2026-11-13에 Kotlin, Jetpack Compose, libVLC, Room을 사용하는 구성으로 결정했습니다. 2026-11-14에 시제품 구현을 시작했습니다.

- Kotlin: 앱의 동작 구현
- Jetpack Compose: 폴더와 영상 목록, 재생 조작 화면 구현
- libVLC: 영상, 음성, 자막 재생. 첫 검증 버전은 `3.7.7`
- Room: 영상별 마지막 재생 위치 저장
- Android의 시스템 폴더 및 파일 선택 기능: 사용자가 허용한 파일에 접근

선택 근거와 배포 파일 검사 결과는 [기술 조사](research.md)에 있습니다. 라이브러리 버전은 프로젝트 설정 시 호환성을 확인하고 고정합니다.

## 화면과 조작을 정하는 방식

직접 쓰는 데 필요한 기능을 하나씩 정하고, 그에 맞춰 화면과 조작을 쌓아갑니다.

VLC의 화면과 조작, MX Player의 광고는 직접 만들게 된 배경입니다. 기존 앱은 기능과 구현 방법을 참고하는 데 사용합니다. 설계는 필요한 기능에서 시작합니다.

## 2026-11-17 화면 리디자인

Viewgrain MCP로 `scene-001` v1의 홈, 세로 재생, 가로 재생과 `frame-002` v1의 컬렉션 목록 원본을 읽고 화면을 새로 구성했습니다. Viewgrain은 2026-11-18에 [폐기](../../../docs/retired-viewgrain.md)했고 레퍼런스 원본은 저장소에 남아 있지 않습니다.

- 홈: 마지막 영상의 큰 썸네일과 이어서 재생, 가로로 넘기는 이어보기 목록, 최근 영상 목록.
- 보관함: 좁은 썸네일과 제목, 재생 시간을 한 행에 배치하고 제목으로 검색합니다. 현재 저장소가 제공하는 최근 20개 기록을 대상으로 합니다.
- 재생: 영상 위 제목과 뒤로 가기, 양 끝 시간 표시, 배경 없는 재생 조작. 세로와 가로 모두 아래 중앙에 조작을 모읍니다. 영상 영역을 누르면 재생과 일시정지가 전환됩니다. 원본 영상 비율은 유지합니다.
- 빈 목록과 검색 결과 없음, 파일 재선택 안내도 같은 색상과 글자 체계를 사용합니다.
- 영상 이미지는 사용자가 연 파일에서 읽습니다. Android 8.0은 기본 아이콘을 사용하며, 8.1 이상에서도 썸네일 추출이 실패하면 기본 아이콘으로 표시합니다. 캐시는 메모리에만 두고 원본과 저장 구조는 변경하지 않습니다.

레퍼런스의 스트리밍 추천, 라이브, 계정, 전송, 다음 회차 버튼은 로컬 파일 앱의 기능으로 추가하지 않았습니다. 외부 자막 선택과 폴더별 컬렉션은 기존과 같이 미구현입니다. 새 의존성은 추가하지 않았습니다.

## 2026-11-21 동영상 레퍼런스 반영

오늘의레퍼런스 `2026-11-20-video` 완성작(Infuse, nPlayer와 Dribbble 재생기 시안 두 개를 조합)에서, 이 앱에 이미 있는 요소에 맞는 부분만 구조와 값으로 옮겼습니다. 코드와 색, 서체는 가져오지 않았습니다.

- 홈: 계속 시청하기 카드의 둘째 줄을 `지난 시간 / 길이`에서 남은 시간(`12분 남음`, 1분 미만은 `1분 미만 남음`)으로 바꿨습니다. 마지막 영상의 이어서 재생 버튼은 본 비율만큼 바탕을 어둡게 칠합니다.
- 보관함과 최근 영상 행: 오른쪽 재생 표시의 둘레를 본 비율만큼 채웁니다.
- 재생: 조작이 보이면 영상 전체를 50% 어둡게 덮고(위아래는 조금 더), 10초 뒤로, 재생(64dp), 10초 앞으로를 화면 가운데에 반투명 원으로 둡니다. 재생바는 맨 아래에 남깁니다. 2026-11-17의 "아래 중앙에 조작을 모은다"는 배치를 대신합니다.
- 재생바를 끄는 동안 위쪽 막대와 가운데 버튼을 숨기고 덮개를 20%로 옅게 해 장면과 시간 말풍선을 보이게 합니다.
- 끝까지 보면 가운데 버튼이 다시 보기 아이콘(읽기 도구 이름 "처음부터 다시 보기")으로 바뀝니다.

- 재생 속도: 사용자가 보류 항목 중 재생 속도를 골라 추가했습니다. 오른쪽 가장자리 가운데에 빠르게(+), 현재 속도, 느리게(-)를 세로로 둡니다. 단계는 0.5, 0.75, 1, 1.25, 1.5, 2배이고 숫자를 누르면 1배로 돌아갑니다. 1배가 아니면 숫자 바탕을 밝게 칠합니다. 속도는 앱을 쓰는 동안 다음 영상에도 이어지고, 앱을 다시 시작하면 1배입니다. 저장 구조는 바꾸지 않았습니다.

- 두 번 눌러 이동: 사용자가 이어서 골랐습니다. 영상 영역을 1 : 1.2 : 1 비율로 왼쪽, 가운데, 오른쪽으로 나눕니다. 가운데를 한 번 누르면 기존처럼 바로 재생과 일시정지가 바뀝니다. 양옆은 0.26초 동안 두 번째 누르기를 기다려, 두 번 누르면 그쪽으로 10초 이동하고 한 번이면 그 뒤에 재생을 바꿉니다. 이동하면 그쪽 가장자리에 반원 모양 밝은 영역과 누적 초(`10초`, `20초`)를 0.7초 보여 주고, 그동안 같은 쪽을 한 번만 눌러도 10초씩 더 갑니다. 표시 중에는 재생바를 끌 때처럼 위쪽 막대, 가운데 버튼과 속도 조작을 빼고 시간과 재생바만 남깁니다. 표시는 영상 비율로 계산한 영상 자리 안에만 그립니다. 화면 읽기 기능을 켜면 두 번 누르기는 운영체제의 선택 동작이므로 영상 영역은 재생과 일시정지만 바꾸고, 10초 이동은 버튼으로 합니다.

- 다음 영상 버튼: 사용자가 이어서 골랐습니다. 폴더에서 영상을 열면 그 폴더 목록에 보인 순서(하위 폴더 제외)를 재생 선택에 함께 담습니다. 끝까지 보면 다시 보기 아래에 `다음 영상: 제목` 버튼을 두고, 누르면 폴더 목록에서 연 것과 같은 방식으로 다음 영상을 엽니다. 마지막 영상이거나 시스템 선택기, 홈, 보관함 최근 목록에서 연 영상에는 버튼이 없습니다. 재생 중 이전과 다음 이동, 자동 이어 재생은 넣지 않았습니다. 폴더 순서는 앱을 쓰는 동안만 기억하고 저장 구조는 바꾸지 않았습니다.

- 폴더 바로가기: 사용자가 이어서 골랐습니다. 추가한 폴더가 있으면 홈의 계속 시청하기와 최근 영상 사이에 `폴더별 영상` 줄을 두고, 폴더 목록과 같은 순서(이름, 주소)로 136dp 타일을 가로로 놓습니다. 타일은 위쪽 76dp에 그 폴더나 하위 폴더에서 최근에 연 영상의 장면을 45% 밝기로 깔고 폴더 아이콘을, 아래에 폴더 이름을 씁니다. 그런 영상이 없으면 아이콘만 둡니다. 타일을 누르면 그 폴더 안이 바로 열리고 뒤로 가기로 홈에 돌아옵니다. 줄 제목과 화살표는 레퍼런스의 `모두 보기` 대신 보관함으로 갑니다. 홈에서 폴더 내용을 읽지 않으므로 레퍼런스의 영상 개수는 넣지 않았습니다.

- 영상 상세: 사용자가 이어서 골랐습니다. 위쪽에 4:3 장면(가로 화면은 220dp)과 배경으로 이어지는 그라데이션, 반투명 원 안의 뒤로 가기를 두고, 제목 아래 한 줄에 길이, 파일 수정 날짜(올해는 연도 생략), 해상도 표시(짧은 변 기준 `720p`), 형식을 둡니다. 그 아래 화면 폭의 이어보기 버튼(`이어보기 2:28`, 기록이 0이면 `재생`)이 본 만큼 칠해지고, `파일 정보` 표에 영상(해상도, 압축 방식, 초당 장면 수), 음성(채널, 표본 주파수, 압축 방식), 형식, 용량, 수정한 날짜를 둡니다. 트랙 정보는 Android `MediaExtractor`로, 용량과 날짜는 파일 제공자에서 따로 읽어 하나가 실패해도 나머지를 보여 주고, Android가 읽지 못한 트랙은 `확인할 수 없음`으로 둡니다. 원본은 읽기만 합니다. 레퍼런스의 자막 목록과 `처음부터 보기` 버튼은 넣지 않았습니다. 자막은 libVLC만 읽는 형식이 있어 Android 기준으로 `없음`이라고 단정할 수 없고, 처음부터 보기는 재생 화면의 `처음부터`가 맡습니다.
- 보관함의 폴더 묶음(2026-11-21 취향 판정 반영): 사용자가 "터치의 의도에 대한 행동은 가장 즉각적이어야 한다", "버튼이 한 줄을 차지하는 경우는 신중해야 하고 맥락에 맞아야 한다", "버튼을 모두 border-radius 있는 네모난 버튼일 이유가 없다"고 판정했습니다. 보관함 제목 아래 한 줄을 차지하던 테두리 버튼 `폴더별 영상`과 그 뒤의 폴더 목록 화면을 없애고, 보관함 안에 `폴더` 묶음을 두어 추가한 폴더를 행으로 보여 줍니다. 폴더를 여는 단계가 버튼, 폴더 목록, 폴더의 세 번에서 한 번으로 줄었습니다. 폴더 추가는 묶음 제목 오른쪽의 밑줄 글자로, 폴더가 없을 때는 추가 행 하나로 둡니다. 폴더 맨 위에서 뒤로 가면 연 곳으로 바로 돌아갑니다. 같은 이유로 홈 대표 영상의 `상세 정보` 테두리 버튼을 카드와 행과 같은 정보 아이콘으로 바꿨습니다. 사용자 결정으로 썸네일, 카드, 폴더 타일이 쓰는 테마 `medium` 모서리를 10dp에서 6dp로 낮춰, 앱의 모서리 값을 4dp와 6dp 두 단계로 줄였습니다.
- 보관함 정리(2026-11-22 취향 판정 반영): 사용자가 보관함이 "너무 세로로 정리 안 된 느낌"이고 머리 줄의 `+`와 `+ 폴더 추가`가 헷갈린다고 판정했습니다. 보관함은 묶음마다 간격을 따로 두고(행 위아래 11dp, 묶음 사이 28dp), 큰 `보관함` 줄 대신 머리 줄이 화면 이름을 맡습니다. 사용자 확인으로 보관함 머리 줄의 `+`(영상 열기)를 빼고 아래 탭에 맡겼으며, 폴더 추가 행은 폴더 모양 아이콘을 씁니다. 영상 행 제목은 소제목보다 낮은 15sp 500 한 줄입니다. - 들어가는 길: 처음에는 레퍼런스(Infuse)처럼 카드와 행을 누르면 상세가 열리고 재생 원으로 재생하게 바꿨으나, 사용자가 "상세 보기를 따로 버튼으로 빼주세요"라고 정정했습니다. 그래서 카드와 행을 누르면 기존처럼 바로 재생하고, 상세는 대표 영상의 `상세 정보` 버튼(이어서 재생 옆), 계속 시청하기 카드 오른쪽 위의 정보 아이콘(장면 위에 반투명 원), 최근 영상과 보관함 행 오른쪽 끝의 정보 아이콘으로 엽니다. 행의 진행 둘레는 다시 장식으로 둡니다. 상세에서 돌아오면 홈과 보관함 목록의 스크롤 위치를 유지합니다.

레퍼런스 중 폴더 목록 행의 형식과 용량, 날짜와 시청 표시는 현재 범위에 없는 화면이나 기능이라 보류했습니다.

## 화면 잠금

재생 화면 오른쪽 위의 자물쇠 버튼으로 잠급니다. 잠금 중에는 영상 터치, 위치 이동과 화면의 재생 조작을 차단하며, 잠그기 전 재생 또는 일시정지 상태를 유지합니다. 화면을 누르거나 시스템 뒤로 가기를 사용하면 잠금 해제 버튼만 나타납니다. 해제 버튼을 눌러야 조작이 돌아옵니다.

회전 중에도 잠금은 유지하고, 다른 영상을 열면 잠금 없이 시작합니다. 화면 읽기 기능의 터치 탐색이 켜져 있으면 해제 버튼을 숨기지 않습니다. 앱 안의 조작 잠금이며 운영체제의 홈, 알림과 전원 기능을 막지는 않습니다.
