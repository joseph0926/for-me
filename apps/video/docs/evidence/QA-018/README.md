# QA-018 비디오 앱 리디자인 제보 자료

Android 비디오 앱에 웹사이트용 `design-taste-frontend` 2.5.1의 색상과 배치 지침을 적용한 사례입니다. 화면은 Jetpack Compose로 구현했으며, 아래 이미지는 Android 17 가상 기기에서 ADB로 캡처했습니다.

2026-11-20 사용자 의견 원문입니다.

> 색깔, 폰트 배치 모든게 ai-slop으로 보입니다.

## 보관한 파일

- [리디자인 소스 패치](redesign.patch)는 리디자인 직전의 메인 소스를 기준으로 Android 코드, 화면 문구와 문서 등 13개 파일의 변경을 담습니다.
- [리디자인 디버그 APK](redesign.apk)는 해당 화면을 실행할 수 있는 로컬 설치 파일입니다. 앱 버전은 0.1.0(1)이고 SHA-256은 `35ebe86af741183f7c8f6acecd01914041fe19ebfdaa1593041633500c9b32a7`입니다. APK는 Git 추적에서 제외했습니다.

## 메인 앱 롤백 확인

복원한 메인 빌드를 같은 가상 기기에 덮어 설치했습니다. 기존 홈에 영상 두 편과 이어보기 시간이 표시됐고, 등록한 폴더에서 영상을 열어 기존 자막 선택 창과 저장한 표시 시각을 확인했습니다. 같은 폴더의 롤백 전후 비교에서는 화면 상단 100픽셀을 제외한 나머지가 리디자인 직전 캡처와 픽셀 단위로 일치했습니다. [복원한 홈](restored-home.png), [폴더](restored-folder.png), [자막](restored-subtitles.png)

복원한 소스에서 Android Lint, 단위 테스트 20개, 디버그 및 릴리스 빌드가 통과했습니다. 새 디버그 APK의 SHA-256은 `b540602d7ac53712dd42e1b69592bd1124e18a74e8371ba1b05768dc432688b0`입니다. 리디자인 직전 APK와 압축 내부 파일을 비교했을 때 `classes4.dex` 한 파일에 차이가 있었고, 그 안에서 실행 명령이 달라진 곳은 Compose가 MainActivity에 생성한 함수 하나였습니다.
