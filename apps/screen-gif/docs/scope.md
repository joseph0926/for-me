# 화면 녹화 GIF 생성기

## 목표

for-me의 두 번째 앱입니다. 화면의 일부를 녹화해 GIF 파일로 만듭니다. 평소 쓰는 앱을 직접 만들어 쓰고 유지보수한다는 저장소 목적에 따라 만듭니다.

## 구현 범위

- Windows를 먼저 개발하고, 이후 macOS로 확장합니다.
- 기술은 Windows에서 시작해 macOS로 넓힐 수 있는지를 기준으로 조사한 뒤 정합니다. 조사 결과는 기술 조사 문서(`research.md`)에 남깁니다.
- 첫 확인 환경은 개발에 쓰는 Windows 11 PC입니다. 모니터 구성과 화면 배율은 미확인입니다.

## 첫 버전의 사용 흐름

앱 실행 → 녹화할 영역이나 창 고르기 → 녹화 시작 → 녹화 정지 → 앞뒤 자르기 → 자동 저장

### 녹화 대상

- 드래그한 영역: 화면에 사각형을 그려 그 부분만 녹화합니다.
- 선택한 창: 창 하나를 골라 그 창만 녹화합니다. 녹화 중 창을 옮겨도 그 창을 녹화합니다.
- 마우스 커서를 함께 녹화합니다.
- 녹화하는 동안 녹화 범위를 테두리로 보여 줍니다. 테두리는 녹화 결과에 나오지 않습니다.

### 시작과 정지

- 화면 위 조작 막대: 녹화 대상 근처에 작은 버튼을 띄웁니다. 조작 막대는 녹화 결과에 나오지 않습니다.
- 트레이 아이콘: 작업 표시줄 알림 영역의 아이콘 메뉴로 시작하고 정지합니다.

### 자르기와 저장

- 녹화가 끝나면 앞뒤의 불필요한 부분을 잘라냅니다.
- 사용자 폴더의 `.screen-gif`(`~/.screen-gif`)에 날짜와 시각으로 이름을 붙여 자동 저장하고, 저장한 파일을 탐색기에서 보여 줍니다.
- 같은 이름의 파일이 있으면 덮어쓰지 않습니다.

화면 구성과 움직임은 [화면 설계](ui.md)에 있습니다.

### 품질 모드

크기와 초당 프레임 수를 직접 조절하는 화면은 두지 않고, 용도별 모드 두 가지를 고릅니다.

- 기본 모드: GitHub PR과 이슈에 첨부하기 좋은 작은 파일
- 품질 모드: 블로그와 문서에 쓰기 좋은, 글자가 선명한 파일

GitHub는 이슈와 PR에 첨부하는 GIF를 10MB까지 받으므로, 기본 모드는 이 한도 아래를 목표로 합니다. 모드별 크기와 초당 프레임 수는 GIF 변환 방식을 정한 뒤 시제품으로 맞춥니다.

## 확인 기준

- 드래그한 영역만 녹화한 GIF가 만들어집니다.
- 선택한 창만 녹화한 GIF가 만들어지고, 녹화 중 창을 옮겨도 그 창이 녹화됩니다.
- 조작 막대와 트레이 아이콘 양쪽에서 녹화를 시작하고 정지할 수 있습니다.
- 조작 막대는 GIF에 나오지 않고, 마우스 커서는 나옵니다.
- 앞뒤를 자른 결과가 저장한 GIF에 반영됩니다.
- 기본 모드의 GIF를 GitHub 이슈에 첨부할 수 있습니다.
- 품질 모드의 GIF에서 화면 글자를 읽을 수 있습니다.
- 정한 폴더에 저장되고, 기존 파일을 덮어쓰지 않습니다.

## 첫 버전에서 제외

- 모니터 전체 녹화
- 전역 단축키
- 소리 녹음
- 프레임 단위 편집, 글자나 화살표 추가, 클릭 강조
- GIF 외의 출력 형식

- 최대 녹화 길이

- 녹화 중인 창이 가려지거나 최소화될 때의 동작
- 앱 식별자와 표시 이름. 시제품은 식별자 `dev.forme.screengif`, 이름 `screen-gif`를 임시로 씁니다.
- 녹화한 화면 내용을 외부로 보내지 않는다는 규칙을 [작업 규칙](../../../AGENTS.md)에 둘지 여부
