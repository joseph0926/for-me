- 브라우저: 설치된 Google Chrome 157.0.8103.79. 기존 Playwright 1.64.1로 headless 조작. 브라우저와 의존성을 새로 설치하지 않음.
- 앱: 0.1.0. 빌드 과정 없는 Node.js 서버와 정적 웹 파일.
- 실행 소스 SHA-256: `1b55715a6700373aa884fd23479d372ceaf5b82579fbcd3f32d8c81f12ed6f17`. package.json, src와 web의 파일명을 정렬해 각 파일명, NUL 문자와 파일 바이트를 차례로 해시한 값. 문서, 테스트와 개인 데이터는 제외.

### 자동 검사

명령: `node --test test/*.test.mjs`

7개 통과. 생성물과 개인 데이터가 없는 새 임시 사본에서도 같은 테스트 통과. 패키지 설치와 별도 빌드 또는 릴리스 명령은 없음.

- 요청, 변경, 후속 사용의 연결과 사용자 원문 보존, 순환 연결 거절.
- 같은 요청 재시도의 중복 방지, 오래된 revision과 다른 내용의 operationId 재사용 거절.
- 휴지통, 재시작, 백업 복원, 복원 직전 기록 보존.
- 앱 이름과 폴더 변경, 문서 누락, 앱 폴더 제거 후 기록 보존. 기록 당시 이름과 현재 이름 구분.
- 잘못된 날짜와 숫자, 미래 스키마, 손상 파일 거절. 실패 뒤 원본 유지.
- 별도 CLI 프로세스 두 개의 동시 쓰기에서 하나만 승인하고 다른 요청에는 충돌 반환.
- HTTP 서버와 AI CLI의 같은 데이터 조회. 외부 Origin과 Host, 쓰기 토큰 없는 요청 거절. 임의 파일 조회와 심볼릭 링크 거절.

새 임시 사본에서 원문 수정 제한, revision 검사, 휴지통 처리, 문서 누락 표시, 미래 스키마 검사, 동시 쓰기 충돌 검사, HTTP 쓰기 토큰 검사를 각각 고장 낸 뒤 해당 테스트가 실제 assertion 실패로 잡는지 7건 확인. 원본 저장소를 고장 내거나 Git 작업을 하지 않았고 임시 사본은 정리함.

### 브라우저 확인

실제 서버와 임시 개인 데이터로 다음 흐름을 조작함. 검사용 가상 경험은 실제 사용자 기록에 넣지 않음.

1. 한 줄 입력으로 기록 저장.
2. 기록 수정과 사용자 원문 수정 금지, 변경 전후 보존.
3. 창을 닫고 새로고침한 뒤 미저장 초안 복구.
4. 입력 중 별도 AI 쓰기가 발생하면 충돌을 표시하고 입력 보존. 사용자가 다시 저장하면 반영.
5. 변경에 후속 경험을 연결하면 후속 사용 대기 표시 해제.
6. 휴지통 이동과 복원.
7. 선택 범위 Markdown 내려받기.
8. 새 앱 등록과 시작 이유 입력.
9. 앱 이름과 사용 상태 변경, 상태 변경 이유 보존.
10. JSON 백업 복원과 기록 수 보존.
11. 1440px 데스크톱과 390px 모바일 크기에서 조작. 모바일 가로 넘침 없음.
12. HTML 모양의 사용자 입력을 텍스트로 표시하고 코드 실행하지 않음.
13. 저장이 완료된 뒤 응답만 끊긴 경우 오류와 입력을 보존하고 재시도 시 중복 생성하지 않음.

화면 증거는 Git에서 제외되는 `artifacts/desktop-empty.png`, `desktop-records.png`, `mobile-records.png`, `mobile-timeline.png`에 있음. 모바일 전체 페이지 캡처가 반복되는 현상을 확인해 실제 보이는 영역과 스크롤 후 영역을 나눠 확인함. 데스크톱과 모바일 영역 캡처를 직접 열어 검사함.

### 최초 실패와 후속 결과

- 첫 검사에서 macOS 임시 경로의 `/var`와 실제 `/private/var` 차이로 정상 문서를 누락으로 표시함. 저장소 루트의 실제 경로를 먼저 구하도록 수정하고 같은 폴더 이동 검사 통과.
- Host 위조 검사에서 Node fetch가 전달한 Host 값이 그대로 전송되지 않아 기대한 거절을 확인하지 못함. 실제 HTTP 요청에 Host를 명시하는 검사로 바꿔 403 확인. 앱의 호스트 허용 범위를 완화하지 않음.
- 샌드박스가 로컬 포트 실행을 EPERM으로 거절함. 승인된 환경에서 서버 검사를 통과했으며 해당 실행 권한을 빠뜨린 재실행 실패는 별도 실패 inbox에 기록함.

### 미검증과 제한

- Windows 실행과 실제 Windows 파일 교체 동작.
- Safari, Firefox, 실제 휴대폰 조작과 다른 컴퓨터에서 접속.
- 사용자의 장기 사용성과 실제 만족. 테스트 기록으로 대신 판정하지 않음.
- 전원 손실, 파일 시스템 고장과 32 MiB에 가까운 대용량 이력의 장기 성능.
- 각 앱 내부의 실제 사용량 자동 수집, 외부 대화 이력 자동 수집, 기기 동기화는 미구현.
