# 범위와 결정

2026-11-17 사용자는 직접 만든 앱의 사용, 유지보수와 발전 과정을 기록하고 싶다고 요청했습니다. 시작 이유도 남기고 수동 입력 부담을 줄이는 자동화와 웹 화면을 요구했습니다. 개발 AI가 사용자의 불편 요청을 다시 입력하게 하지 않고 기록, 변경과 검증, 버전을 연결하는 방식을 승인했습니다.

첫 버전은 현재 컴퓨터에서 실행하는 Node.js 서버와 빌드 없는 웹 화면, 같은 저장 기능을 호출하는 CLI입니다. 별도 패키지 설치, API 키, 계정이나 외부 게시가 없습니다. 네 기존 앱을 초기 등록하며 시작 이유와 사용 상태는 확인 전까지 비워 둡니다.

사용자 원문과 AI 해석, 실행 증거를 구분합니다. 앱 ID는 폴더나 이름 변경에 영향받지 않습니다. 저장소 연결 실패가 기록 조회와 수동 입력을 막지 않습니다. 요청 중복 방지와 revision 충돌, 파일 교체와 이력 보존을 저장 기능이 책임집니다.

후속 범위: 앱 내부 사용량 자동 수집, 전체 대화 수집, 휴대폰과 여러 기기 동기화, 외부 AI 상시 분석. Git 커밋과 배포는 기록 기능에 포함하지 않습니다.
