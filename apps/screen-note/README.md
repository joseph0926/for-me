# 개인용 이미지 편집기

평소 이미지를 편집할 때 운영체제 기본 편집기에서 느꼈던 불편을 줄이기 위한 도구입니다. 스크린샷도 편집할 수 있는 이미지의 한 예입니다.

2026-11-23에 사용자가 개발 방향을 정했습니다. 첫 화면 초안은 자주 하는 메모, 자르기, 가리기, 강조를 쉽게 찾는 데 초점을 둡니다. 첫 버전은 macOS와 Windows를 목표로 Tauri 2, React, TypeScript, Konva로 만듭니다.

## 편집기 사용

첫 화면의 점선 안을 눌러 PNG, JPEG, WebP, GIF 파일을 고르거나, 이미지 파일을 창에 끌어다 놓거나, 이미지가 담긴 클립보드에서 macOS는 ⌘V, Windows는 Ctrl+V로 붙여 넣습니다.

macOS에서는 Finder에서 이미지의 **다음으로 열기 → Screen Note**를 선택할 수 있습니다. 더블클릭할 때마다 Screen Note로 열려면 PNG, JPEG, WebP 각각에 대해 **정보 가져오기 → 다음으로 열기 → Screen Note → 모두 변경**을 선택합니다. 여러 파일을 한꺼번에 열면 첫 파일을 열고, 편집 중이면 기존 이미지를 교체할지 먼저 묻습니다.

파일은 보기 모드로 열립니다. GIF는 바로 재생됩니다. 정지 이미지에서 **편집**을 누르면 도구가 나타납니다. **보기로**를 누르면 작업 중인 결과를 볼 수 있고, 다시 편집을 누르면 되돌리기 기록도 이어집니다. [보기 모드와 GIF 재생 조사](docs/view-mode-and-gif.md)

편집 모드에서 왼쪽 도구 아이콘에 마우스를 올리거나 Tab 키로 이동하면 이름과 단축키가 나타납니다. 선택(V), 자르기(C), 펜(P), 메모(T), 가리기(R), 강조(H)는 키를 눌러 바로 고를 수 있습니다. 좁은 창에서는 도구 이름이 아래쪽에 표시됩니다. 맨 아래에는 자른 결과의 픽셀 크기와 화면에 맞춘 배율이 표시됩니다.

- **메모**를 고르고 이미지에서 글을 넣을 위치를 누릅니다. 글을 입력한 뒤 **적용**을 누릅니다.
- **자르기**를 고르고 남길 범위를 끕니다. 안내선과 픽셀 크기를 확인하고 놓으면 적용됩니다. **가리기**는 선택한 범위를 불투명하게 채우고, **강조**는 기본으로 주황색 테두리를 그립니다.
- **펜**을 고르고 이미지 위에서 끌면 자유선을, 한 번 누르면 점을 그립니다. 위 설정에서 선 색과 굵기를 정하고 여러 획을 이어 그릴 수 있습니다.
- 메모, 가리기, 강조를 만들면 바로 선택됩니다. 네 모서리의 손잡이를 끌어 크기를 바꿉니다. 메모는 글자 비율을 유지하고, 가리기와 강조는 가로와 세로를 따로 조절합니다. 끌어서 옮기거나, **선택** 도구로 기존 표시를 눌러 다시 고릅니다. 강조는 테두리를 누르면 선택되고, 안쪽을 누르면 그 아래 표시가 먼저 선택됩니다. 아래에 다른 표시가 없으면 강조가 선택됩니다. 선택한 표시 옆의 막대에서 색을 고르거나 표시를 지울 수 있습니다. 메모는 글, 글자색, 굵기, 크기(원본 이미지 픽셀)도 바꿀 수 있습니다. 가리기는 채우기 색을, 강조는 테두리 색을 바꿉니다.
- **되돌리기**로 마지막 편집을 취소합니다. 같은 표시의 색을 연달아 바꾼 것은 한 번에 되돌립니다. **이미지 복사**로 현재 영역과 표시를 원본 해상도의 PNG로 합쳐 클립보드에 보냅니다.

편집 결과를 파일로 남기려면 **복사본 저장**을 누릅니다. 데스크톱 앱은 다운로드 폴더에 `사진-복사본.png`처럼 저장하고, 같은 이름이 있으면 번호를 붙입니다. 자르기와 표시가 반영되며 원본 파일과 편집 기록은 유지됩니다. 웹에서는 브라우저의 다운로드 설정을 따릅니다.

## 개발과 빌드

저장소 루트의 Node.js 버전과 이 앱의 Rust 버전을 사용합니다. 이 폴더에서 실행합니다.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm test
corepack pnpm build
corepack pnpm tauri dev
```

macOS 앱은 `corepack pnpm tauri build --bundles app -- --locked`로 만들며, 결과는 `src-tauri/target/release/bundle/macos/Screen Note.app`에 있습니다. 개발 머신의 로컬 실행용으로 서명합니다. Windows 빌드와 실제 편집 확인 범위는 [검증 기록](docs/verification.md)에 남깁니다.
