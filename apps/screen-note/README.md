# 스크린샷 메모

화면을 캡처한 직후 바로 그리기와 메모를 남기는 도구입니다.

## 현재 상태

2026-11-22에 조사와 범위 초안을 정리했습니다. 코드는 없고, 구현 시점과 대상 운영체제는 아직 정하지 않았습니다.

비교 기준은 운영체제 기본 도구입니다. 공식 문서와 기사를 조사한 범위에서는 macOS와 Windows의 기본 캡처 도구에서 캡처 직후 편집기 자동 열기, 영역 모자이크, 단계 번호를 찾지 못했습니다. 이 차이를 첫 버전에서 채웁니다.

## 문서

- [범위 초안](docs/scope.md): 사용 흐름, 그리기 도구, 결정할 것
- [조사](docs/research.md): 운영체제 기본 도구, 기존 앱, 구현 기술 후보

공통 개발 절차는 [개발 절차](../../docs/development.md)를 따릅니다.
