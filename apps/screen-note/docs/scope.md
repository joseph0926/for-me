# 범위 초안

2026-11-22에 정리한 아이디어입니다. 구현 시점과 어느 운영체제부터 만들지는 아직 정하지 않았습니다. 지금 단계는 조사와 문서화까지입니다.

## 목표

화면을 캡처하면 곧바로 편집 화면이 열리고, 여러 그리기 도구로 표시와 메모를 남긴 뒤 복사하거나 저장합니다.

사용자가 처음 말한 요구는 두 가지입니다.

- 캡처 직후 바로 그리기
- 그리기 도구가 많을 것

[화면 녹화 GIF 생성기](../../screen-gif/README.md)와는 별도 앱으로 둡니다(사용자 선택). 화면 캡처와 권한 처리 코드는 가져다 쓸 수 있습니다.

## 기본 도구와 다른 점

비교 기준은 운영체제 기본 도구입니다(2026-11-22 사용자 결정). [조사](research.md#결론)에서 찾은 차이는 다음과 같습니다. 문서와 기사 기준이며 직접 써 보며 확인하지는 않았습니다.

- 캡처하면 편집 화면이 바로 열립니다. macOS는 미리보기를, Windows는 알림을 눌러야 열립니다.
- 영역 모자이크로 가릴 수 있습니다. 두 기본 도구에서 찾지 못했습니다.
- 그린 도형과 글자를 나중에 골라 옮기고 고칠 수 있습니다.

기존 앱(Shottr, Flameshot, ShareX 등)은 [도구를 고를 때 참고](research.md#기존-앱기능-참고)합니다.

## 사용 흐름 초안

전역 단축키 → 화면이 멈춘 상태로 영역이나 창 고르기 → 편집 화면이 바로 열림 → 그리기와 메모 → 복사 또는 저장

- 화면을 먼저 찍고 정지 이미지 위에서 고르는 방식을 우선 검토합니다. 근거는 [조사](research.md#화면-녹화-gif-생성기에서-가져올-교훈)에 있습니다.
- 편집 화면에서 Enter나 `⌘C`로 클립보드에 복사하고 닫습니다. 저장은 정한 폴더에 날짜와 시각으로 이름을 붙이고 기존 파일을 덮어쓰지 않습니다.
- Esc는 편집 중 그린 것이 있으면 버릴지 묻고, 없으면 바로 닫습니다.

## 그리기 도구

### 첫 버전 후보(사용자 선택)

- 펜: 자유 그리기. 색과 굵기 몇 가지
- 사각형과 화살표
- 글자 메모
- 모자이크로 가리기: 원본 픽셀을 덮어 굽습니다. 저장한 이미지에서 원래 내용을 되살릴 수 없어야 합니다.

### 함께 필요한 기본 조작

- 그린 것을 골라 옮기고 크기 바꾸기, 지우기
- 되돌리기와 다시 하기
- 자르기

### 이후 후보

기존 앱에는 있지만 기본 도구에서는 찾지 못한 기능입니다. 필요한 것만 고릅니다.

- 단계 번호(1, 2, 3을 차례로 붙이기)
- 스포트라이트(고른 곳 외에 어둡게)
- 형광펜, 확대경
- 화면에 고정해 띄우기
- 글자 인식으로 복사
- 다시 편집할 수 있는 원본 저장

## 결정할 것

- 구현 시점: 사용자가 정합니다. 지금은 조사와 문서화까지입니다.
- 첫 대상 운영체제: macOS, Windows, 또는 둘 다
- 기술: Tauri 2와 Konva, 또는 macOS만이면 Swift. 비교는 [조사](research.md#구현-기술)에 있습니다.
- macOS 최소 버전: 한 장 캡처 API(`SCScreenshotManager`)를 쓰면 macOS 14 이상입니다. 화면 녹화 GIF 생성기는 12.3 이상입니다.
- 캡처 방식: 정지 화면에서 고르기, 또는 실제 화면 위에서 고르기
- 저장 폴더와 저장 여부: 복사만 하고 저장하지 않는 사용을 기본으로 할지

## 확인 기준 초안

구현을 정하면 다듬습니다.

- 단축키를 누르고 영역을 고르면 편집 화면이 바로 열립니다. 열리는 데 걸린 시간을 측정해 남깁니다.
- 캡처 결과는 화면의 원래 픽셀 해상도입니다. 선택 화면과 이 앱의 창이 찍히지 않습니다.
- 네 도구로 그린 결과가 복사한 이미지와 저장한 파일에 같게 나옵니다.
- 모자이크한 부분은 저장한 파일에서 원래 내용을 읽을 수 없습니다.
- 화면 기록 권한을 거절하거나 취소하면 안내가 가려지지 않고 앱이 멈추지 않습니다.
- 단축키 등록에 실패하면 사용자에게 알립니다.
- 같은 이름의 파일이 있으면 덮어쓰지 않습니다.
